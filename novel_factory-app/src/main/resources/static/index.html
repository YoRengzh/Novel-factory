EMBEDDING

向量检索分区

Embedding 负责「回忆相似情节」的向量召回，与聊天模型相互独立：走自己的 base-url 与 key。 可运行时覆盖地址 / 密钥 / 模型 / 维度——客户端按调用自动重建，保存即生效、跨重启保留，留空字段沿用当前值。 ⚠️ 维度与 Qdrant 集合绑死：换维度后新旧向量不可比、既有索引需重建，不确定就别动维度。API Key 只显示掩码。

SCENE MODELS

场景模型矩阵

每个生成场景可独立指定模型 / 输出上限 / 采样温度。优先级：场景覆盖 > 全局覆盖（上方表单）> yml 静态配置 （场景条目缺项回落统一 chat-model）。覆盖输入留空 = 清除该字段覆盖、回退下一层。保存即生效、跨重启保留。

关闭时：所有场景强制走上方「模型接入设置」的全局地址与密钥，场景自带地址密钥一律不生效； 打开时：每个场景可自配地址密钥，并在下方各行编辑（留空 = 沿用全局 / yml 静态）。
