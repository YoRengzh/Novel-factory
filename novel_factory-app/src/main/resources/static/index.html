FALLBACK

兜底模型

说明：所有场景共用这一个兜底模型，只有主模型与场景配置都不可用（额度耗尽 / 模型下线 / 参数被拒）时才启用。 兜底的意义是换一个供应商——同供应商的另一个模型常与主模型一起挂，所以这里可以选中转站； 留空则沿用主模型的地址密钥（同供应商时只写模型名即可）。 输出上限建议显式填写：不同模型族的 token 上限差异很大，沿用主模型的值可能直接 400。 留空模型名 = 不启用兜底。

PROVIDERS

中转站管理

在这里登记多个供应商（中转站），保存后到上方「模型接入」的中转站下拉选用； 「获取模型」一键拉取该站可用模型名，全局/场景/兜底的模型输入框都会变成可选的下拉。 按站点选择接口协议：OpenAI 兼容站选 OpenAI，Claude 官方或 Anthropic 协议中转选 Anthropic， gpt-5 系 Responses 中转选 OpenAI Responses。 地址带不带 /v1 都可以，程序自动适配。密钥只保存在本机，界面只显示掩码。

EMBEDDING

向量检索分区

Embedding 负责「回忆相似情节」的向量召回，与聊天模型相互独立：走自己的 base-url 与 key。 可运行时覆盖地址 / 密钥 / 模型 / 维度——客户端按调用自动重建，保存即生效、跨重启保留，留空字段沿用当前值。 ⚠️ 维度与 Qdrant 集合绑死：换维度后新旧向量不可比、既有索引需重建，不确定就别动维度。API Key 只显示掩码。

REFERENCE MODE

资料检索方式

动态参考资料（写作技法/情节结构等）的挑选方式： 向量语义检索按语义相似召回，更贴合当前章节意图（需在上方配置嵌入 Key）； LLM 索引选择让聊天模型读资料目录来挑，不需要向量设施。 保存即生效、跨重启保留；切换后资料选择缓存自动按新模式重算。

MY REFERENCES

我的参考资料

把你自己的写作范例、题材知识喂给产线：新资料与内置 58 份同等待遇——进向量索引、被按需检索注入对应场景，保存后下一批作业即生效。
格式要求：首行写「# 标题」，随后一段一句话简介（这两行决定资料在目录里怎么被选中）；正文随意，纯 Markdown，建议不超过 3 万字。
命名规则：小写字母/数字/连字符（如 my-battle-exemplar）。 名字前缀决定资料被哪些场景检索到：plot-structure- 开头归「结构模板」（计划/蓝图场景），seed- 开头归「题材设定」（设定集场景），其余归「写作技法」（正文/审校场景）。

STYLES

文风（写作风格）

每个题材对应一篇文风文件，写作时整篇注入。内置四篇（通用/玄幻/言情/悬疑）可查看； 「编辑」即创建你自己的覆盖版——故事命中该题材时用你的版本，恢复内置一键回退。 没有内置文风的题材（科幻/末世/无限流/都市现实/异能）编辑后即第一次拥有专属文风，不再回落通用版。
