# 悬疑/推理 题材风格

悬疑、推理、刑侦、惊悚类题材的写作风格与纪律：信息差制造悬念、多线交织、线索的埋设与揭示节奏。适用于写正文与修订；规划类场景只取线索布局原则。本文管基础方向，具体调查、诡计与证据处理见题材补充参考；推理公平性、视角形式及悬念强度遵循本书定位与作者指定契约。

## 悬疑推理风格

- **叙事结构**：围绕未知问题组织信息，单线调查或多线交织均可；切换时让读者理解各线的时间、人物与关联。
- **误导技法**：红鲱鱼、视角盲区与人物偏见可引导错误判断，误导有事实基础，并能在揭晓后解释。
- **线索管理**：决定解答的线索在揭晓前以可理解的方式呈现；复现用于建立联系、修正理解或提醒遗忘，不以出现次数衡量公平性。
- **节奏控制**：紧张与舒缓交替，章末可落在疑问、阶段答案、决定或平静余韵上；悬念来自尚待解决的问题，不必每章追加危险。
- **氛围营造**：光影、声音、天气与日常违和细节服务于角色感知和未知压力，调查清晰度与恐惧强度各按场景需要安排。
- **人物行为**：决策符合动机、知识与处境；失误可来自偏见、恐惧或错误信息，其原因与影响可追溯。
- **对话风格**：审讯、访谈与对峙关注试探、回避和信息交换；直说与言外之意都可有效，语气符合角色身份。
- **真相揭示**：核心解答有因果与证据支撑，公平推理所需材料提前可见；巧合可触发调查，但不能替代关键证明，回看时能分清事实与误判。
