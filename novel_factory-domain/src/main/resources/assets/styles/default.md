# 通用写作参考

优先服务当前文体、任务和作者最新明确要求。以下原则冲突时，以具体任务、连贯性和作者明确指示为准；不要机械套用。

## 表达选择

- 重要过程可以用具体细节推进，也可以让人物直接说出或想到关键判断。 已经通过行为和反馈讲清的用意，写到结果可以收住 但关键转折仍需必要支撑，不能只剩结论。
- 对白体现人物声音、交流对象与目的。段落长短、语气和修辞随人物处境与感受变化，不机械统一。

## 视角与信息

- 区分叙述者、读者和角色各自知道的内容。全知叙述可以让读者先知道一件事，角色仍须按自己掌握的信息作出判断；非全知视角不要强行制造信息差。
- 让处境和新证据决定交代时机。调查可逐步推进，收官和技术说明也可完整揭示，但避免无必要的大段说明性倾倒。

## 结尾与伏笔

- 结尾服从本章落点，可以是决定、结果、关系变化、余韵或悬念。
- 伏笔兑现以既有承诺和当前事件的关联为准。一个事件可以兑现多条线索，某章也可以暂不回收；但伏笔管理留在构思和计划层，正文只写实际发生的事。
