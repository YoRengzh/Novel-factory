# 通用写作参考（未指定风格时的兜底）

作者明确的风格、视角、基调和当前章节任务优先。本文件是可选择的技法参考，不新增人物、对白、冲突、代价、伏笔或悬念任务。

## 表达选择

- 以具体而可理解的细节支持重要场景，展示、讲述和内心判断可以组合；不要把所有情绪都改成肢体动作。
- 对白体现人物声音与交流目的，不规定句长、轮次或每章数量。独处行动和无对白章节合法。
- 节奏随人物处境、行动规模和后果展开，不按固定章数切换高潮与缓冲。
- 简洁不是压缩掉必要过程，充分展开也不是重复已知状态。

## 视角与信息

- 服从作者选定视角，区分叙述者、读者和角色各自知道的内容。
- 关键知识和能力需要既定来源；全知叙述可以告知读者，不意味着角色已经知情。
- 信息释放没有统一比例，调查可逐步推进，收官和技术说明也可完整揭示。

## 结尾与伏笔

- 结尾服从本章具体落点，允许决定、结果、关系变化、余韵或悬念，不强迫每章留新危机。
- 伏笔回收以已有承诺和当前事件相关性为准，不按每章数量布置。一个事件可以自然兑现多条线索，某章也可以完全不回收。
- 事件正文只写发生的事，来源登记放在计划字段，不把无关伏笔评估塞进正文目标。
- 排期与场景冲突时明确说明，不为清账硬造人物和场面。

## 重复检查

- 注意空洞套句、同角度重复描写和无新认知的自我确认，判断基于上下文而不是词语或次数本身。
- 人物声音允许随状态变化，不把稳定口头习惯改成每章轮换的表演任务。
