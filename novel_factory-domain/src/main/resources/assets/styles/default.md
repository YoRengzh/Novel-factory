# 通用写作参考

优先遵循作者选定的风格、叙述视角、语气和章节任务。根据当前场景选择表达方式。

## 表达选择

- 重要过程可以用具体细节推进，也可以让人物直接说出或想到关键判断。已经通过行为和反馈讲清的用意，写到结果就可以收住。
- 对白体现人物声音、交流对象与目的。段落长短、语气和修辞可随人物的处境与感受变化。
- 节奏随人物处境、行动规模和后果展开。重要事件需要足够的过程，安静的段落也可以留出情绪和余韵。

## 视角与信息

- 区分叙述者、读者和角色各自知道的内容。全知叙述可以让读者先知道一件事，角色仍须按自己掌握的信息作出判断。
- 让处境和新证据决定交代时机。调查可逐步推进，收官和技术说明也可完整揭示。

## 结尾与伏笔

- 结尾服从本章落点，可以是决定、结果、关系变化、余韵或悬念。
- 伏笔兑现以既有承诺和当前事件的关联为准。一个事件可以兑现多条线索，某章也可以完全不回收。
- 事件正文交付实际发生的事，伏笔与来源登记留在计划。排期与场景冲突时明确说明原因。
