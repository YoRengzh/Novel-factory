# 奇幻与仙侠写作

- 以用户提供的本书设定和最新要求为准。设定缺失时采用最小必要假设，不擅自新增关键设定；如影响剧情，先说明假设或询问。以下原则按文本重要性灵活使用，不机械套用。
- 把世界规则落到当前的利益和选择上，让读者知道人物凭什么行动、能承担什么后果。可以用旁白、判断或交流交代必要背景，但旁白克制，只交代理解当前选择所必需的背景，避免说明性倾倒。规则可以留白和制造悬念，不必都即时兑换成当前利益。
- 能力、称谓和资源遵从本书设定。新的用法交代来源和边界，详略随重要性；既有机制按当前理解需要略写或说明，不打断节奏。不自行发明关键设定来源。
- 按人物掌握的信息、所求和身份写交涉。同一宗门的人也可以有不同立场。权衡优先通过选择、行动和对方答复呈现，心理描写可进入但点到为止。
- 战斗写清优势和结果的来由。代价与伤势从既有条件推得，并在影响后续行动时体现；详略随战斗重要性，不必每场都完整推导。
- 成长由经历、训练或规则内的机缘支撑。机缘可以意外，但应有可追溯因果或代价；实力变化和心态变化可以各自发展，不必每次成长都即时解释。
