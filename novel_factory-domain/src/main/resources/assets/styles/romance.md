# 言情/情感 题材风格

言情、情感、都市爱情类题材的写作风格与纪律：情感递进节奏、关系张力的建立与释放、误会与和解的写法。适用于写正文与修订；规划类场景只取关系线原则，不照搬情感描写条款。本文管基础方向，具体情感节拍与场景技法见题材补充参考；关系类型、结局取向与描写尺度遵循本书设定及作者指定契约。

## 言情风格

- **情感递进**：通过共同经历、互动变化与选择积累感情；接触、好感、冲突、和解、深入可作为参考，也适用于重逢、先婚后爱或已稳定关系的不同顺序。
- **关系张力**：性格、立场、误解与外部压力可形成阻碍；稳定期可用共同目标和生活磨合维持吸引力，不必持续制造矛盾。
- **内心描写**：结合行动与心理呈现矛盾，关键选择处可深入展开，轻巧互动中也可用留白。
- **互动细节**：微表情、小动作、习惯与直接表达共同传递情感，选择符合人物表达方式的细节。
- **对话节奏**：暧昧可有试探和留白，甜蜜可轻松或郑重，冲突可尖锐或沉默；语气以人物及关系状态为准。
- **场景氛围**：环境可呼应情绪，也可通过反差增强感受，选取与人物当下注意力有关的细节。
- **配角功能**：闺蜜、兄弟、家人等有自己的生活和立场，其建议与介入应符合所知信息和实际关系。
- **冲突设计**：误会有成立的信息差，价值观与现实利益也可形成矛盾；沟通能够解决的小问题可以及时解决，深层裂痕则落实到后续选择。

## 修罗场写作规范

多方感情交锋可形成戏剧张力；本节仅适用于本书已有此类关系的场景，参与者及反应按实际人物安排，不预设多女主，也不要求全员吃醋。

- **节奏控制**：围绕场景焦点安排发言、动作与沉默，让关键话语有接收者和后果；角色可暂时主导对话，转换焦点时保留其他在场者的状态。
- **误会设计**：交锋基于人物性格、利益和已知信息；半句话或偶然撞见也可成为触发点，但后续判断有合理依据，澄清的难度与实际影响相称。
- **情绪差异**：在意关系的人可能追问、回避、转移话题、争取独处或直接谈边界；也有人不吃醋。表现来自其经历与表达习惯，不按性格标签套固定菜单。
- **应对符合人设**：情绪可以影响判断，化解则依赖当事人掌握的信息、沟通与行动；本书确有系统时再考虑其约束，没有系统也能正常处理关系。
- **信息差管理**：区分读者、视角人物及各参与者掌握的事实，保持知识来源可追溯；谁看见、谁误读、谁刻意隐瞒会改变交锋方向。

## 系统流言情规范

本节只补充本书确已建立的系统面板、好感度、任务提示或读心能力，不新增系统、惩罚或能力。提示形式与作用遵循既定机制，人物感情仍由经历和选择支撑。

- **提示与情感节奏配合**：转折提示、日常数值和任务变化均可按需要出现；提示若改变人物的认知或选择，后续体现其影响，可即时回应也可延后处理。
- **惩罚按机制落地**：本书有惩罚时，交代其实际表现与后果；可承担喜剧、压力或关系变化等功能，影响范围以已建立规则为准。
- **读心能力有边界**：读取范围、精度、可靠性及代价遵循本书设定；碎片弹幕或完整语句都可使用，角色判断不超出能力实际提供的信息。
- **系统变化有因果**：升级、故障或消失的铺垫与篇幅按重要性安排；若改变依赖关系、任务或信息获取，后续保留相应的适应过程与实际影响。
