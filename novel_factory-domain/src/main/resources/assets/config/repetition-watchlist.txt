# 重复意象盯防清单：跨章累计出现的"具体意象"点名表
# 与 fatigue-patterns.txt 的分工：那份管**词性套话**（副词/眼神/身体反应，与题材无关）；
# 本表管**题材相关的具体意象**——同一件东西（物件/场景/动作）被反复用作情绪载体时点名，
# 要求换成别的载体。典型病症：同一意象每隔几章出现一次，每次都承担同样的抒情功能。
#
# 格式：一短语一行；# 开头为注释；[组名] 行切换分组；空行忽略
#   [common]  所有题材通用（默认组）
#   [<题材>]  仅该题材生效，题材名取 GenreTypeVO.code（urban/fantasy/scifi/...）
# 匹配口径：正文**逐字包含**（子串匹配，非分词）——故词条应写得足够具体，
#   能命中真实情节用法的词优先（如某个具体动作短语），避免用会大面积误伤正常叙述的单字/通用词。
# 阈值不在本文件：一律以 StyleStatService 的常量为准（改词只改本文件，改阈值只改代码）。
# 增删本文件即时生效（索引按内容哈希缓存），无需改代码。
#
# 本文件刻意不预置任何题材词条：意象是"这本书反复用了什么"的判断，须按具体故事自行增删，
# 不能替某本已跑过的小说把它诊断出的意象沉淀成默认规则。默认全空 = 不启用意象盯防，
# 对任何题材零影响；需要时在对应 [题材] 组下逐行添加。
