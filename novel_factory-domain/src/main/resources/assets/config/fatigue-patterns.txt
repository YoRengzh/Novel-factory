# 疲劳词与套话模式表：单章门禁（StyleViolationPolicy）与跨章疲劳统计（StyleStatService）共用数据源
# 格式：一词一行；# 开头为注释；[类别] 行切换类别；空行忽略
# 类别语义（**阈值不在本文件，一律以 StyleViolationPolicy 的常量为准**）：
#   adverb  AI万能副词——单章密度 > 5 次/千字 报 MINOR（由 3.0 上调；
#           旧口径在长篇样本上 BLOCKING 误报偏高，中位密度约 3.92 次/千字）
#   eye     眼神套话——单章合计 >= 3 次 报 MINOR（原为 >= 2 次：低位命中多为正常描写）
#   body    身体反应套话——同一词条单章 >= 2 次 报 MINOR
#   extra   仅参与跨章疲劳统计（StyleStatService），不触发单章门禁
# 严重度分层：上述四项**全部为 MINOR**——只记录 + 回灌规划层，
#   不触发修订、不触发候选选优（阈值型指标在整章重写下不可收敛）。
#   本词表驱动的检查中没有任何一项是 BLOCKING；唯一保留 BLOCKING 的是
#   「章节编号元信息泄露」，该检查硬编码在 StyleViolationPolicy 内，不走本文件。
# 改词只改本文件，改阈值只改 StyleViolationPolicy。
