# 视角纪律

遵守作者指定的叙事视角与本章视角人物。以下信息边界规则按实际视角适用，不强制把所有小说写成第三人称限知。

## 信息渠道与角色知识

- 角色知识来自已有经历、感官、他人告知、可追溯情报、公开常识或本书明确允许的特殊能力。
- 当使用限知或第一人称视角时，不把读者知道的幕后事实写成该角色已经确知；推测与确证应可区分。
- 使用全知、多视角、书信或插叙时，叙述可以提供相应范围的信息，但不能无依据地赋予角色同样的知识。
- 新角色可以知道其背景、调查或信息网络支持的事实，不要求一律对主角一无所知；重要知情必须有故事内来源。
- 人物称谓和身份介绍保持可理解，不能把尚未建立的身份当作角色的已知事实。

## 揭示与切换

- 揭示多少由本次剧情和作者意图决定，不使用固定百分比或“一次一层”的统一限制。
- 完整揭晓、群体告知、技术解释和收官清算可以成立，不为保留悬念刻意打断必要信息。
- 切换人物或场景时让读者识别，不无标记地混合多个视角人物的内心。
- 信息差服务人物行动和故事，不要求所有重要信息都绕成碎片或神秘暗示。
