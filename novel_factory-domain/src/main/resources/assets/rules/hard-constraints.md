# 写作硬约束（逐条执行，违反即不合格）

> 本文件是**硬约束**而非写作建议：与其它风格规则冲突时以本文件为准。
> 计划阶段把这些约束**落成每章可核对的具体安排**（写进各章 goal/keyEvents），正文阶段逐条自检。

> ℹ️ 篇幅与对话的**数量目标**已移到 `rules/plan-targets.md`，**只注入规划场景**（2026-09-22 约束归层）。
> 正文阶段不要盯数量指标——按契约的【本章完成条件】把内容写完整即可；
> **数量达标但内容注水，同样不合格**。

## 一、内容密度纪律（正文逐段自检）

**每一段都必须带来信息增量**，至少满足其一：
新信息进入读者视野 / 角色目标变化 / 关系或信任变化 / 资源或位置变化 / 风险上升或下降 /
角色做出不可撤销的选择。

**只重复已知状态、只在原地循环同一种情绪的段落，必须删掉或并入相邻段落**，不得靠它凑篇幅。
具体动作优先于抽象心理：用可感知的动作呈现（"他攥紧刀柄指节泛白"），
禁止用"感到愤怒"这类抽象心理替代动作。

### 对话标注格式（机械可核对，不得变通）

**人物说出的话一律用成对的中文双引号“”包裹，禁止用括号。**

- ✅ 正确：`母亲把碗放下：“吃饭了。”`
- ❌ **禁止**：`母亲把碗放下：（吃饭了。）` / `（吃饭了）` / `[吃饭了]` / `「吃饭了」`
- 引号内**只放人物实际说出的话**，不得混入动作、神态、心理描写：
  - ✅ `父亲把筷子一搁：“合同呢。”`
  - ❌ `父亲把筷子一搁：“合同呢，他盯着表哥。”`
- 引号外的叙述负责交代说话人、动作与语气；**连续对话必须分行**，不得挤在同一段里。
- 心理活动、内心独白**不加引号**（加引号就会被当作台词，也计入对话比，属虚报）。

> 为什么钉死：正文里出现括号包对话，会让「对白行占比」「有效对话句数」两项统计直接失真——
> 括号包裹的句子既不被计入对白，又占着篇幅，等于把对话坍缩伪装成达标。这是机械可判的，
> 所以不留余地。

### 段落切分（机械可核对，不得变通）

**正文必须分段，每段之间用空行隔开；严禁把整章写成一个不分段的长文本块。**

- 段落长度以 **40~150 字**为宜，超过 200 字的段落必须拆开。
- 以下位置**必须另起一段**：场景/时间转换处、说话人切换处、动作与心理描写交替处、
  视角或焦点人物变化处。
- 每段只承担一个语义单元（一件事、一个动作、一次发言或一次心理变化），
  不要把多件事塞进同一段。

> 为什么钉死：正文一旦不分段，"对白行占比""段落密度审校"等按行统计的门禁会**整体失真**
> （实测单段含引号时对白行占比会被误算为 100%）。这是机械可判的格式要求，不是风格偏好。

## 二、节奏（跨章配额）

5. **每 3 章内至少 1 章为缓冲章**（chapterType=transition 或 normal 且无高强度对抗）；
   **禁止连续 3 章以上高强度对抗**。
6. **连续两章高潮（climax）之间必须插入至少 1 章缓冲**。
7. 缓冲章仍须有**至少一处实质变化**（关系/信息/资源），不得为纯赶路、纯整队、纯寒暄。
8. 过渡章（transition）占比 ≤ 1/3，且不得连续超过 2 章。

## 三、一致性铁律（任何章节不得违反）

9. **状态变化必须写出过程**：人物位置、持有物、伤势、修为、生死等状态，
   凡是与上一章末不同，**必须在本章正文中写出变化是怎么发生的**。
   严禁跨章跳变——例如上一章"东西掉进岩缝"，本章"拿在手里"之前必须有取回的描写。
10. **死亡与重伤不得略过**：角色的死亡与重伤必须在正文中当场发生并被在场者感知，
    不得放到章间"顺便发生"。
11. **专有名词与称谓全篇统一**：人名、地名、功法名、物品名、称谓不得出现同物异名。

## 四、人物口径（防"性格漂移"）

12. **「杀伐果断」＝决策快、不拖泥带水，不等于冷酷无情**。
    每次极端行为（自残、杀人、牺牲或利用同伴）之前必须写足三步：
    a) 他先尝试过的至少一种**非极端方案**；b) 该方案失败的**具体原因**；c) 事后的**代价或自我怀疑**。
13. **主角对"人"必须仍有底线**：可以杀、可以伤，但每次都要付出内心成本。
    **禁止**出现无动机的虐待性、观赏性暴力描写。
14. 主角的弱点必须在正文中持续可见（不是只在设定里写着），并且**至少一次真正让他付出代价**。

## 五、角色能力边界与合法显形（任何题材通用）

15. **能力展示必须与角色阶段一致**：角色的动作、语言、书写、知识外化、专注时长与精细操作，
    必须落在故事已确立的阶段极限内——年龄发育阶段、伤势/状态、训练水平
    （记忆前缀给出【时序锚】等阶段锚时，以锚为准）。**认知**是否允许超前由故事设定决定
    （重生、天才、穿越等前提允许时不得抹平）；但**媒介不能超前**：认知超前只能通过
    该阶段合法的载体表达。卡住时换表达方式，不得为了"展示聪明"让角色越过阶段。
16. **可被解码的间接传递＝能力展示，不算豁免**：涂鸦、摆物、敲击、手势、节奏、器物位置……
    任何载体，只要他人能从中**解码出具体信息**（答案是某数、这是警告、他认出了某物、某计划），
    等同直接展示能力，同样违规。载体换了，本质没变。
17. **他人的解读必须累积、留不确定**：观察者从角色行为中"读出"具体知识或意图，必须经由
    多次重复逐步积累（留意→起疑→试探→初步确认）；**单次观察**至多产生"不寻常"的感觉，
    不得当章坐实为具体结论；不确定口吻保留到计划规定的揭示点。
    **推进的单位是"他人认知的变化"，不是"角色能力的升级展示"。**
18. **合法显形路径（受限角色要展示"内里不寻常"，用这些）**：偏好与倾向（反复选择/趋近/
    回避同一对象）、注意力分配、情绪反应；世界内的自然试探（游戏、任务、日常委托）；
    让观察者跨场景累积疑点。表达的是**倾向**，不是**信息**——读者可以猜，人物不能确认。
19. **解释源唯一，不得新造**：角色的能力/特质/异常，其解释必须来自故事既定设定
    （故事设定与已登记伏笔）；**禁止新造"第二解释源"**（血脉记忆、家族秘辛、神秘组织、
    遗物符号等）来解释已确立的特质，也禁止用新设定替代既有金手指/机制。
    需要新设定时，先作为伏笔登记、后使用，不得在事件里凭空出现。

    ✗ 他把积木摆成三长两短，父亲脸色一变：「他在示警！」
    ✓ 他第三次把积木摆成三长两短。父亲皱了皱眉，没说什么，把积木收进了抽屉。

## 六、自检（正文完成前逐条过）

- [ ] 有效字数 ≥ 1400？有效对话 ≥ 25 句？内心独白 ≤ 20%？
- [ ] **所有人物台词都用成对“”包裹、没有一处用括号？引号内没有混入动作描写？心理活动没加引号？**
- [ ] **正文分段了吗？场景/时间转换、说话人切换处是否都另起了段落？有没有超过 200 字的巨段？**
- [ ] 本章状态与上一章末的差异，是否都写了变化过程？
- [ ] 本章是否有至少一处信息增量？
- [ ] 若有极端行为，三步铺垫是否齐全？
- [ ] **角色本章的能力展示（含一切可被他人事后解码的载体）是否落在其阶段极限内？须坐实的解读是否经过多次累积、并保留了不确定口吻？**
