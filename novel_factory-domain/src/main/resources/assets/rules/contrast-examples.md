# 表达对照与事实保真示例

比较前后句交付的信息。删减重复时保住原有动作、因果、时间和人物所知，改写只服务于当前场景。

## 1. 动作和对白已经交代了用意

- **原句** “签不签？”“我不答应。”她把纸推了回去。她这么做是为了拒绝签字。
- **改写** “签不签？”“我不答应。”她把纸推了回去。
- 前两句已经说清是否签字，最后一句只重复拒绝。推回的是同一张纸。

## 2. 行动与反应足以说明试探

- **原句** 他要先装作不知情，再问钥匙在哪里，看看守门人会先望向哪边。于是他问：“钥匙还在老地方吧？”守门人先朝右廊看了一眼，才摇头。
- **改写** “钥匙还在老地方吧？”守门人先朝右廊看了一眼，才摇头。
- 上下文已经说明问话者知道钥匙换了位置，读者可以从这句问话和守门人的反应看出试探。看向右廊只是线索，不能坐实钥匙在那里。

## 3. 人物的判断提供了新信息

- **原句** 他放下刀。他杀得起，藏不起。何况这人和他没有仇。
- **保留** 放刀交代了选择，内心交代了他担心藏不住杀人的后果，也交代了他为何不愿杀一个与自己无仇的人。

## 4. 直接讲清一条新规则

- **原句** 电梯门合上前，领班说：“这部电梯断电就停，停在半层也不会自动开门。”
- **保留** 这是角色第一次知道断电后不能靠自动开门脱身。下次遇到相同状况，可以接着写他们的应对，除非规则产生了新的作用。

## 5. 章末的动作已经兑现了选择

- **原句** “把今天的也画上。”她把两张图并到一起，终于开始了独立调查。
- **改写** “把今天的也画上。”她把两张图并到一起。
- 上下文已经交代她决定接手调查，话和动作写出了她开始做的第一件事。保留图的数量，收在行动上。
