# 表达对照与事实保真示例（判断方法，非改写公式）

比较前后句交付的信息。删减重复时保住原有动作、因果、时间和人物所知，改写只服务于当前场景。

以下示例用于训练判断力，不是可套用的改写模板。每个示例的结论依赖其上下文；换一个上下文，同样的原句可能需要保留。修订时先问“这句话交付了什么信息、上下文是否已经交付”，再决定删留。删减与保留示例各占一半，目的是展示判断方法，不是提供删减清单。

## 1. 动作和对白已经交代了用意

- **原句** “签不签？”“我不答应。”她把纸推了回去。她这么做是为了拒绝签字。
- **改写** “签不签？”“我不答应。”她把纸推了回去。
- 前两句已经说清是否签字，最后一句只重复拒绝。推回的是同一张纸。**前提是上下文已让读者知道她拒绝签字；若上下文未交代，最后一句可能是必要交代。**

## 2. 行动与反应足以说明试探

- **原句** 他要先装作不知情，再问钥匙在哪里，看看守门人会先望向哪边。于是他问：“钥匙还在老地方吧？”守门人先朝右廊看了一眼，才摇头。
- **改写** “钥匙还在老地方吧？”守门人先朝右廊看了一眼，才摇头。
- 上下文已交代他知道钥匙换了位置**并决定装作不知情**，读者可以从问话和守门人反应看出试探。看向右廊只是线索，不能坐实钥匙在那里。**若上下文未交代“装”，这句不能删，否则读者可能以为他真的不知道。**

## 3. 章末的动作已经兑现了选择

- **原句** “把今天的也画上。”她把两张图并到一起，终于开始了独立调查。
- **改写** “把今天的也画上。”她把两张图并到了一起。
- 上下文已交代她决定接手调查，话和动作写出了她开始做的第一件事。保留图的数量，收在行动上。**若上下文未交代“决定接手”，“终于开始了独立调查”可能承担交代功能，不宜删。**
