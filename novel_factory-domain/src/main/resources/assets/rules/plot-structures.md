# 情节结构参考（按需使用，不是生成模板）

常见结构用于检查已有剧情的缺口，不用于替人物决定剧情。先根据人物目标、前情后果和作者大纲规划事件，再按需借助结构诊断节奏；完整参考由动态资料选择器从 `references/plot-structure-*.md` 注入，不要求照表填空。

## 使用规则（必须遵守）

- 作者明确指定的结构与叙事意图优先；未指定时不强制选一种模板贯穿全书，也不要求额外输出 `structure` 字段。
- 结构用于全书/卷/弧的适当尺度，不得把同一套完整节拍在每章、每个五章段里重跑。参考资料中的固定章数、比例、必备桥段仅是示例，不得凌驾于当前规划契约。
- 先推导「已有局面→人物选择→持续后果」，再决定哪些事件值得成章；独立支线应有自己的动机，不必硬连主角的每次解题。
- 检查的是「问题来源→关键应对→结果反馈」是否重复。换场景、反派、能力名或剧情线标签，不算结构变化；尤其避免「发现问题→主角轻松解决→旁人震惊→再来一个问题」。
- 新进展应承接此前选择的后果，或已有独立角色的行动。允许顺利兑现与日常相处，不机械轮换输赢、不强塞挫败/代价/反转来凑多样性。
- **组织型结构**描述事件排布，可按需要使用；无需混写里程碑术语来显得复杂。

## 单章有效性检查（不固定比例）

- 本章新增了什么事实、选择、关系或资源变化？这种变化会如何影响后续行动？
- 若与前一章交换顺序仍不影响相关人物的选择，是否只是同一种桥段换皮？独立支线可有各自的时序。
- 章内可突出交锋、行动、发现、兑现或后果消化，不要求每章都从新问题起步、以强悬念收尾。
- 日常和安静收束并非无效；没有局面变化的流水账、重复确认和背景堆积才需要删改。高潮/卷末的强钩子仍按对应场景规则执行。
