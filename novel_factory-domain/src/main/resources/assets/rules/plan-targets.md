# 篇幅与对话目标（**规划层专用**）

> ⚠️ 本文件**只注入计划/蓝图场景，不注入正文**。
>
> **为什么分开**：正文层若直接下达数量指标，模型会"为满足数量而写"——多写动作、多塞对白、
> 硬凑推进点，这恰恰是注水的来源（实测：正文 prompt 里的"至少 3 个推进点 / 8 个动作 / 25 句对话 /
> 1500-2500 字"既没有阻止偏薄章节，反而给了凑字数的方向）。
> 正确做法是：**规划层把目标落成每章的具体安排**，正文层只认契约里的【本章完成条件】
> 与 `hard-constraints.md` 的「内容密度纪律」（定性要求）。
>
> ⚠️ 下列数值是**全书统计目标**，不是逐章硬门槛：落在合理区间即可。
> **严禁为了达标而注水，也严禁为了达标而截断**。

## 每章目标

1. **单章有效字数**：常规章（normal）≥ 1400；climax/finale（高潮/收束）≥ 1600——
   这两类章信息密度最高，写薄了等于白给；过渡章（transition）可短于 1400，但须至少一处实质变化。
   总体宜落在 1400–2600。
2. **有效对话（成对引号包裹）≥ 25 句**。对话必须推进情节、揭示人物或制造冲突；
   **禁止**用寒暄、应答式短句凑数（"嗯。""是吗。""好。"一律不计入有效对话）。
   ⚠️ 计划里安排对话时，**台词一律用成对中文双引号“”标注，不得用括号**——括号包裹的句子
   不计入对白统计，会让人误以为对话量达标。计划阶段的示例台词请照此写法，正文才好照做。
3. **未加引号的内心独白占比 ≤ 20%**。推理与判断必须通过**对话、动作、物证、环境反应**呈现；
   **禁止**用旁白直接讲出结论（"他意识到这一切都是阴谋"这类句子必须改成他如何发现的）。
4. 每章至少一处**信息增量**（新情报/新关系/新资源），不得整章只是重复已知状态。

## 落地要求（计划阶段必须做到，否则本文件等于没用）

**不要把上面 4 条原样抄进每章 goal** —— 那只是把数量指标转手塞进正文 prompt
（goal 会进正文），等于绕了一圈又回来了。

必须把它们**翻译成这一章的具体安排**：

- 谁在这一章想要什么、遇到什么具体阻碍；
- 结束时什么状态**不可逆地**改变了（关系 / 认知 / 资源 / 风险）；
- 关键对话发生在**哪两个人**之间、围绕**什么分歧**展开；
- 结尾停在哪个**具体画面或动作**上。

自检：如果一条 goal 读起来像是"数量要求"而不是"剧情安排"，就重写它。
