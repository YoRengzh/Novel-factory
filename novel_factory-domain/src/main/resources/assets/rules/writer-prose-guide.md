# 章节行文指引

- 优先服务当前文体、本章任务和作者最新明确要求。以下原则冲突时，以具体任务、连贯性和作者明确指示为准，不机械套用。

## 一、让动作与对白承担各自的信息

- 前文已经让读者理解人物的用意时，可以直接接对方的反应或下一件事。比如角色已经开口拒绝，再说一遍“他这么做是为了拒绝”就没有新信息。
- 试探或布局时，按计划安排读者何时知道计策。局势、行动和反馈足以让读者理解时，省去抢先讲完的计策和事后对同一意思的复盘；但计策本身构成悬念、或读者知情能制造张力时，可以保留。要省的是“已经演完再讲一遍”，不是所有计策说明。
- 一段行动结束后，已经写清的得失和用意可以留给读者。人物清点物资时发现短缺，或一个判断改变了下一步打算，这些新信息要交代清楚；是否交代看它是否交付了新信息，不按“具体事务必须写、感受可以省”机械区分。章末可落在计划所需的结果、感受、新认识，也可落在未决变化、关系转折、悬念或余韵上。
## 二、保留读者需要知道的事

- 新判断、推理、情绪变化、内心取舍和首次需要交代的规则可以直接写。说清人物为什么改主意、何时放下顾虑、知道什么或误以为什么，仍然要靠恰当的叙述。
- 语气随作者要求、叙述视角、人物身份和说话对象变化。让用词、节奏和修辞服务于当下处境，保留能传达感觉、气氛或人物声音的比喻。修订时保留原有事实、行动、因果和视角。
- 场景切换可用空行。含系统面板的故事用面板交代任务、数值或警告，按剧情需要说明人与面板变化如何相互影响；无系统设定的故事不因本条添加面板。

## 三、照顾相邻几段的读感

- 推翻已有判断时，交代人物原先信什么、眼下看到了什么。直接观察到的事实可以直说，省去替读者虚设的错误猜想。
- 相邻几段都在用明喻时，留意哪一个真正写出了难以直说的质感。其余地方若原有细节更准确，用细节承接；若细节不如比喻准确，保留最准确的一处比喻，不把“换细节”当硬性改法。
- 人物赶期限、掐算时机时，准确写出影响行动的时长。普通停顿可以直接接下一句对白或下一件事。
