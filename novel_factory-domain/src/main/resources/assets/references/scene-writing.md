# 场景与感官描写

场景描写要让读者理解人物身处何地、正在做什么，以及环境怎样影响行动或体验。展示、讲述、静态描写、感官与镜头组织都可使用；取舍依据视角、空间需要、节奏和语言风格，不按感官数量、句数或模板词匹配判好坏。

## 展示而非讲述：落地判断法

“讲述”直接交代事实、结论或心理判断；“展示”提供可供读者理解的细节与过程。两者均可出现在重要场景或过渡段：关键决定可以直接写清，过场也可以留一个有意味的细节，往往混合使用更准确。

**判断依据：读者此刻需要知道什么、体验什么，当前视角能提供什么？** 不以“能否被摄像机拍到”作为合格门槛。人物的内心判断、回忆和直接情绪表达，只要符合叙事视角，也可以有效。

| 可直接讲述的信息 | 有事实依据时可展开的表现 | 选择依据 |
|-----------------|-------------------|-------------------|
| 他很紧张。 | 他担心这次答错会失去工作，因此回答前又核对了一遍资料。 | 是否需要交代紧张的原因与行动；不能无故添转杯、发抖。 |
| 她很生气。 | 她指出对方第二次失约，要求以后做不到就提前告知。 | 是否需要读者看到冲突如何发生；直接命名也可保留。 |
| 集市很热闹。 | 若场景已有摊贩吆喝和拥堵，可写它们如何妨碍人物赶路。 | 需要概括氛围，还是说明行动受阻。 |
| 他是真的怕了。 | 若人物此刻明知退路被封，可写他的判断与选择。 | 恐惧可以写成认知，不必统一换成退半步。 |

这些方向不是事实等价的替换句。扩写时只能使用已建立或与场景一致的事实，不因想“展示”就增加摔凳、物件或伤势。

- 情绪可直接命名，也可写行为、感官、对话或内心推断；是否准确比是否外显更重要。
- 时间跨度、背景或过程可用讲述压缩；需要读者细看时再展开。不存在“重要场景只能展示、过场只能讲述”的分工。

## 五感聚焦法

- 选择与行动、注意力和处境相关的感官，不规定单场景必须有几种。人物靠听辨路时声音重要；读一份文件时，视觉已可能足够。
- 气味、声音、触觉、温度等可强化体验，也可与回忆或判断关联，但并不天然胜过视觉。
- 细节应准确、有辨识度；无需每项都“独一无二”，也不为避免普通措辞增加不存在的来源。

```
概括：演武场很吵。
展开方向：若正文已交代兵刃相撞和观众起哄，可写这两种声音混在一起，使场边的交谈难以听清。
```

概括适合快速交代，展开适合当前需要听辨或交流的场面。展开增加的具体事实必须成立，不把“很吵”无依据改成战马、骡车等新内容。

## 动态化：让场景活起来

动态化适合表现变化、过程与行动中的感受，但静物不是画面感的天敌。空屋、停泊的船、静止的山景也能建立空间与氛围，不强制让每件东西动起来。

- **描写变化**：需要表现雾上升、光线推移或人群散开时，写清变化如何发生；已有静止薄雾就不必改成吞没石阶。
- **用动词交代关系**：角色踏入积水、推开门、穿过人群时，动词帮助读者跟上行动；动作和结果要符合物理条件及既有事实。
- **环境反馈是可选信息**：旧门可能响，隔音门也可能无声；人群可能注意到进入者，也可能继续做自己的事。反馈须有因果，不要求环境每次回应人物。
- **空间按行动需要交代**：追逐时需让读者知道路口、障碍和退路，室内对话可能只需座位关系。可先给关键方位，也可在行动到达时补充；避免人物临时穿墙、凭空换位，不要求开场列全地图。

## 环境烘托情绪

环境可以烘托情绪，也可以独立交代天气、生活状态、距离与观察兴趣。风景本身有审美与节奏价值，不必每次都暗示危险或替人物说心事。

- **同景异情**：人物的注意、评价与联想可以不同，但客观天气、地形不因情绪而无故改变。赴任者可能留意渡口的忙碌，逃亡者可能关心哪里能藏身。
- **用景写心**：人物观看雨中灯影时可以联系其心境，也可以只是观察景色。不要把“不写内心，只写水面”当强制改写方向。
- **主观感官**：心虚时觉得冷意格外明显，是人物的体验；需要区分主观感受与实际降温。
- **修辞的适用性**：拟人、比喻、排比可以使用。检查意象是否符合视角和语气、是否帮助理解，而非因用了修辞就删除。

## 镜头感

“镜头”是安排观察顺序的比喻，不是限定叙事只能外部观察。可在空间描写中穿插人物的判断、记忆与内心。

1. **远景定调**：需要时交代城、山、天气或整体布局；不限定一句，也可省略。
2. **中景带人**：交代人物位置与行动所需的环境关系；环境无需作出回应。
3. **特写聚焦**：放大读者此刻值得注意的细节，可能服务行动、人物、气氛、日常质感或审美，而非只准冲突与伏笔。

不必每场依次远景、中景、特写，也不规定特写数量。近写一个普通细节不等于它日后必成线索；避免处处怼近煽情，让焦点服从人物注意与当前阅读需要。

## 描写的取舍

先看整场描写的作用，再决定局部详略，不要求每段挂一条剧情线索。可能的作用包括：

- **交代行动条件**：距离、出口、障碍、物件位置和时间变化。
- **塑造人物**：呈现他注意什么、忽略什么，以及如何判断处境。
- **营造氛围**：建立紧迫、安静、陌生或日常的体验。
- **提供观察与审美**：让读者停留在风景或生活细节中，也可以形成必要的节奏缓冲。

长景物段、静态描写和概括句都可成立。不规定开场句数或连续写景上限；若信息重复、视角失焦或明显拖慢当前任务，再压缩。数字用于距离、时间、数量等准确事实时应保留，不因数字出现而判模板。

## 常见模板句病

以下是需要结合上下文检查的表达，不是禁词表。“常见”不等于“错误”，不能出现即改，更不统一换成小动作或新线索。

| 表达 | 可能的问题与保留条件 |
|--------|------|
| “阳光透过树叶洒下斑驳的光影” | 若只是重复已有光线说明，可压缩；真实场景需要这幅画面时可保留。 |
| “空气中弥漫着……的气息” | 核对气味来源与人物是否能感知，不设全篇使用次数。 |
| “他的眼中闪过一丝……之色” | 核对视角能否作此推断、判断是否准确；内心或情绪命名不因非镜头信息而失格。 |
| “仿佛整个世界都安静了下来” | 强烈主观体验可以使用；若误把嘈杂现场写成客观寂静或只是空泛造势，应澄清。 |
| 连续排比铺陈景物 | 可组织观察与节奏；只有内容重复、空间含混或不合当下语气时才需调整。 |
| “夜色如墨”“月光如水”“星光璀璨” | 可契合叙述风格；若反复替代本场所需信息，再补足或压缩。 |
| “灯火通明”“人声鼎沸”“熙熙攘攘” | 可快速概括；需要辨认路径、人物或声源时再写具体。 |
| “车水马龙”“川流不息”“络绎不绝” | 检查是否准确、是否同义堆叠，不因成语本身判错。 |
| “微风拂过”“清风徐来”“风轻轻吹过” | 可写天气与安静气氛；没有新增体验又重复前句时可删，不强制改成环境反馈。 |

## 自查清单

- [ ] 读者能否理解当前行动所需的位置、距离与空间关系？
- [ ] 展示与讲述是否准确、符合视角，有无为了展示添出新事实？
- [ ] 感官选择是否符合人物的注意与任务，而非凑齐种类？
- [ ] 静态、动态及环境反馈是否符合实际条件，没有被机械强制？
- [ ] 特写与长景物段是否契合节奏，是否把普通细节无故写成伏笔或煽情信号？
- [ ] 是否依据具体重复、含混或因果问题调整，而非匹配模板词后改写？
