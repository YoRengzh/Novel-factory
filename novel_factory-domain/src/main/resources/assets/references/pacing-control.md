# 节奏与字数控制（防灌水）

章节节奏与内容取舍的参考：检查重复、补足过程、调整详略。节奏服从作者意图与人物处境，不设事件、对白、动作或快慢章数配额；篇幅以本次交付为准。

## 灌水的定义

需要压缩的是没有新阅读功能的重复，不是没有新增情报的文字。人物思考、闲聊、等待、空间定位、情绪与后果消化都可以承担内容。

可从以下角度判断一段是否值得保留：

1. 是否帮助理解事件的前提、过程或后果。
2. 是否体现人物的声音、理解、关系或当前状态。
3. 是否提供空间、生活、氛围或节奏体验。

**可删除测试**：删后不影响因果衔接，只说明它不是因果必需段；还应检查人物和阅读体验是否受损。不要把所有能删的生活描写都改成新冲突。

## 水文的高发形态

| 形态 | 检查方向 |
|------|----------|
| 聊天重复 | 是否只重述已知结论；必要寒暄、确认和关系互动可以保留 |
| 重复危机 | 是否只换对手与地点，人物应对及后果完全相同 |
| 原地复述 | 是否反复宣布同一个判断；等待和暂时无法行动不自动算重复 |
| 心情注水 | 内心是否有处境和声音，还是事件后固定补一段感悟 |
| 流程堆叠 | 是否把已清楚的移动和操作逐步报告；缺少关键路径则应补足 |
| 疼痛重复 | 是否重抄相同体感；伤势变化与持续限制仍可写 |
| 环境重复 | 是否每次进门都重报光线、气味、质地；准确的氛围和生活描写无需全部转成线索 |
| 首尾复述 | 是否无意义地复制前章结尾，而不是接续未完成的行动 |

## 矛盾冲突急救法

拖沓时先找到重复和缺失，再判断是否需要新冲突。删去复述、补清现有因果或缩短不必要过程，常常比另造事件更有效。

若当前计划确有冲突缺口，可以检查已有的意见分歧、期限、独立角色行动或持续后果。不要为了提速临时添追兵、伤害、误会或资源损失；新增剧情须在作者规划与授权范围内。

## 快慢节奏的交替

- 连续战斗、审讯、同地生活或长期等待可以保持同一种节奏，不按固定章数插缓冲。
- 高潮后的结果和情绪需要多少篇幅，由实际后果决定；安静结尾不必加新危机。
- 快慢可以通过详略、时间跨度和叙事焦点改变，不强制换场景、人物或视角。
- 期限只有在故事确有时间压力时才使用，不为紧张感给每个目标加倒计时。

## 信息密度管理

- 本章应交付计划明确的内容，单场调查、协作、思考或生活均可成立。
- 参考模板用于检查交付缺口，不把事件数与字数均值当作写法配额。
- 新信息多少取决于读者已有知识和场景任务；技术说明与收官可以集中讲清，不能为了限额切成多次谜语。

## 压抑蓄力期的防灌水写法

可以根据已有剧情展开准备、等待、调查、关系或人物理解，不要求每章同时推进多条线。

- 支线按自身人物动机展开，不为主角暂时受挫而临时造支线。
- 威胁的推进要有实际行动或渠道，不随意切换到主角不可能知道的全知判断。
- 资源变化在影响当前选择时交代，不每次转场盘点损益。
- 持续悲伤、失败和暂时无解可以存在；不按章数强迫补偿或心态升级。

## 章末自检（防灌水清单）

- [ ] 本章实际完成了什么内容，是否与计划一致？
- [ ] 必要的过程、空间和后果有没有省略？
- [ ] 重复段落是否还有人物、情绪或生活意义？
- [ ] 详略是否符合当前事件，没有为了快慢配额制造新剧情？
- [ ] 结尾是否服从本章落点，而非固定补一段总结或新危机？

## 开篇节奏防崩盘（前 10 章专用）

开篇需要建立阅读兴趣，但不适用所有故事同一套升级、敌人阶梯和高潮章号。短篇可以很早兑现，慢热与群像也可以先建立人物和生活。

### 节奏过快的典型症状

- 关键能力或身份变化没有设定内依据，人物直接获得解题结果。
- 大量新名词接连出现，却缺少足够语境供读者理解。
- 重大立场变化只宣布结论，缺少事件或人物已有理由。
- 已建立的能力、伤势和关系在后文无解释地被忘记。

这些是因果与交付问题，不依据“第几章出现最终敌人”或升级次数直接判定。

### 前 10 章节奏基准线

| 检查角度 | 需要确认的内容 |
|---------|----------------|
| 人物与局面 | 读者能跟上当前人物在做什么，为什么值得关注 |
| 核心期待 | 已经建立的卖点、问题或关系得到适当展开 |
| 持续后果 | 新事件承接旧选择，或来自已有独立人物的行动 |
| 能力与信息 | 解题依赖已有条件，不临场发明新机制 |

这是一组观察角度，不规定前三章冲突、七至十章高潮或第十章以后才揭示世界观。

## 重大决策的内心挣扎要求

重大选择需要理由，不一定需要犹豫。人物可以迅速决定，也可以长时间思考，服从性格、知识、紧迫程度与此前积累。

- 补足人物怎样理解处境，以及为何选择当前做法；内心、对白或行动均可承载。
- 真有两难时写清两种选择的实际后果，不为了“深度”临时制造损失。
- 长期形成的信念可以直接引导行动，不强迫每次经历惯性、冲突、决断三层。
- 状态与关系变化要在后续承接，不能靠一段工整总结代替必要过程。
