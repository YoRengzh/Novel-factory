# 对话写作规范

对话写作要先看人物在具体场合想做什么、知道什么、与谁交谈，再选择直说、隐瞒、礼貌或冲突的表达。自然的对话可以顺畅、完整，也可以停顿或回避；本资料提供语气、信息传递与动作配合的检查方法，不以结巴、潜台词或小动作作为质量指标。

## 对话核心原则

### 1. 对话的交流需要

交流需要包含人物此刻的目的和整场对话的叙事作用，不要求每句话单独推进剧情。问候、确认、闲谈、重复都可能建立关系、维持礼节或让人物休息；只有在具体段落中既无交流需要、又无阅读价值的赘述才考虑删减。

| 目的 | 示例 |
|-----|------|
| **推动情节** | “我找到凶器了，在河边的草丛里。” |
| **揭示人物** | “我不信任警察，他们从来不帮我这样的人。” |
| **制造冲突** | “你答应今天交稿，现在又说没写完。” |
| **传达信息** | “炸弹将在三点引爆。” |
| **表达情感** | “你肯来，我很高兴。” |
| **维持关系** | “吃了吗？没吃就一起。” |

**闲聊的判断：**
> 甲问：“吃了吗？”
>
> 乙答：“吃了。”
>
> 甲说：“那就好。”

若只是重复已知状态，且拖慢了紧迫场景，可以压缩；若甲一直担心乙在忙碌中顾不上吃饭，这段问答便有关系意义。不因出现问候就判为无效。

### 2. 对话应该简洁

简洁是减少不必要的重复，而不是把每个人都改成命令口吻。措辞长度要看身份、关系、风险和交流任务；道歉、解释、郑重承诺、专业说明都可以需要较长表达。

| 可压缩的表达 | 一种较简洁的说法及适用处境 |
|-----|----------------|
| “我想告诉你的是，我认为我们应该立刻离开这里。” | 同伴已知危险：“我们得马上走。” |
| “我非常抱歉，但我真的不知道你刚才说的那件事的答案。” | 普通询问：“抱歉，我不知道。”；若负有告知责任，可补充如何核实。 |
| “如果你不介意的话，我能不能请你帮我把那个东西递给我？” | 一般求助：“能帮我递一下那个吗？”；正式或敏感场合可以保留更多客气。 |

不以“最短、最粗”作为统一答案。人物刻意绕远、慎重措辞或保持距离时，较长句子也可能恰当。

### 3. 完整表达与省略的选择

熟练说明、明确答复、坦诚告白都可以完整流畅；打断、迟疑、转题和暗示仅在有交流原因时使用，不为显得人类而硬塞结巴或冷场。

可能导致不完整表达的处境包括：
- 被对方打断，来不及说完。
- 担心说出某事会伤害关系或泄露受保护的信息。
- 尚未想清楚，或正在核对记忆。
- 对方已理解，双方不需要把后半句说完。

**示例（同事问起尚未获准公开的人员调整）：**
> 甲问：“下周是不是要调组？”
>
> 乙答：“我现在不能确认，等正式通知。”
>
> 甲说：“那我先照原安排准备。”

有保密原因也不必装作结巴。若人物知情且有权告知，直接回答同样自然。

## 对话格式规范

### 中文对话标点

**基础格式：**
```
“说话内容。”他说。
“说话内容？”她问。
“说话内容！”他喊道。
```

采用中文引号，句末标点放在引号内。说话标签与独立动作句要分清，全文使用一致的排版方式。

**多行对话：**
```
“第一句话，”他说，“第二句话。”

他说：“第一段内容。”

他接着说：“第二段内容。”
```

同一人长篇发言需要分段时，按作品采用的出版格式处理，并让读者知道说话人未换；不把多行拆分当成增加节奏的固定手段。

**对话动作：**
```
“说话内容。”他做了动作。
他做了动作。“说话内容。”
```

动作句不是“说、问”等发言标签，不能把未完的对白用动作句硬接成一个逗号串联句。

### 对话标签使用

**原则：**
- 能辨识说话人且不会误读时，可以省略标签。
- “说”“问”等中性标签通常足够，不必为了避免重复而强换词。
- 情绪副词可用；检查它是否准确、有必要，而非见到就换成身体动作。
- 动作、声音变化或内心判断均应来自已成立的场景和视角，不能为替换标签编造。

| 需要检查的情况 | 保留事实的处理 |
|---------|--------|
| 上文已写明愤怒，又写“你骗了我，”他愤怒地说。 | 可简为：“你骗了我。”他说。无需新增颤抖。 |
| “好的。”她同意道。 | 标签若只重复对白，可写：“好的。”她说。也可省略已明确的标签。 |
| 场景需要说明语气，但动作未交代 | 可以保留“她平静地说”等准确说明，不必补低头、握拳或眼睛发亮。 |

**标签位置：**
```
他说：“我明天回来。”
“我明天回来。”他说。
“我明天回来，”他说，“你不用等我。”
```

### 段落划分

**规则：** 通常每个说话人的对话另起一段，避免多人同段导致归属不清。对同一人的长段发言可以分段，并用必要标注保持归属清楚。

```
清楚：
“第一句。”甲说。

“第二句。”乙回答。

“第三句。”甲点头。

容易混淆：
“第一句。”甲说。“第二句。”乙回答。“第三句。”甲点头。
```

## 对话声音区分

角色声音来自长期经历、交流习惯和此刻的目标，但不要求每个人都有醒目的口头禅。相似背景的人可能说法接近，同一个人在工作、亲密关系和危险中也会调整口吻。

### 区分维度

| 维度 | 观察方向 |
|-----|------|
| **用词** | 是否熟悉专业术语；在对方面前是否需要解释或回避 |
| **句式** | 是交代流程、请求帮助、争取认同，还是试探底线 |
| **停顿** | 是核实、犹豫、被打断，还是已经准备好完整表达 |
| **语气** | 双方权力、信任、冲突程度及公开或私下场合 |
| **习惯语** | 已建立的说话习惯；不为区分人物强塞口头禅 |

### 角色声音示例

以下均是通知“下午三点开会，请带上上周的数据”。区别来自真实工作关系与场合，而非“教授、混混、内向者”的类型标签：

**课题负责人对熟悉流程的组员，当面提醒：**
> “下午三点开会，带上上周的数据。”

**协助召集的组员在熟人群里提醒，担心大家漏看通知：**
> “提醒一下，下午三点开会，别忘了带上周的数据。”

**新任助理给资深合作方发工作消息，保持礼貌：**
> “您好，下午三点开会，麻烦您带上上周的数据。”

**负责会议安排的同事发正式通知，便于转发确认：**
> “会议时间为下午三点，请携带上周的数据。”

这些说法都可用于不同性格的人；不能单凭职业决定傲慢，或单凭内向决定结巴。

### 反差型角色台词设计

人物在公开与私下场合表达不同，先说明他为什么要控制表达：维护职业形象、避免越界、保护隐私，或担心对方的反应。反差来自处境与目标变化，不把“高冷、病娇、社恐”等标签直接当台词模板。

- **表层台词**：符合已建立的交流习惯和公开场合需要。例如负责人在会上讨论进度，不等于私下也只能说短句。
- **隐藏意图的显露**：可以通过选择回答什么、主动询问什么、与已知立场的差异来表现。用词变化、句长变化、暗示都只是可选手段，直接表达也可以显露另一面。
- **反差节奏**：按信任、风险与事件发展决定何时显露、是否掩饰。人物有时会自然切换，有时会被看穿；不要求每次暴露后清嗓或转题，也不按章数分配“破绽”。

## 潜台词（Subtext）

潜台词用于表面表达与真实意图有距离的交流。先确认为什么不能或不愿直说，再决定需要隐藏多少；坦诚、准确的对白同样有力量。

### 直接 vs 潜台词

| 上下文与真实意图 | 直接表达 | 有相应动机时的间接表达 |
|-------------|---------------|---------------|
| 已因失约生气；此刻旁人在场，不愿公开争执 | “我很生气，晚点再谈。” | “这件事我们回去再说。” |
| 喜欢对方；尚不确定对方是否愿意单独相处 | “我喜欢你，想约你吃饭。” | “周末有空吗？想请你单独吃顿饭。” |
| 不信任对方提供的数据；需先核实而不当场指责 | “我还不能相信这些数据。” | “谢谢，我先和原始记录核一下。” |
| 想离开；不愿在主人面前争论聚会安排 | “我想先走了。” | “我今晚得早点回去。”（须符合人物已知安排或隐瞒动机。） |

两栏不是优劣排名。不能把原本愿意坦诚的人改成无缘由的绕话者。

### 潜台词技巧

**1. 话题转移**

对方想在开会前谈分手，人物不愿此刻谈私事：
```
“我们还要继续吗？”她问。
“先开会，晚上我会认真答你。”他说。
```
转题有原因，也给出后续安排；不必拿天气硬岔开。

**2. 反问而非回答**

被问者认为对方已经在指控，试图先弄清依据：
```
“是你删了文件？”她问。
“你为什么认定是我？”他问。
```
反问不自动证明有罪；也可以直接答“不是，我没有删除权限”，取决于他知道什么、想解决什么。

**3. 谈论其他事物**

两人久未见面，一方借共同经历试探关系是否还亲近：
```
“最近想过我吗？”她问。
“昨天路过我们以前常去的那家店。”他说。
```
上下文让联想可理解；若人物只是报告行程，这句不必被解读为想念。

**4. 沉默和动作**

道歉者刚要求立即得到原谅，对方尚不愿答复：
```
“你愿意原谅我吗？”他问。
她没有回答。
```
沉默可以就是暂不答复，无需补翻杂志、端杯子等动作。若此前有相关行为或之后有关系变化，可据此判断，而非把沉默自动编码为原谅或拒绝。

---

### 潜台词使用边界

使用边界取决于知情范围、隐瞒动机和读者此刻需要理解的内容：

- **功能性角色也有处境**：办事员、路人、传信者没有隐瞒原因时可直说；受保密约束、害怕报复或维护利益时也能合理隐瞒，不能因戏份少就剥夺其动机。
- **关键信息可以合理隐瞒**：任务、约定、危机信息通常需要清楚，但人物可能依法、依职业职责或故事既有设定不能公开，或者出于已建立的利益选择隐瞒。写清知情范围和行为因果，不另添保密制度替生硬台词找借口。
- **可解读不等于立即揭底**：读者应能理解当下交流的压力、目标或疑点，未必马上知道全部真相。后续证据与后果应能回扣，不能只靠随机答非所问制造神秘。
- **不按句式判定**：回避、双关、直答都可能合理。审核结合正文，不因缺少潜台词或出现反问就贴“AI 味”标签。

### 潜台词信息差的实战工序

需要设计隐瞒时，可先核对“人物知道什么 → 想达到什么 → 为什么不直说 → 对方会怎样理解”，再落台词。普通问答无需逐句制造信息差。

| 支点 | 适用方法 | 需要检查的问题 |
|------|-----------|--------|
| 意图分层 | 区分真实目标与公开说法 | 两者的差异是否有动机，而不是写完才补借口 |
| 错位表达 | 在回避、试探、误解时使用 | 问东答西是否仍与问题相关；有问必答并非坏写法 |
| 信息不对称 | 依据各自所知安排答复 | 错误信息的来源是否成立；共享信息也可产生冲突 |
| 动作拆台 | 用已有或可验证的行为对照承诺 | 行为是否真的矛盾，是否存在其他解释 |
| 台词减法 | 删重复解释，保留理解所需内容 | 不要为了“机锋”删掉必要的情绪说明与事实 |
| 身份口吻 | 结合经历、关系和当下处境 | 是否把身份标签当成固定句长或礼貌等级 |

- **解码体验**：间接表达应让读者有依据理解，不要求每句都多藏一层。
- **检验法**：结合前后文检查读者是否能跟上人物当下的目标。脱离正文听不懂，不足以证明写法有问题；真正阻断理解时再补必要说明。
- **比例与节奏**：不规定潜台词百分比、连续回合数或摊牌句长。高压场面也可直说，信息交接也可因保密而绕；按任务、风险、关系变化安排。
- **设定说明**：讲解、培训、询问流程时可以清楚说明设定。问题在于人物无故互讲已知内容，或说明打断了当前行动，不是“解释”本身。
- **情报交接**：允许准确问答与完整交代。只有双方确有不同知识、利益或权限时，才把信息交换写成试探或争执。

## 对话与动作结合

动作可交代行动、关系和话语是否兑现，但并非每句对白都要配动作。直接表达、声音说明、内心判断或没有附加动作都可成立。

### 同步原则

判断一致或矛盾，要看承诺的具体内容、人物权限与可验证行为，而不是靠一个小动作替台词下结论。

**共同场景：** 项目材料已齐，负责人有权签字送审，最终拨款仍须上级审批。以下两例比较同一承诺，不把到账时间误当成支持与否的唯一证据。

**一致（增强）：**
> “我支持这个项目，今天就签字送审。”负责人说。
>
> 他当天签了申请并提交，上级审批系统生成了收件回执。

**矛盾（揭示真相）：**
> “我支持这个项目，今天就签字送审。”负责人说。
>
> 但当天的系统记录显示，他主动退回了申请，并注明“暂不送审”。

第二例能验证的是行为与“今天送审”不一致，并不能据此断定他所有动机。若只是一个月拨款未到，仍可能是正常审批延误；是否伪支持需要更多证据。

### 动作打断

动作插入可以交代空间变化或调节节奏，也可以不插入。独立动作用完整句子，不冒充发言标签。

```
“我本来想告诉你。”他停下脚步，转过身。“但我想你已经知道了。”
```

停步、转身应与场景中正在行走的事实相符；若没有这个事实，不为拉长停顿临时补动作。

### 动作替代标签

已有动作可以帮助辨识说话人，不能为了避开“说”而给人物增加脾气或身体反应。

```
她把核对出的两份不同账目放到他面前。“这两个数为什么不一样？”

“我看一下。”他说。
```

这里动作服务于核账；下一句用中性标签即可。不要求一方拍案、另一方头也不抬。

## 对话场景类型

### 争吵场景

**可能的特征：**
- 围绕具体损失、责任或价值冲突争执。
- 句长、音量、打断与重复随人物习惯及压力变化。
- 可以越吵越激烈，也可以冷静争论、迅速达成处理办法。

**示例（共同负责的报告今晚要交，乙答应中午发数据，却未告知甲自己忙不过来）：**
> 甲说：“你答应中午发数据，现在都晚上了。我怎么交报告？”
>
> 乙说：“临时多了一个任务，我没做完。”
>
> 甲说：“做不完可以告诉我，为什么让我等到现在？”
>
> 乙说：“这件事是我没说清。现有的数据我先发你，缺的我今晚补。”
>
> 甲说：“先发。以后别等我来问。”

冲突与回应都有具体缘由，无需强加跑题、结巴或对仗狠话。

### 告白场景

**可能的特征：**
- 明确表达期待，或因关系风险而试探。
- 可紧张、迟疑，也可准备充分、表达流畅。
- 对方可以接受、拒绝、要求考虑；回应与双方关系相符。

**示例（两人相处半年，一方想把关系从朋友变成恋人）：**
> 他说：“这半年和你在一起，我很开心。我喜欢你，想和你交往。”
>
> 她说：“我也喜欢你。之前没说，是怕你只把我当朋友。”
>
> 他说：“那我们周末正式约一次？”
>
> 她说：“好，我来定地方。”

真诚不靠空杯、吞话或尴尬认证。若对方并无同样心意，也可以清楚拒绝，不必为保留含蓄让双方永远猜。

### 审讯场景

**可能的特征：**
- 围绕待核事实提问，问题顺序体现已有证据和调查目标。
- 双方可能信息不对称，被问者可据其知情与处境直答或回避。
- 压力和程序依据故事既有设定处理，不凭类型名称新增权限或规则。

**示例（调查人员核实当晚行踪，尚没有旁证）：**
> 调查人员问：“那天晚上你在哪里？”
>
> 他答：“在家。”
>
> 调查人员问：“有人能证明吗？”
>
> 他答：“没有，我一个人。”
>
> 调查人员问：“整个晚上都没出去？”
>
> 他答：“是的。”

顺畅直答不是低质量对白，也不能单凭停顿推定撒谎。

### 调情场景

**可能的特征：**
- 依据已有亲近程度表达好感，试探对方是否愿意继续。
- 双关、玩笑、直说均可；身体接近不是必需。
- 留意对方的接受程度；无兴趣或不适时不把拒绝当欲擒故纵。

**示例（两人已互有好感，她邀请他看演出，散场后聊起下次见面）：**
> 他说：“下次还约我吗？”
>
> 她说：“看你今晚表现。”
>
> 他说：“那我请你吃夜宵，争取一个下次。”
>
> 她说：“行，先让我看看菜单。”

玩笑围绕已经发生的邀约，自然接话即可；不需要故意没接住、结巴或冷场。

## 对话常见问题

### 避免

1. **无缘由的信息倾倒**：人物互相解释早已知道的事，却没有提醒、核对、争论或教学需要。先查交流任务，再删重复；年份、专业术语和长说明本身不构成错误。

2. **声音失去人物依据**：所有人都用同样的机锋或命令句。根据关系与目标校准，不靠方言、脏话或口头禅强行区分。

3. **礼貌分寸失准**：礼貌程度与具体场合不合。陌生人说“抱歉打扰，能否请您……”很合理；熟人也可能郑重请求，着急的人也可能保持礼貌。不能一律改粗或删道歉。

4. **交流重复而无增益**：同一轮确认反复出现，既不改变理解也不呈现关系。闲聊本身不是问题，必要时压缩的是无增益部分。

5. **观点表达缺乏处境**：人物在紧急行动中无故发表长论述，或作者让角色代言与其经历无关的观点。辩论、演说、教学可以有长段；检查是谁对谁说、为何此刻说以及对方怎样回应。

## 对话练习自查

写完后结合完整场景检查，不逐词匹配禁令：

- [ ] 人物此刻的目标、知情范围和交流处境是否清楚？
- [ ] 闲谈、重复、解释与礼貌是否在这段关系中有作用？
- [ ] 说话人是否易辨识，口吻是否符合已建立的习惯及当前场合？
- [ ] 若用了潜台词，隐瞒动机和可理解的线索是否成立？直答是否被无故改绕？
- [ ] 节奏是否适合本场景，而非为显得真实硬塞停顿或冷场？
- [ ] 动作是否已有事实支持，是否真正兑现或违背了具体承诺？
- [ ] 是否保留了人物声音与必要事实，标签、标点和分段是否清楚？
