# 文风提取编译法

从样本中观察叙述、人物声音和语言节奏，整理成有证据与适用条件的风格卡。与 corpus-distillation.md 分工：该文侧重结构，本文件侧重表达方式。统计帮助观察，不把样本偶然特征变成全书禁令；资料中的字段示意不替代实际系统 schema。

## 一、样本投喂：少量、标注、来源

- 标注作品、章节、作者、题材与希望研究的片段特征，分清原文与自行改写。
- 样本覆盖需要研究的叙事、对白和情绪场景，数量由稳定性决定，不保证几段就能代表整部作品。
- 区分叙述者与角色，以及日常、行动、高潮的不同语气。不把一段战斗的短句推广到所有场合。
- 先记录人物怎样选择信息、怎样判断、对世界有什么态度，再记录表层词句。

## 二、客观统计（可量化的硬指标）

可统计句长、段长及分布、标点频率、对白占比、词频与重复表达。明确取样范围和计数口径，跨场景比较时说明差异。

统计值是观察锚点，不是创作配额。例如样本没有破折号，只能说明这批样本未使用，不能据此编译为禁止；平均段长较短，也不能要求所有段落都短。数字本身不证明表达是否自然。

## 三、主观特征（靠 LLM 抽取，但要结构化）

可按以下维度记录有证据的特征，不为凑条数虚构规律：

| category | 观察内容 | 可执行的记录方式 |
|---|---|---|
| narrative | 视角、信息选择与判断方式 | 该视角如何区分已知事实与推测，何时直接讲述 |
| character-voice | 身份、关系与交流目的 | 同一人物在不同场合怎样调整表达，避免用职业标签代替声音 |
| language | 用词、修辞与说明习惯 | 记录实际语气及其功能，而不是规定每段句数 |
| rhythm | 详略与场景转换 | 哪些过程展开、哪些略过，节奏为何适合该处事件 |

每条可记录：
- `weight 0~1`：对特征稳定性的估计，不代表规则越高越该绝对执行。
- `rule`：明确适用的场景、方法与例外，避免“语言生动”等空话。
- `example-good`：带必要上下文的样本例证，分清原文和解释。
- `example-bad`：说明具体失准原因的对照；改写保持同一事实、动机与知识范围，不凭空增删剧情。

证据不足的类别可以标为未确定，不要求四类各有两条。尤其不要把“所有情绪都动作化”“内向者必结巴”“短句才自然”提炼成通用规律。

## 四、编译：按 weight 分档措辞

权重帮助区分稳定偏好与偶然表现，输出力度还应考虑作者授权和适用场景：

| 特征情况 | 指令方式 |
|---|---|
| 作者明确指定的视角、命名或格式 | 按当前交付约定执行 |
| 多场景都有支持的表达偏好 | 优先采用，并保留适用条件与例外 |
| 只在某类场景出现 | 仅在同类场景参考，不推广到全书 |
| 少量或相互矛盾的证据 | 不编译成约束，补样本或保留观察 |

例如“少重复解释同一判断”可以写成：“人物已得出并表达过的结论，后文没有新理解时不再复述；新的推理、直接情绪和必要解释仍可呈现。”不能把高权重改成“禁止他感到、他意识到”，也不能用微动作替掉有效心理。

## 五、反 AI 规则三段结构

- **forbidden**：只收作者明确禁用项或已有事实、权限和交付约束，不由某个标点、句式或词语自动推出绝对禁止。
- **risk**：记录需要上下文核查的重复、无证据判断、断裂动线、替情道具与故弄玄虚；机械检测按现有程序及 anti-ai-tone.md 口径执行，本文件不另造频次阈值。
- **encourage**：鼓励有来由的细节、准确人物声音、清楚空间与因果，以及符合视角的直接表达；不规定每场景感官数、动作数或对白比例。

风险条目应配具体原文与原因，不把正常修辞、数字、长段或沉默一概判罪。

## 六、按任务类型装配（同一个风格卡，不同用途不同力度）

| 任务 | 使用范围 | 保留边界 |
|---|---|---|
| 新章正文 | 与本章视角、人物和事件有关的偏好 | 不把写法示例当成额外剧情任务 |
| 续写 | 前文声音与当前持续后果 | 不为换手法改位置、伤势或能力 |
| 润色 | 有证据的表达问题 | 不增剧情、不改关系和事实 |
| 改写 | 明确授权的表达范围 | 保留事件、动机和知情来源 |
| AI 味修正 | 定位到原文的具体问题 | 修后核对事实和阅读体验，不仅检查少了几个词 |

同一风格卡不是每次整份照抄。规划场景需要人物与事件方向，不应被正文句长、对白轮次等偏好替代。

## 七、多层绑定与合并规则

全书、卷、章、人物视角或任务级的风格要求可能不同，合并以实际实现和作者明确约定为准，列出冲突来源。局部风格可以更具体，但不能覆盖事实一致性。

作者禁用项与从样本推测的倾向必须区分。不把任一低层样本偶然未出现的写法并入全书禁令；遇到互相排斥的要求，保留来源并说明冲突，不盲目叠加。

## 八、维护操作

- 新增样本后复查旧结论是否仍稳定，注明版本和来源。
- 停用或调权重按实际系统字段与实现执行，不凭教程示意发明配置操作。
- 样例发生变化时同步修改解释、适用条件和反例，不保留已不存在的证据。
- 修改资料后验证索引、内容块依赖和实际装配，再用固定任务比较生成效果；不能只看文档是否更短。

## 自检清单（编译风格卡后）

- [ ] 重要特征有原文证据及上下文，样本和作者授权分得清？
- [ ] 统计口径明确，没有把平均值或零次出现当作禁令？
- [ ] 方法有适用场景，不把某一角色或段落的写法推广到全书？
- [ ] 正反例保留同一事实、动机、能力和知识范围？
- [ ] 与现有规则的冲突已识别，没有另设机械阈值？
- [ ] 按当前任务选择必要内容，未为文风添剧情或抹掉有效心理？
