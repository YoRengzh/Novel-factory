# 对话场面范例

本范例仅供对话戏技法参考，切勿照搬姓名、桥段或具体台词。人物须依据各自掌握的信息与当下诉求交谈，允许留白沉默、认知错位与克制的内心判断；严禁使用破折号强行解释动作意图，严禁角色在交谈后做账房式的信息盘点。
## 门钥匙

林晚星在廊下脱了沾湿的鞋，赤着袜迈进门槛，反手掩上了门。江叙白正提壶斟茶，见她立在桌前未坐，便将铜壶放回了炭炉边。

“昨晚，你去过西阁。”她将半截焦黑的残纸拍在案上，“这页纸掉在门槛外。”

江叙白起身搬开靠门的木椅，让出炭炉旁的暖处，开口道：“西阁的铜锁是我换的。往后若还要去，先来我这儿取钥匙，西墙头上铺了防贼的碎瓦。”

“我在问你昨晚去那儿做什么。”

炉膛里的红炭轻轻塌落一块。他执火箸拨开壶底积灰，重新落座：“三年前那场火没烧干净，还剩小半匣旧档。我昨晚过去，是想瞧瞧东西还在不在。”

林晚星在案边坐下，指尖按住那截焦纸：“与我有关？”

“有关。”他自袖中摸出一枚黄铜钥匙，推到她手边，“里头有几页未曾烧毁，你亲自看过便知。只是卷宗上牵涉到的几个名字，我得先找当事人当面核实。”

她将铜匙拢入袖中，起身去门外穿鞋。江叙白取了油纸伞跟到门槛边，刚要递出，她却先一步握住伞柄，往廊下侧让了半步：“一道去。火燎模糊的字，你得念给我听。”
## 雨里的伞

走到单元楼下时，夜雨依旧没停。江叙白把伞柄往林晚星手里送了送，说伞明天再拿，自己顺着街沿跑回去就行。她没有接，抬眼望了望雨幕对面昏黄的路灯。

“你住四公里外，末班车早停了。”

“街角还有家便利店亮着灯，我去那儿避一阵。”

林晚星握住他的手腕把伞拉回来，两人重新拢在同一把伞下。她从包里摸出门禁卡，却没急着往门里走：“上楼等吧，雨小些再走。家里还有咖啡。”

江叙白仰头看了眼楼上还亮着灯的那扇窗：“那只马克杯洗出来了？”

“洗干净了。你上次随手搁在水槽边，我洗碗时差点碰碎。”她刷开单元门，单手撑着门扇等他，“今晚喝完自己刷。”

他收拢雨伞，在台阶外甩净水珠，迈步跟进门厅。她先走过去按亮上行电梯，又折回来替他扶住半掩的玻璃门，等他把滴水的长伞插进门边的伞桶。轿厢叮的一声停稳，两人并肩朝电梯口走去。
