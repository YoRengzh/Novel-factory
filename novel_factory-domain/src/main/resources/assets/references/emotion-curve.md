# 情绪曲线与爽点节奏

本资料把"爽点/虐点/燃点"当成**可观察的阅读体验**来诊断：读者此刻在等什么、这个等待有没有内容、结果是否回应了承诺。以下是诊断视角与可选手段，不是每章必填的配方。

## 核心：期待感是锚

读者留下来的理由，通常落在四类兴趣上：

1. **目标与选择**：人物想达成什么，眼下的办法够不够。
2. **因果未完**：一个决定已经做出，后果还没到。
3. **信息差与疑问**：读者知道的比人物多（或双方都不知道答案）。
4. **相处与观察**：生活、关系、手艺本身也构成持续兴趣。

把兴趣说清的三件事：可理解的结果、实际障碍、真实时限（只在故事确有时限时给）。障碍可以是制度、天气、犹豫，不必是具名敌人。

## 波浪式情绪曲线

有受挫与释放的写法，常见形状是：

```
抱有希望 → 发现阻碍 → 找到办法 → 结果落定 → 消化结果
```

诊断点：
- 每一轮困难是否带来新信息、新选择或关系变化？只有重复羞辱才是问题。
- 释放是否对应前文的承诺？承诺公平考核，就让判定可信；写失去，就不必用更大胜利补偿。
- 持续黑暗、缓慢哀伤、稳定日常同样成立，观察它们内部的层次即可。

**情绪记录法**（回读工具）：按章或场景记录紧张、愉悦、悲伤、兴趣四项的 1-10 主观值，并注明事件依据（"紧张 8：通道被封"）。连续高位看是否反复用同一种威胁，连续低位看是否仍有可读的细节。数值是定位线索，不是删改阈值。

## 爽点七大来源

先看人物与读者在意什么，再看结果为何值得在意：

| 来源 | 做法 | 例 |
|------|------|----|
| 获得 | 提前交代用途或情感价值，让取得过程与既有条件相连 | 修鞋匠终于拿到合手的工具，旧鞋因此能修好 |
| 变强 | 对照前后解决同一问题的方式，展示能力边界 | 从只能照图修理，到能找出图上没有的故障 |
| 认可 | 让评价有观察依据，写出关系或待遇的实际变化 | 师傅私下把钥匙交给学徒，不必全场改口 |
| 复仇 | 建立伤害、责任与行动之间的因果 | 找回证据并使责任人失去职位 |
| 翻盘 | 交代弱势、筹码与办法，使获胜可回溯 | 利用早先测过的潮汐离开包围 |
| 解谜 | 公平提供与视角相容的线索，揭晓后能解释旧场景 | 两张不同日期的收据揭出冒领者 |
| 情感 | 用相处、对话和选择呈现关系变化 | 对方记得忌口并主动说明缘由 |

多种满足可以同场存在；是否过载看它们是否争夺同一场景的注意力。

## 欲扬先抑

"立欲 → 受挫 → 应对 → 结果"是这类剧情的参考结构：

| 环节 | 回读问题 | 可用调整 |
|------|----------|----------|
| 立欲 | 读者是否理解这件事为何重要？ | 补人物与目标的联系 |
| 受挫 | 阻碍是否真的影响目标？ | 写清欠薪、期限或犹豫如何改变选择 |
| 应对 | 人物用过什么办法，条件是否支持？ | 让求助、协作、退让或反击有前因 |
| 结果 | 成功、失败或部分完成是否回答核心问题？ | 展示各自的相关后果 |

受挫时长与释放幅度不设配额；悲剧可以不补偿。

## 期待建立、叠加、兑现

**建立**：给一张能兑现的支票——可理解的结果、相关阻碍、真实节点。人物说"我一定回来"只是愿望；若叙事反复暗示必归，失约就要有可回溯的风险。

**叠加**：新目标尽量来自旧结果（赢得比赛后有资格进城）；旧线留下的知识、关系或损失可以影响新选择；阶段完成后允许休息与日常。

**兑现**：等待要有理由（调查需要证据、返乡需要路程）；结果要回应原问题，不能偷换；兑现前的变数要有前因，不能每次临时加羞辱。

## 五类情绪点

### 爽点（征服感）

| 写法 | 组织方法 |
|------|----------|
| 打脸 | 先写评价依据，再让行动改变事实；回应可以公开，也可以只发生在当事人之间 |
| 越级挑战 | 交代差距、环境与筹码，再展示策略为何有效；不临时添加金手指 |
| 身份揭露 | 让揭露解释此前疑点并改变关系，不只靠标签获得敬畏 |
| 装备或收获 | 交代用途与取得条件，在需要时发挥作用；暂存、转赠、留作纪念都可有意义 |

### 虐点（心疼感）

先写人物在意的人或生活，使损失有具体意义；伤害之后写行动、心理、关系与生活留下的痕迹。既定悲剧、无法挽回的损失可以保留，不必用后续胜利宣布伤害已抵消。

### 燃点（热血感）

热血可以来自"认清难处仍作选择"：知道可能失败，仍分配人手、找来替代材料并承担责任。能力、协作和代价先有依据，结果才有分量；也允许行动失败。

### 泪点（共情感）

日常铺垫能让离别更有分量。也可以直接写悲伤、哭喊、长段回忆或对话；不必把情绪全部替换成茶杯、扣子或短句沉默。

### 甜点（心动感）

共同经历、坦诚表达、可靠照顾和幽默相处都能成立。可参照 [style-references](genres/romance/style-references.md) 与 dialogue-writing 的潜台词章节，但不把潜台词当成唯一表达方式。

## 高频四流程

- **打脸四步**：挑衅 → 压制 → 蓄力 → 回应。评价要有依据，应对要有依据，事实要变化（例如用原始签收单澄清，接着恢复资格），不止停在对手惊呼。没有旁观者不等于无效。
- **升级可视化**：前后对照（修行前只能维持一次照明，修行后能照亮整段隧道）、参照稳定、来源可信、边界不丢。数值用于观察，不按章数补展示。
- **夺宝流水线**：识别价值 → 面对取得条件 → 获得 → 产生影响。取得方式可以是寻找、购买、继承、赠予或偶然；不强制每件宝物都引来追索。
- **高光认可**：观察事实 → 改变判断 → 改变相处。认可者基于自己能获知的事实作判断，可以是私下感谢、稳定信任或待遇变化。

## 密度与间隔

| 观察尺度 | 记录内容 | 可用判断 |
|----------|----------|----------|
| 场景或章 | 情绪变化、信息、选择、生活体验 | 当前篇幅是否使这一内容更可感 |
| 连续段 | 重复路径、等待时长、不同情绪的联系 | 重复是否有新意义，等待是否仍值得 |
| 故事弧 | 前因、核心问题、结果与余波 | 重要问题是否被回答或有意保留 |
| 卷与全书 | 体验性质、未完线索、人物状态 | 阶段变化是否符合作品目标 |

**同类事件历史记录**：记下事件的问题、办法、结果、情绪与后果。若几场都靠"遭贬低—亮底牌—众人惊叹"完成，优先变化选择与后果，也可以删重复环节。

**数据仍可观察**：对照章节评论与追读变化，定位"套路""水"出现在哪一段，再回读文本。注意样本量、题材受众与平台差异；热度下滑是调查线索，不是自动加爽的指令。

## 常见错误

| 可观察问题 | 检查方向 | 具体修正 |
|------------|----------|----------|
| 多场重复同一种羞辱或翻盘 | 是否只有名字变了 | 合并重复场，或让后一次真正改变应对 |
| 结果与前面的问题无关 | 核心等待是否被偷换 | 回到原问题，展示对应结果 |
| 收获或能力凭空出现 | 来源与边界是否有依据 | 补来源或条件，不临时加外挂 |
| 情绪只剩道具和沉默 | 是否缺人物对此事的理解 | 加入适合人物的心理、对白或叙述 |
| 危机只靠"很危险" | 风险对象与证据是否清楚 | 写出具体影响 |
| 悲剧后果被快速抹平 | 是否用一次胜利抵消所有损失 | 保留生活、心理与关系后果 |
| 同类段落反馈变差 | 样本是否可比 | 联合评论与回读定位，不直接按热度加爽点 |
