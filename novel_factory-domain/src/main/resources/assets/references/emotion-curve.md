# 情绪曲线与爽点节奏

本资料以类型小说中的情绪组织为参考，用于诊断已有剧情如何建立兴趣、维持等待并可靠回应期待，再按作品目标调整章内与跨章节奏；爽点、虐点、燃点是可选的观察维度，不是生成剧情的配方或固定进度任务。

## 核心原理：期待感是一切的锚

本节把期待感作为追读的一种诊断视角：读者可能想看目标如何实现，也可能在意人物怎样生活、关系怎样变化，或既定悲剧如何发生。

可从已有场景中辨认兴趣来源：
1. **目标与选择**：陈九想赎回母亲的银簪，读者关心他如何取得月钱、是否赶得上赎当。
2. **因果未完**：一次隐瞒改变了朋友的判断，读者等待秘密对关系的影响。
3. **信息差与疑问**：读者知道有人改过账，人物尚未发现；也可以让双方都不知道改账者是谁。
4. **相处与观察**：一家人怎样重新一起吃饭、同一条街如何过冬，本身也能成为持续兴趣。

**把兴趣说清的三个工具**：把抽象愿望落到可理解的生活结果；指出实际障碍及其影响；有真实时限时说明时限。障碍可以是制度、天气、内心犹豫，不需要具名敌人；数字与期限只在故事确有时使用。

回读时记录读者已获知的问题、重要程度、最近一次变化与当前状态。线索遗忘可能来自跨度、信息遮蔽或重复不足，是否提醒取决于阅读距离与场景需要，不按章数重提，也不限制全书线数。

先问“这一段已有的兴趣在哪里、有什么变化”；没有新承诺的章，也可以承担体验、回味、人物观察或生活连续性。

## 波浪式情绪曲线

波浪式曲线是对有明显受挫与释放的写法的参考，不是所有故事都要遵循的情绪形状。

例如，争取资格的情节可能呈现：

```
抱有希望 → 发现阻碍 → 找到办法 → 结果落定 → 消化结果
```

- **受挫是否有内容**：每一轮困难带来新信息、选择或关系变化，还是重复上一轮羞辱？重复才是优先诊断对象，不按压抑占比判定问题。
- **释放是否对应前因**：若故事承诺公平考核，最后获准参加能回应期待；若写失去资格后的生活，结果可以是损失与重新选择，不需用更大的胜利补偿。
- **曲线是否符合作品体验**：持续黑暗、缓慢哀伤、稳定日常与持续轻快都可成立。观察它们内部的层次，不为了制造波峰主动添加灾难或敌人。

### 峰谷错落模型（情绪记录法）

情绪记录法是回读已有章节、比较体验变化的参考工具，不用分数自动改大纲。

- **分开记录维度**：可按章或场景记录紧张度、愉悦度、悲伤度、兴趣强度，各用 1-10 的主观尺度，并注明评分视角。悲伤很高不等于阅读兴趣很低。
- **标注事件依据**：例如“紧张 8：通道被封；兴趣 8：人物改走旧水渠”“紧张 3：返家吃饭；兴趣 7：父女第一次谈起离别”。折线要能对应具体文本。
- **观察连续段**：高位持续时检查是否反复用同一种威胁；低位持续时检查是否仍有值得体验的细节。连续章数是定位线索，不是删改阈值。
- **峰后消化**：高潮后的休整可展示损失、关系重排或胜利余味，也可直接进入因果相连的下一场；长度由内容决定。
- **转折依据**：用消息、行动结果、记忆触发或视角转换解释情绪变化。突变可以有力，不必预留固定过渡篇幅。
- **多线比较**：观察主线与支线的情绪是否有意义地呼应或对照。它们可以同涨同跌，独立支线不需要给主角提供小峰。
- **跨卷比较**：记录高潮的性质与影响范围，不要求峰值逐卷升高。后卷的安静和解可以比前卷大战更适合结局。

## 爽点七大来源

以下七类是作品确有满足感时的辨认参考：先看人物与读者在意什么，再看结果为何值得在意，而不是给每章分配一种爽点。

| 来源 | 可用方法 | 场景示例 |
|------|----------|----------|
| 获得 | 提前交代物品的用途或情感价值，让取得过程与既有条件相连 | 修鞋匠终于拿到合手的工具，旧鞋因此能修好 |
| 变强 | 对照前后解决同一问题的方式，展示能力边界 | 从只能照图修理，到能找出图上没有的故障 |
| 认可 | 让评价有观察依据，写出关系或待遇的实际变化 | 师傅私下把钥匙交给学徒，不必全场改口 |
| 复仇 | 建立伤害、责任与行动之间的因果，让结果回应人物的追索 | 找回证据并使责任人失去职位，或秘密完成报复 |
| 翻盘 | 交代弱势、筹码与办法，使获胜可回溯 | 利用早先测过的潮汐离开包围，不靠敌人突然变笨 |
| 解谜 | 公平提供与视角相容的线索，揭晓后能解释旧场景 | 两张不同日期的收据揭出冒领者 |
| 情感 | 用相处、对话和选择呈现关系变化，也可呈现稳定互信 | 对方记得忌口并主动说明缘由，关系不必升档 |

多种满足可以同时存在；是否过载，看它们是否争夺同一场景的注意力，而非按种类数设限。

## 欲扬先抑循环

“立欲 → 受挫 → 释放”是欲扬先抑类剧情的参考结构，用来核对已有转折，不要求全书重复这个循环。

| 环节 | 回读问题 | 可用调整 |
|------|----------|----------|
| 立欲 | 读者是否理解这件事为何重要？ | 补充人物与目标的联系，如旧簪是母亲留下的唯一信物 |
| 受挫 | 阻碍是否真的影响目标？ | 写清欠薪、当铺期限或人物犹豫如何改变选择 |
| 应对 | 人物用过什么办法，条件是否支持？ | 让求助、协作、退让或反击有前因；不把独力解决当成唯一主动性 |
| 结果 | 成功、失败或部分完成是否回答了前面的核心问题？ | 展示赎回、未能赎回或决定放手各自的相关后果 |
| 等待过程 | 长段落是否只是复述同一困境？ | 保留调查、关系变化、认知改变等有内容的等待，压缩无差别重复 |

受挫时长和释放幅度不设配额。悲剧可以不补偿，黑暗剧情可以保留困局；需要检查的是结果有没有因果、情绪有没有得到呈现，而不是是否加倍奉还或立刻开下一笔仇账。

## 期待感管理：建立、叠加、兑现

本节是对已有叙事承诺的管理参考，帮助区分“结果值得等待”与“强制人物获胜”。

### 期待建立（给一张能兑现的支票）

“支票”比喻适合检查作品已明确许诺的体验，不意味着每个愿望都保证成功。

- **可理解的结果**：用演武台资格、失物归还、一次坦诚谈话等说明目标的意义，也可用人物观察与叙述建立开放兴趣。
- **相关阻碍**：说明规则如何限制行动。路断了、证件缺失、无法开口，都比空泛的“困难重重”更便于读者等待后续。
- **真实节点**：有赎当期限、汛期或见面日时写清；没有期限，不临时添加倒计时。
- **长线中间变化**：根据已有因果辨认可见步骤，如核实账目、得到证词、改变判断；步骤数量不预设。
- **私下也能成立**：读者看见人物取回钥匙、悄悄护住某人，就能感知结果。只有名誉争议本身需要公开解决时，才考虑公开场合。
- **区分愿望与保证**：人物说“我一定回来”可以是愿望；若叙事持续提供必归的确定性暗示，失约需要前面可回溯的风险与后果，不能用“现实残酷”替代铺垫。

### 期待叠加（目标套娃逐层加码）

目标套娃是连续成长型故事的参考，不限制独立支线、阶段结束或稳定生活。

- **因果咬合**：检查新目标是否来自旧结果。赢得比赛后有资格进城，是自然延伸；想转向照顾家人，也可以由比赛的代价引出。
- **沿用收获**：旧线留下的知识、人际关系或损失，可以影响新选择；不要求新目标更难、更危险或观众更多。
- **让阶段结束完整**：达成目标后允许休息、庆祝与日常，不必当章暴露下一层敌人。
- **独立线保留自身意义**：配角探亲可以不服务晋级主线，读者已建立的关注仍应在该支线内得到回应。
- **提醒靠关联**：某张旧票据重新影响办事时自然带回长线，比定时让旁人复述目标更有效。
- **收束看状态**：临近结局检查哪些问题仍重要、哪些已结束或有意开放，避免仓促添题；不按剩余章数限制目标层数。

### 期待兑现（拖到极限但不越线）

延迟兑现是悬念型写法的参考，诊断重点是等待是否有内容、结果是否可靠，而不是拖到指定章或读者极限。

- **等待有理由**：调查需要证据，返乡需要旅程；若答案已能给出却反复被无关插曲打断，可压缩延迟。
- **结果回应核心**：承诺解释失踪原因，就交代能解释线索的原因；承诺一次公平比赛，就让规则与判定可信。回应可以是失败，但不能偷换问题。
- **不机械加价**：兑现前的变数需有前因，不能每次都临时加羞辱或新门槛。
- **断章有选择**：决定之前、结果之后的余波、安静的完成都能作章末。按场景重心选择，不反复截断同一动作。
- **可追踪记录**：登记提出位置、读者已知证据、最近变化、结果及仍未处理的相关后果。预计回应位置可随剧情调整，不设卷末清账比例。
- **开放也有边界**：开放结局可不回答未来，却应让当前选择与代价可理解；既定悲剧不需要改写成守护成功或幸福结局。

## 五类情绪点的配方

以下“配方”只是五类情绪场景的分析参考，用来找出文本中情感成立的原因，不是必须补齐的步骤。

### 爽点（征服感）

征服感是部分爽点的参考方向，获得安稳、解决小事与秘密胜利也能带来满足。

| 写法 | 可用组织方法 |
|------|--------------|
| 打脸 | 若题材确有评价冲突，先写评价依据，再让行动改变事实；回应可以公开，也可以只发生在当事人之间 |
| 越级挑战 | 若能力体系允许，交代差距、环境与筹码，再展示策略为何有效；不临时添加金手指 |
| 身份揭露 | 让揭露解释此前疑点并改变关系，而不是只靠身份标签获得全员敬畏 |
| 装备或收获 | 交代用途与取得条件，在剧情需要时发挥作用；暂存、转赠、留作纪念都可有意义 |

### 虐点（心疼感）

心疼感的建立可参考“理解人物 → 看见伤害 → 看见影响”，不要求虐前给糖、虐后补偿。

先写人物在意的人或生活，使损失有具体意义；伤害之后写行动、心理、关系与生活留下的痕迹。例如失业后仍把闹钟调到原来的时间，可以与“他害怕家人发现”这样的明确心理叙述并用。既定悲剧、无法挽回的损失和亲人受害可以保留，避免用后续胜利把伤害当作已经抵消。

### 燃点（热血感）

热血场景可参考“认清难处仍作选择”，不限定为绝境爆发或武力取胜。

人物知道修堤可能失败，仍分配人手、找来替代材料并承担责任；热血来自价值选择与实际行动。能力、协作和代价先有依据，结果才有分量，也允许行动失败。

### 泪点（共情感）

共情场景可参考具体经历与人物解释共同承载情感，不把死亡、离别或小道具当成泪点必备件。

日常铺垫能让离别更有分量：此前每周一起读信，分开后只剩一人读到熟悉的落款。也可以直接写悲伤、哭喊、长段回忆或对话；选择取决于人物与叙述声音，不必把情绪全部替换成茶杯、扣子、喉结或短句沉默。

### 甜点（心动感）

甜点可参考关系双方如何感知彼此，不把克制或禁止写“心动”当成统一风格。

共同经历、坦诚表达、可靠照顾和幽默相处都能成立。例如一方说明自己为何一直等晚班车，另一方承认早已发现；动作、对白与明确的心理描写可以结合。若需扩展，可参照 [style-references](genres/romance/style-references.md) 与 dialogue-writing 的潜台词章节，但不把潜台词当成唯一表达方式。

## 高频爽点四流程

四种流程是相应类型情节的参考，回读时只检查作品已有的打脸、升级、夺宝或认可场景，不补造这些任务。

### 打脸四步闭环

“挑衅 → 压制 → 蓄力 → 回应”是部分打脸戏的参考路径，不要求压制时长、观众在场或规模递进。

- **评价有依据**：对方因旧成绩、身份偏见或错误消息低估人物，避免集体降智。
- **应对有依据**：人物先前掌握的证据、技术或协作者参与回应，不为凑蓄力而故意拖延现成办法。
- **事实有变化**：例如被指冒领后用原始签收单澄清，接着恢复领取资格；不止停在对手惊呼。
- **场合与争议匹配**：公开谣言可以公开澄清，密室谈判可以私下赢。没有旁观者不等于无效。
- **观察重复路径**：若连续出现“贬低—露底牌—惊叹”，考虑改变问题、选择或后果，不默认换更强敌人。

### 升级可视化

升级可视化是已有成长或能力体系的参考，不要求固定频率升级或升级后立即挑战旧对手。

- **前后对照**：修行前只能维持一次照明，修行后能照亮整段隧道；写清作用范围比只报等级更直观。
- **参照稳定**：同一种测试条件可帮助比较，若参照条件变了就说明差异。
- **来源可信**：训练、天赋、资源、休养或体系规定的自然成长，都依已有设定解释，不额外制造冒险成本。
- **边界不丢**：力量增加不代表经验、抗性与战术同时增加；仍输给旧对手可以有合理原因。
- **数值观察**：记录已有提升及展示，检查是否重复报数、能力通胀或规则前后矛盾，不按章数补展示。

### 夺宝流水线

“识别价值 → 面对取得条件 → 获得 → 产生影响”是已有夺宝线的参考，不要求争抢、当章使用或必遭觊觎。

- **价值可知**：展示实际用途、人物需求或可靠鉴定；价值不必靠众人竞价证明。
- **取得合因果**：寻找、购买、继承、赠予或偶然捡到均可，检查来源与条件是否可信，而不是凡收获都设机关。
- **用途随需求展开**：药材可以留待病发，信物可以直到见面才使用；回读时检查读者是否理解暂存的原因。
- **后果相关**：易辨认的宝物可能引来追索，隐秘所得可能只改善人物生活，不强制生成下一轮争夺。

### 高光认可

高光认可可参考“观察事实 → 改变判断 → 改变相处”，不要求先狠踩、公开证明或逐层震惊。

让认可者基于自己能获知的事实作判断。例如同事连续几次看到可靠交接，终于愿意把复杂工作交给新人。认可可以是私下感谢、稳定信任或待遇变化；不同人物的反应依利益与性格而异。新环境不必重置为全员轻视，也不要求权威在卷末压轴。

## 复仇线倒计时

倒计时与仇账是部分复仇叙事的参考，只有既有情节确有时限或清算结构时才使用。

- **动机具体**：交代伤害与人物追索的联系，伤害可以是诬告、剥夺机会或背叛，不必开篇制造亲人死亡。
- **责任有证据**：区分实施者、指使者、知情者与无关者；人物可以误判，但叙事应让误判与证据状态可辨。
- **路径由条件决定**：调查、诉讼、秘密行动、放弃报复或直接对核心行动，依资源与伦理选择展开，不设每卷清一名爪牙的任务。
- **结果可理解**：秘密报复同样能回应期待，前提是读者理解谁采取了行动、结果如何改变处境；意外死亡也可保留，但应呈现它对复仇目标的影响。
- **长线保持关联**：通过证词变化、旧伤影响、相关消息或人物选择维持关注，不必定期插入仇人作恶戏。
- **余波不规定方向**：完成、失败或中止复仇后，可以走向新生、空虚、继续黑暗或开放未来；不强制转向守护结局。

## 密度与间隔

密度与间隔是观察已有阅读体验的参考，不规定每章必爽、固定章距的小高潮或卷末大爆。

| 观察尺度 | 记录内容 | 可用判断 |
|----------|----------|----------|
| 场景或章 | 情绪变化、信息、选择、生活体验 | 当前篇幅是否使这一内容更可感，而非只拖长 |
| 连续段 | 重复路径、等待时长、不同情绪的联系 | 重复是否有新意义，等待是否仍值得 |
| 故事弧 | 前因、核心问题、结果与余波 | 重要问题是否被回答或有意保留 |
| 卷与全书 | 体验性质、未完线索、人物状态 | 阶段变化是否符合作品目标，不比较强弱档位 |

**同类事件历史记录**：记下事件的问题、办法、结果、情绪与相关后果。若几场都靠“遭贬低—亮底牌—众人惊叹”完成，优先变化选择与后果，也可以删去重复环节、拉开距离或让人物不再参与该争议。

**变化不等于升级**：智取、协作、坦诚、失败后调整或维持已有生活，都可改变体验。无需全书凑齐爽点种类，也不要求对手、赌注和场面越换越大。

**数据仍可观察**：对照章节评论、追读变化与同类段落反馈，定位“套路”“水”等评价出现在哪一段，再回读具体文本。注意样本量、题材受众、发布时间与平台变化；热度下滑是调查线索，不是自动加爽、换类型或加伤亡的指令。

## 虐与爽配比

配比是检查以受挫后满足为卖点的写法的参考，不把伤害视为必获补偿的投资，也不为悲剧设幸福门槛。

- **伤害有叙事依据**：看它是否来自既有冲突、环境或人物选择，是否展现了被伤害者的真实处境，而非只给主角攒怒气。
- **影响不被抹平**：亲人可以受害，尊严可以遭损；后续写清现实与心理后果，不靠一次胜利宣布伤害已抵消。
- **承诺与回应匹配**：若作品明确承诺追责，检查责任与处理结果；若写无法挽回的悲剧，则检查失去后的生活与认知是否成立。
- **表达有多种出口**：哭泣、争执、求助、叙述反思、继续生活或无法言说都可承载情绪，不强迫当章立誓反击。
- **误会看信息条件**：检查人物为何不能沟通、为何误判。轻易可解却反复拖延会削弱可信度，但复杂误会本身不是禁用题材。
- **结局遵循既定方向**：幸福、悲剧、黑暗或开放结局均可，不添加亲人无损、逐项补偿或必须守护成功的条件。

## 慢热题材的替代期待源

替代期待源是慢热作品的兴趣诊断参考，不要求每章微推进、每卷关系质变或前三章给期限。

- **稳定生活的差异**：固定场景中观察季节、手艺、相处与身体状态。例如同一家早餐铺连续营业，人物点单变化能让读者读懂熟悉感。
- **人物观察**：让视角注意有选择、有解释；叙述者对一条街的记忆可以建立兴趣，不必立即转成事件钩子。
- **关系持续性**：写已有互信如何在不同事情中体现，也可以长期维持朋友关系，不把每次相处转成升温。
- **缓慢信息积累**：若确有谜团，用新增证据或重新解释旧细节维持关注；没有谜团则不补造。
- **回读篇幅作用**：相似日常若展示新的层次就保留；若只是重复介绍已知事实，可合并。慢热与配角视角都可以成为开篇方式。

## 悬念与期待感的配合

悬念与期待的区分是理解读者问题的参考，两者可以重合、同章回应，也可只有其一。

- **辨认疑问**：“是谁改账”偏向答案未知，“他拿到证据后会怎么做”偏向行为等待，同一条线可以同时承担两种兴趣。
- **选择信息方式**：读者与人物都未知适合解谜；读者已知而人物未知适合担忧。依视角处理，不为了藏答案删掉人物本应呈现的关键事实。
- **揭晓产生影响**：答案改变判断、行动或关系时，写出相关联系；也允许答案只结束一段观察，不强制接新谜。
- **同场回应**：谜底与人物抉择可以汇聚于一场，检查是否彼此增益，而非规定错峰。
- **追问记录**：在阶段回读中记录读者仍可能关心什么、依据在哪里、作品准备回答或开放什么；不限制主副线数量与首章挂牌时间。

## 打脸场观众预设

观众设计只是已有公开打脸或名誉争议场景的参考，不要求其他胜利当众发生。

- **到场有路径**：说明谁因值班、考核或当事关系在场，避免需要惊呼时突然出现。
- **见证有边界**：旁观者只能判断自己看到或可靠获知的事实；不同位置的人可以误解结果。
- **反应有差异**：支持者可能松口气，利益受损者可能继续抵赖，权威可能只关心规则，不必全员惊叹。
- **传播有渠道**：若名誉变化依赖传播，写清消息经谁、如何传出；不要求多个走样版本，也不为传播临时加人。
- **不适用就保留秘密**：密室胜利、匿名保护与不求认可的选择，可以只让读者知道结果。

## 配角高光章

配角高光的组织可参考其自身目标与读者关注，不把配角视为限时授权，也不要求成果归主角。

- **铺垫能力与愿望**：此前的行动、叙述或关系让读者理解这次选择；铺垫次数由需要决定。
- **保留独立价值**：配角完成返乡、和解或救援，可以形成多章独立支线，不必兑换成主角资源。
- **视角清楚**：主角不在场时，用配角所知组织行动；不强制补主角牵挂或章末回归。
- **行动有条件**：成果属于实际行动者，协作中说明各人的贡献，不把关键一击硬留给主角。
- **后果由故事决定**：高光可以无伤完成，也可付出重大代价或死亡；若有后果就持续呈现，不设重伤、牺牲或两卷内交代的配额。
- **篇幅看内容**：检查支线是否维持自身兴趣、与全书结构如何相处，而非用主角获益判断支线合法性。

## 感情线节奏控制

推拉循环是部分恋爱叙事的参考，不要求所有关系逐卷升档，也不限定误会数量与关系终点。

- **变化有依据**：共事、坦诚谈话、习惯积累、价值冲突与独处反思都能改变关系，不只靠生死任务或当众维护。
- **稳定也有内容**：既有伴侣如何分担家务、处理分歧或尊重彼此计划，可以持续有趣而不退回暧昧。
- **误会可解释**：信息缺口、信任经历与表达习惯共同造成误判；不要为延长推拉让人物反复忘记已沟通的事实。
- **双方有主体性**：观察各自的欲望、边界和选择，不把第三者自动当催化工具，也不要求每个节点安排一对高光。
- **主支关系可选择**：感情线可独立展开，不必挂在夺宝、大比或主线战后。
- **终点遵循作品**：相恋、分离、长久友情、悲剧与开放关系均可；检查转变的因果，不按相识到定情的档位排卷。

## 危机压迫感营造

“期限、资源、代价”是部分危机的诊断参考，不是三项齐备的公式，更不要求用死亡证明威胁。

- **风险具体**：让读者知道什么可能失去，以及为何在意。考试资格、住处、信任、秘密暴露都可以产生压力。
- **时限真实**：若潮水将封路，说明何时与依据；若风险长期存在，用不确定性、持续限制或反复选择体现，不添加虚假倒计时。
- **资源连续**：故事依赖燃料、金钱或体力时，在关键消耗与行动节点交代变化；不要求每章盘点。消耗、补充与可用量应前后自洽。
- **威胁有证据**：封路公告、试验失败、先前失去资格的案例都能证明危险，不必伤亡示范。
- **应对影响结果**：提前疏散可以无人受伤，拆除机关可以避免爆炸；避免风险是有效结果，不把每个威胁都变成必发损失。
- **压力变化有因**：封锁升级、协作争取缓冲或长期僵持均依行动展开，不设固定加码层次与喘息章距。
- **规则一致**：同类条件下的角色适用同样规则，差异需有设定与场景依据。不能因是主角就凭空免疫，也不能为压迫感任意改事实。

## 章内情绪过山车

章内过山车是高波动场景的参考，不要求每章转折、爽点释放与尾钩齐全。

可回读“进入场景时的感受 → 哪个事实或选择改变了感受 → 场景结束留下什么”。对峙可能由误判转为释然，日常章也可能始终平静，只让读者更了解人物。

- **句式服务内容**：动作密集处可用短句明确先后；心理纠葛、叙述回望与情绪宣泄可以用长句、直接表达或对白，不把短句沉默当成情绪标准。
- **留出感知结果的空间**：用对话、后续行动、心理叙述或日常恢复承接结果；篇幅由结果的意义决定，不只是为下一轮压抑蓄势。

## 常见错误

以下是回读既有文本时的诊断参考，问题在因果、兴趣或表达失效，而不在偏离固定情绪曲线。

| 可观察问题 | 检查方向 | 具体修正 |
|------------|----------|----------|
| 多场重复同一种羞辱或翻盘 | 是否只有名字变了，选择与后果没变 | 合并重复场，或让后一次真正改变人物的应对 |
| 结果与前面的问题无关 | 核心等待是否被偷换 | 回到赎当、追责、解释真相等原问题，展示对应结果 |
| 收获或能力凭空出现 | 来源与边界是否有依据 | 补来源、已有线索或条件，不临时加外挂 |
| 情绪只剩道具和沉默 | 是否缺人物对此事的理解 | 加入适合人物的明确心理、对白或叙述，不机械堆动作细节 |
| 危机只靠“很危险” | 风险对象与证据是否清楚 | 写出封路、失去资格、信任受损等具体影响 |
| 悲剧后果被快速抹平 | 是否用一次胜利抵消所有损失 | 保留相关生活、心理与关系后果 |
| 数据显示同类段落反馈变差 | 是否样本可比，文本是否确有重复 | 联合评论与回读定位原因，不直接按热度添加爽点 |

## 自查清单

以下清单用于诊断已有章节，只检查适用项，不生成新剧情任务。

- [ ] 读者可能在意什么：目标、关系、疑问、观察还是生活体验？依据在文本哪里？
- [ ] 等待期间有哪些有意义的变化或体验？是否重复了同一信息与路径？
- [ ] 结果是否回应原问题？明确承诺的体验有没有被偷换或无依据取消？
- [ ] 成功、失败、悲剧或开放结果的前因及相关后果是否可理解？
- [ ] 能力、资源、证据与角色所知是否保持事实连续，没有为情绪任意改规则？
- [ ] 公开场合、观众、升级、复仇、金手指是否本就属于此故事，而不是为清单补造？
- [ ] 日常、秘密胜利、稳定关系与独立支线是否按自身价值被判断？
- [ ] 情绪记录是否区分维度、注明事件依据，数据反馈是否经过样本与文本核对？
- [ ] 表达是否适合人物与叙述声音，保留心理、对白、叙述和细节的多种手段？
