# 内容扩充技巧

章节需要展开时，先检查缺的是哪段过程、人物理解还是空间交代，再选择补充方式。本文不新增剧情承诺，不按事件、动作或对白数量判定内容是否充足；交付范围和字数以本次任务为准。

## 1. 场景细节描写

读者跟不上行动时，补足必要的空间信息：
- 人物从哪里进入，目标在什么位置，中间有哪些遮挡或通道。
- 正在使用的物件从哪里取得，离人物有多远，能否实际够到。
- 环境是否影响当前行动，例如门打不开、路面湿滑、声音被墙挡住。

人物只是回到熟悉的房间时，可以直接写正在做的事。不必每次重报布局、光线和气味，也不为填字数加入物件特写。

## 2. 人物内心活动

按既定视角展开犹豫、回忆、情绪、推理或判断。内心活动可以直接叙述，不必转译为握杯子、整理衣服或两人争论。

- 判断所依赖的信息需要有来源。人物可以猜错，但叙述不能把无依据的猜测认证为事实。
- 迟疑、理解和后果消化本身也有阅读意义，不要求每次思考立刻产生新行动。
- 同一个结论若已说明清楚，后面只换措辞再宣布一次，可以压缩；处境变化后的重新理解可以保留。
- 不为了拉长篇幅补造过去的创伤、旧承诺或临场新能力。

## 3. 对话扩展

先确定人物此刻为何交谈，再补足必要的交流过程：
- 有人提出问题，回应与该问题的关系应清楚；暂不回答或答非所问需要交流动机。
- 语气服从身份、关系和现场压力，礼貌、直说、长回答都可以成立。
- 寒暄、重复确认、闲聊、共同思考可以体现关系和生活节奏，不因没有新情报就删除。
- 技术讨论、教学和任务交接可以讲清信息，不必故意拆成互相试探。

不为对话配额增设人物，不把独处章节改成双人争论，也不为了“像真人”统一加入结巴、口误和冷场。

## 4. 感官体验

选择人物此刻实际能感知、会注意到的内容。视觉、声音、温度、味道均可使用，不需要按场景配齐五感。

感官细节可以交代身体状态、定位环境或带出记忆；不能替代缺失的因果。例如人物因伤不能抬臂，需要接续既有伤势，而不是为了说明危险临时加一个身体反应。准确的感受可以直接写，不强制改成动作。

## 5. 次要情节线

根据已建立的人物目标和作者规划展开支线。配角可以有独立的经历，支线不必每次都让主角受益，也不要求所有线最终交汇。

- 需要插入支线时，确认当前叙事焦点与切换时机，不用小故事掩盖主线计划不足。
- 普通生活细节不是默认伏笔；明确引起期待的承诺才需要跟踪兑现。
- 不规定每章埋伏笔、每几章切回主线或支线占比。

## 6. 节奏放慢

关键操作、关系变化、等待和结果消化都可以展开。快慢服从事件与叙述意图，不必固定交替。

分解动作应帮助读者理解过程。先前没有写人物走到目标旁，就不能直接写伸手拿到；但已经清楚的日常移动不必逐步报告。不要把每次端杯、落脚、开门都拆成多个特写。

## 7. 环境烘托

环境可以支持氛围，也可以只是人物所处的日常世界。天气与心情不必一一对应，物件也不必承担象征任务。

- 年代、技术和习俗以故事背景为准，有疑点先核对，不靠堆老物件制造时代感。
- 叙述者可以简要交代背景；重要信息的详略由视角和当前场景决定。
- 同一地点再次出现时，可以写变化，也可以简短承接，不要求每次换一套感官角度。

## 扩充原则

- **补缺失内容**：补足当前事件和人物表达，而不是给已经完整的场面追加动作、反转或总结。
- **保留事实**：角色位置、持有物、能力、时间和知识不能因扩写而改变。
- **允许安静**：思考、闲谈、休息和生活描写可以承担章节内容，不必制造新冲突。
- **不凑配额**：没有统一的情节推进点、动作细节、对白句数和内心比例要求。

## 扩充优先级（内容密度不足时按此顺序补充）

以下是检查顺序，不是必须依次补齐的清单：

1. **交付缺口**：本章计划中的事件、结果和必要后果有没有实际写出来？不擅自追加新事件替代未写完的原事件。
2. **过程缺口**：关键行动的前提、路径、工具来源和结果是否连得上？
3. **人物理解**：人物为何作出当前选择、如何理解结果，是否需要内心或交流才能读懂？
4. **场景体验**：空间、生活和氛围是否充分，不把补充细节全部编成线索或情绪暗号。
5. **篇幅协调**：按本次目标检查需要展开还是收束；拿不准时明确指出计划容量与字数的冲突。

## 防注水警告

需要删改的是没有新阅读功能的重复，不是某一类表达本身：

- 同一伤势反复重写相同体感可以压缩；伤势变化和持续行动限制仍需交代。
- 已有身份、机制或判断无需在每次转场重新总结；新理解与实际状态变化可以写清。
- 新章可以接续上一章的行动，不要求时间、空间、视角必变；避免无意义地逐字复述已交付内容。
- 不为增加长度补寒暄，也不因已有寒暄就删掉人物关系。
- 多次执行同类操作可以连续呈现，不为“换写法”制造新困难、伤害或人物。
- 简洁不是省略关键过程，扩写也不是事事解释完再用一句金句复盘。

## 字数与内容密度管理规范

字数服从本次交付配置，内容是否充分通过实际阅读判断。参考均值不能替代作者的篇幅要求。

- 同一场调查、长对白、独处思考或持续行动均可成章，不按事件条数判废。
- 不规定每章至少三次推进、八个动作或二十五句对白，也不设统一对白占比和段落字数上限。
- 相邻章节可以长短不同；需要检查的是内容是否完整、节奏是否符合这段故事，而不是是否保持同一长度。
- 可删除测试只是提示：删除后不影响因果衔接，不代表没有情绪、声音、空间或生活价值。
- 若篇幅不足，先确认原计划是否需要补足过程；若篇幅过长，先检查无新功能的复述，不自动拆章或删掉有效内心。
