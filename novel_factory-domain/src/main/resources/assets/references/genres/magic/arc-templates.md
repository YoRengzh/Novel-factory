# 西幻/魔法 弧型参考

适用于剑与魔法、学院魔法、公会冒险、领主经营与魔法战争类长篇。每条弧的章数是预算示意，不是配额，节点可省略、合并或重排。

### 学徒入门弧（6-12 章）

本书确从学徒写起时，可选拆分：2-3 章处境与契机 → 3-5 章基础训练 → 2-3 章第一次施法与后果。章数是预算示意，不是配额，节点可省略、合并或重排。

- 入门写“学会了什么、还不会什么”，不写“天赋觉醒，一日千里”
- 第一次施法可借消耗、边界或失误立住规则，但不强加额外代价
- 导师可以严厉、敷衍或有私心，不必都是慈祥长者

### 学院/公会考核弧（10-18 章）

本书确有考核时，可选拆分：2-3 章规则与对手 → 4-8 章准备与试炼 → 2-3 章结果与去向。章数是预算示意，不是配额，节点可省略、合并或重排。

- 考核标准要公开，胜负可由准备、策略与临场判断解释
- 同学各有目标：奖学金、推荐、家族交代、混日子
- 结果不一定是第一名；落选也能打开别的门

### 魔法体系探索弧（10-20 章）

本书需要研究设定时，可选拆分：2-3 章异常现象 → 4-8 章查证与实验 → 2-3 章结论与影响。章数是预算示意，不是配额，节点可省略、合并或重排。

- 研究要有方法：对照、记录、复现，不靠灵光一闪
- 新发现改变旧理解时，前文的解释仍要能成立
- 知识本身会带来危险：被觊觎、被禁止、被误用

### 教会/王权冲突弧（12-20 章）

本书确有宗教或王权博弈时，可选拆分：2-3 章立场与筹码 → 4-8 章交涉或对抗 → 2-4 章结果与余波。章数是预算示意，不是配额，节点可省略、合并或重排。

- 各方都有可理解的利益与恐惧，不按信仰自动分善恶
- 神迹、圣物、封圣可以是政治资源，也可以是信仰危机
- 胜负改变制度：税、法、教区、继承权

### 禁忌与代价弧（8-15 章）

本书确写禁术或越界时，可选拆分：2-3 章诱惑与动机 → 3-6 章尝试 → 2-3 章后果。章数是预算示意，不是配额，节点可省略、合并或重排。

- 禁忌之所以是禁忌，要有历史原因与执行机制
- 代价与后果按设定落到具体的人：身体、记忆、关系、名誉
- 不强制道德说教；人物可以明知故犯
