# 科技流/黑科技 弧型参考

适用于黑科技系统流、学霸科研流、硬核科技创业、近未来技术流。核心方法论：技术体系的自洽靠"左右互搏"——反复挑刺、修补漏洞，直到自己驳不倒。与 genre-flow-tactics 配合使用。

### 第一桶金弧（5-10 章）

本书确有技术创业起步时，可选拆分：2-3 章技术雏形 → 2-4 章验证与资金 → 1-2 章初始班底。章数是预算示意，不是配额，节点可省略、合并或重排。

- 技术收入、投资、积蓄或继承资金按本书设定成立，来源与数量可追溯，不强制贫穷开局
- 起步资金在影响决策时给出可核算依据，不要求所有科研故事都写第一桶金
- 团队成员的能力、局限与动机符合既有人设，不强制人人带短板并付出损失

### 技术树攀升弧（10-20 章）

本书需要技术攻关时，可选拆分：2-3 章立项 → 4-8 章研发 → 2-4 章验证 → 1-2 章落地。章数是预算示意，不是配额，不设失败次数。

- 技术依赖、能力与边界前后一致；新增路线有学习、数据或资源来源，不临时长枝救场
- 失败发生时，保留金钱、工期与团队状态的实际影响；顺利研发也可成立
- 突破有可信训练、实验或推理依据，灵感可以突现，但不能替代验证

### 商业化/产业落地弧（10-20 章）

本书确有商业化时，可选拆分：2-3 章产品与需求 → 4-8 章客户、产能与合作 → 2-4 章运行 → 1-2 章结果。章数是预算示意，不是配额，不强制卖不动或竞争者入场。

- 客户按其成本、安全与收益判断，可以达成共识、协商或拒绝，不预设必有让步
- 模仿发生时，技术、工艺、时间与知识产权边界合理，不默认所有竞争都靠抄袭
- 产能、品控与售后在影响事件时充分呈现，不设正面展示次数

### 国家队/大厂博弈弧（8-15 章）

本书确有机构合作时，可选拆分：2-3 章合作契机 → 3-6 章权责与方向 → 2-4 章协商或交锋 → 1-2 章结果。章数是预算示意，不是配额，也允许稳定互利合作。

- 合同体现各方利益与实际权责，有吞并或控制条款时说明依据，不把每份合同写成陷阱
- 断供、专利或挖角确发生时交代原因与影响，不为自研强造卡脖子情节
- 涉及体制合作时遵循相应立项、评审与验收程序，时间尺度与资源条件可信

### 技术伦理/社会冲击弧（8-15 章）

本书确涉及技术伦理时，可选拆分：2-3 章影响 → 4-8 章利益与观点 → 2-4 章选择 → 1-2 章后果。章数是预算示意，不是配额，不强制事故或双方对立。

- 各方担忧有证据或合理推论，不把反对意见一概写成嫉妒
- 技术误用确发生时，责任、补救与后果遵循事实，不强制主角付一次道歉、赔偿或下架代价
- 主动不用技术可表现边界，也可合理使用，不设每卷选择次数

### 科研线弧（穿插型）

本书确有学术共同体时，可写会议、论文、评审与师承关系；认可、争议或平静研究按实际成果展开，不设每卷认可配额。

- 学界与产业的资源、目标和时间尺度按本书情况衔接，也可只聚焦其中一条线
- 师弟师妹有自己的选择与发展，不强制成才、离开或背叛的组合
