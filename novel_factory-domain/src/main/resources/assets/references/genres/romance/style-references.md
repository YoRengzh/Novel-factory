# 言情风格补充参考

基础风格见 assets/styles/romance.md，本文补充心动场面、甜虐组织、误会窗口与 CP 对话的具体技法，按本书关系类型、叙事阶段和作者指定契约选用，不另设优先级。

## 情感递进

- “排斥 → 好奇 → 动摇 → 确认 → 考验 → 稳固”可作一类关系曲线；重逢、友情转爱或已稳定的关系可采用不同起点与路径。
- 通过事件改变相处方式：愿意合作、主动分享、改变约定或共同承担风险；一章可推进、维持或回退，阶段长度由积累决定。
- 心动可落到注意力的变化上：认出脚步声、记住忌口、在人群中先找对方；身体感受和直接情绪词也可与具体情境配合。
- 推拉可用吸引与顾虑制造不确定感，也可写双方坦诚靠近；每次靠近或退开有可理解的理由。

## 心动瞬间的写法

- 多看的一眼、顺手递伞、记得忌口等细节可以传达心动；告白或直说爱也可成立，关键是符合人物与关系积累。
- 互动模式的转变有辨识度：从针锋相对到下意识维护，从礼貌称呼到私下暗语，让读者看见变化。
- 心动后的反常行为，如话变少、绕路或主动邀约，结合角色原有习惯使用；有些人物会更加直接，不必都表现为回避。

## 甜虐配比

- 甜与虐按本书取向组织，持续甜蜜可靠互动差异维持趣味，沉重关系可用理解、希望或生活温度形成情绪层次，不设章或弧的糖点配额。
- “铺垫情绪 → 引爆情绪 → 宣泄释放”适合需要集中爆发的冲突；释放可来自和解、真相、补偿，也可来自接受失去或重新选择。
- 糖点重在双方看见并回应彼此的需要，可是照顾、支持、默契或郑重承诺；详略与重复密度随阶段调整。
- 分手、决裂、牺牲等重大变化承接既有矛盾，后续保留影响；是否和解、以何种方式收束服从作者指定的结局契约。

## 误会的设计

- 信息差有成立原因：不在场、被蒙蔽、隐私边界或性格盲区；角色的判断依据与知识来源保持一致。
- 沟通窗口可承受外部压力：他人插手、任务冲突或证据变化使解释变难；容易说清的误会也可及时化解，把张力转向真正分歧。
- 误会时长由信息流动和关系状态决定；存续期间有新的行动、判断或影响，澄清时回答读者在意的问题。
- 和解与损害程度相称：小误解可一句解释解决，长期信任裂痕则通过沟通、边界调整与后续行动修复。

## 关系张力

- 核心 CP 可因身份、价值观或现实处境受阻，也可通过共同目标、生活安排与未来选择推动稳定关系。
- 阻力落实到选择：异地如何维系、事业如何协调、家庭压力由谁承担，使矛盾有实际内容。
- 配角感情线按与主线的关联分配篇幅，可形成照应、对照或独立支线，不以每章比例限制。
- 情敌或第三方有自己的吸引力、诉求和选择；竞争结果由关系积累与契约决定，不预设谁必然胜出。

## 对话质量

- 暧昧可借潜台词试探，也可直接表达意图；让回应改变下一步互动，而非反复绕同一个问题。
- 吵架围绕各自的立场、痛点与知识展开；人物可以有错，承担与修复方式随行为后果安排。
- 甜蜜对话可克制也可热烈，用具体的关心、共同记忆或承诺区别于通用情话。
- CP 可形成互怼、暗语、未说完的话等专属模式；后续在合适情境唤起或改变这一模式，体现关系变化。

## 常见陷阱

- 降智推剧情：用真实的信息差与利益分歧制造难题，让人物依据实际所知作判断。
- 工具人配角：按戏份呈现其自身的生活与动机，介入主线有身份和关系依据。
- 人设崩塌：感情中的反常举动有触发和铺垫，长期变化在后续选择中延续。
- 模式化关系：男弱女强、强取豪夺等标签不能替代人物塑造，双方的目标、边界与自主选择按本书契约展开。
