# 奇幻题材正文范例

仅供写作技法参考，不替代本章人物和事实。留意沈砚怎样用巡山的责任改变执事的决定，以及两人各自让步的理由。

## 领例钱的队伍

沈砚排到案前时，执事把一袋灰灵石推给了他。袋口没有扎紧，最上面那块缺了角，露出的断面满是杂色。他拈起来看了看，又放回袋里。

“这批不能养器。”沈砚道，“我上个月修了三盏巡山灯，月底得换灵芯。”

执事从册子上抬起眼。“库里只有这些。要好石头，等下一趟矿车。”

门外有人催着往前走。沈砚让开半步，把巡山灯的领用单铺到案角。执事认得那张单子，盖印的手停了下来。上次山道失了灯，巡夜的人在沟里摔断了腿，修灯的活才落到沈砚身上。

“今夜还巡不巡？”沈砚问。

“巡。”

“那我把这袋送到灯房，请值夜的人试。能用，我就领；点不着，劳烦您在单上写明缺料。”

执事瞥了一眼排队的弟子，将册子合上。旁边那个提水桶的少年往前探头，水洒在了门槛上。执事叫他退回去，等队伍重新安静，才拉开案下的匣子，取出一枚供法器使用的净灵石。

“灯修好以后，把旧灵芯交回来。”

沈砚把灰石袋推回案里，接过净灵石，在领用单上按了手印。执事捏着那张单，等印泥干后才收进册子。沈砚提起门边的灯匣，穿过排队的人，往灯房走去。
