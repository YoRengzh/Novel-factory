# 奇幻风格补充参考

基础风格见 assets/styles/fantasy.md，本文补充修炼过程、资源价值、宗门关系与异世界生活的具体处理，按本书实际设定和作者指定契约选用，不另设优先级。

## 世界构建

- 把力量规则落到生活和制度上：谁能使用、谁提供材料、施法条件如何改变交通、生产或防御。
- 用交易、礼仪、协作和冲突展示种族文化，必要背景可由旁白或熟悉当地的人简明交代。
- 新设定关联已有经验：先给用途、现象或对照，再展开名称及原理，使读者知道它与当前目标的关系。
- 力量层级的差距用作用范围、持续时间、抗性或战术选择表现；采用量化体系时沿用既定刻度。

## 修炼与境界

- 重要突破可按瓶颈 → 条件积累 → 尝试 → 验证展开；常规提升可简写，闭关时长与结果服从本书修炼机制。
- 境界变化前对照记忆前缀的【主角境界锁定】与本章计划；无获准突破事件时维持既定境界，有突破时落实条件与结果。
- 修炼场景选取有意义的变化：功法理解、身体反馈、资源选择或师友关系；概述平常训练，把篇幅留给关键尝试。
- 灵石、丹药、功法等资源有可比较的价值锚点，稀缺、地域和供求可以改变价格，但变化有原因。

## 战斗与能力描写

- 组织战斗时写清目的、位置、作用范围与应对链：抢入口、护阵眼、拖时间，比连续报招式名更能区分场面。
- 能力表现遵守 world_rules 与当前境界；越级解法来自本书已有的克制、地形、情报、协作或道具。
- 已发生的伤势、法宝损坏与消耗延续到后文；恢复按治疗、时间和能力机制处理。
- 用敌人的战术改变主角选择：快敌压缩反应时间，阵法封锁退路，诡计制造错误目标；这些是可选组织方法，不是每场必备菜单。

## 金手指运用

- 仅在本书已有金手指或系统时使用本节；将其定位为当前问题中的一种解法，而不是按章提醒存在。
- 围绕目标比较使用方案：提取何种剑意、兑换哪类资源、保留什么权限；消耗与收益遵循既定机制，取舍推动行动。
- 看似能用却未用时，可交代角色所知的障碍、替代策略或使用意愿，避免既有能力在关键困境中无故失效。
- 需要面板时让提示承载有效变化，如权限、储备或判定结果；普通播报可概述，重要数字可直接展示，形式与详略按场景选择。

## 宗门与势力互动

- 贡献点、职务、师承、名额与资源分配形成具体利益链，争执不仅是谁更强，也是谁有权分配和担责。
- 势力关系可经由任务、结盟、欠情、退出或决裂变化；身份与声望改变后，后续待遇有所承接。
- 长辈、执事、同门的职责与个人利益可以一致也可以冲突，用审批、庇护、考核或交易表现其立场。
- 对手的情报来源、权限与组织支持影响行动；落败后根据利益格局安排撤退、报复、谈判或内部问责。
- 配角的诉求落在具体关系中：争名额、保住弟子、还人情或维持中立，让合作与阻碍都能被理解。

## 氛围营造

- 用脚下地形、空气、声音、触感等角色能感知的细节建立沉浸感，选择与行动有关的重点。
- 货币、食物、交通、住宿和通信体现世界运行方式，道具既可参与情节，也可用来建立日常质感。
- 称谓、礼仪与表达方式沿用背景语体；古典、现代或混合世界各有可成立的语言习惯。
- 灵气、法宝与秘境写出作用对象和感官反馈，如剑身结霜、石壁共鸣、方向感失常，胜过空泛的强大评价。

## 常见陷阱

- 能力攀升失去张力：用任务难度、选择范围或局势变化承接成长，而非为每次胜利追加伤损。
- 设定膨胀：新概念有当下用途，并与旧规则相连；复杂信息分组呈现，简明信息可集中交代。
- 语言穿越：核对称谓与语体是否符合本书背景，允许已设定的穿越者口吻或混合文化表达。
- 换图失忆：进入秘境或新域后，旧功法、物资、人脉与名望有适用范围或转化路径，既有积累保持连续。
