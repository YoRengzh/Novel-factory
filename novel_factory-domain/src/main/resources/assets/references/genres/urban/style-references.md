# 都市重生/年代现实 风格参考

基础风格见 assets/styles 中本书已选用的风格文件，本文补充重生者的认知落差、时代生活与经营账目的具体处理，按本书设定和作者指定契约选用，不另设优先级。无超自然体系的重生/年代文，质感来自“可信的时代 + 可信的人 + 克制的爽”；节奏打法可参照 genre-flow-tactics 的【重生先知】【年代文】两节，不因此新增先知或能力设定。

## 认知落差的克制展示

重生者的“不寻常”是全书的重要资产，也是容易写得重复的部分；本节只用于本书已建立的重生或先知认知。

- 展示放在经验差异真正改变选择的场景，如避开交易风险、认出时代机会或更早处理家庭问题；出现密度随暴露程度与情节任务调整。
- 动作暗示、旁人评价和专注偏好可交替或组合使用；重复观察要增加新的依据，而非反复复述同一种惊讶。
- 旁人反应与证据强度相称：小异常可能只是多看一眼，明显超出常识时也可追问、警惕或公开质疑。
- 观察者的疑心可跨场景累积：先注意细节，再与其他经历比较，最后求证；“不像孩子”等评价落到具体观察上。
- 被问及时，主角按当前年龄、身份和已知风险选择解释或掩饰；打岔、装傻、借口与坦白均可成立，是否露拙由场景决定。

## 时代质感

- 价格、工资和票据制度符合具体年份、地区与职业；重要金额用购买力作对照，背景小额支出可简写，参考数值先核准适用范围。
- 年代实物按场景选取，如粮票、BP 机、搪瓷缸或自行车；既可参与办事、交易和人际，也可建立生活质感，不按卷凑件数。
- 手机、网络、邮寄、快递等服务的名称、普及度和使用方式与时地相符，已知事实保持一致。
- 对白按年龄、职业、地域与家庭关系取口吻，“单位上”“票子”“户口”“顶职”等词在适合的背景中使用，不让所有长辈或邻里一个腔调。
- 大事件可写家常侧面：下岗后的工资变化、邻里的传话、投资亏损；需要人物分析政策时，也可给出符合其见识的判断。

## 日常与爽点的配比

- 温情日常与搞钱、布局按因果和情绪节拍衔接；可连续推进经营，也可用家庭生活蓄力，不设固定比例或插场要求。
- 日常戏可推进关系、建立习惯、呈现时代环境或提供喘息；物件与人情需要后续使用时保留承接，而非每场强埋伏笔。
- 家人支持或反对来自自身处境：棺材本、脸面、户口、编制、对子女的担忧；情感与利益可以共同作用。

## 数字的账目感

- 经营决策受成本、回款和利润约束时，把关键口径分开说明；例如“进价八毛，卖一块五”，可再结合销量判断机会，小账本是可选的呈现方式。
- 重要进账交代资金归属与用途，存折、锁抽屉或再投资可落实钱的去向；已有流向保持一致，普通收益可汇总或略写。
- 亏损与风险按其对决策的影响写清来源、规模与责任；资金不足如何改变计划，比每笔交易都完整盘点更能体现账目感。
