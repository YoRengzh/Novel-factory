# 都市重生/年代现实 弧型参考

适用于都市重生、年代文、现实向创业/商战/家庭流等"无超自然体系"的长篇。与 genre-flow-tactics 的【重生先知】【年代文】两节配合使用：那边管节奏与雷区，这里管弧线骨架。按需组合，不必全用；每条弧的章数按你的卷长伸缩。

### 先知布局弧（8-15 章）
本书确有重生先知时，可选拆分：2-3 章确认时代/处境 → 3-5 章验证信息 → 3-5 章布局 → 1-2 章结果。章数是预算示意，不是配额，节点可省略、合并或重排；普通现实题材无需新增先知。

- 收益与疑虑按信息、操作与家庭关系成立，可以坦然成功，不强制挣得心虚
- 信息可持续有效也可因改变失效，登记实际知识边界，不要求每次变现都出现历史偏移
- 挨骂、损失或放弃仅由真实行动产生，不为布局强加代价

### 家庭守护/亲情弧（10-20 章）
本书确有家庭应对事件时，可选拆分：2-3 章征兆 → 4-8 章决策与行动 → 2-4 章事件 → 2-3 章后续关系。章数是预算示意，不是配额，不强制灾难、秘密或隔阂。

- 家人有自己的判断，可以采纳或否决，结果由行动与条件决定，不要求否决后必付代价
- 守护依信息、协作与行动成立，不用预言替代可执行过程
- 可以完整守住，也可以有损失，按实际结果保留影响，不强留一角没守住

### 时代节点弧（大事件驱动，10-18 章）
本书确涉及时代事件时，可选拆分：2-3 章背景与态度 → 5-10 章选择 → 2-4 章落定 → 1-2 章生活变化。章数是预算示意，不是配额，不强制阶层跃迁。

- 下岗、房改等事件落到相关人的工资、票证、住房与选择，时间和数据可信
- 对照家庭确存在时各有立场与结果，不为证明主角正确强造踏空者
- 先知精度遵循本书设定，普通现实人物按可获得信息判断，不预设信息差必然获利或必然失灵

### 贵人与对手弧（8-15 章）
本书确有重要关系发展时，可选拆分：2-3 章交集 → 3-6 章互动 → 2-4 章选择 → 1-2 章关系结果。章数是预算示意，不是配额，不要求小合作与摩擦交替。

- 帮助可来自利益、欣赏、亏欠或善意等可信动机，不限三选一，也不把所有善意写成交易
- 对手的行动从其立场与所知可解释，不依靠脸谱标签
- 关系弧可以改变资源、理解或生活，也可以巩固已有关系，不要求力量格局升级

### 转型/升级弧（10-20 章）
本书确需转型时，可选拆分：2-3 章动机 → 4-8 章尝试 → 3-6 章运行结果 → 1-2 章身份变化。章数是预算示意，不是配额，不强制亏损后才成功。

- 新方向有学习、经验或可信机会来源，不临时编出能力与资源
- 试错发生损失时说明金额、责任与影响，也可以顺利转型
- 成功规模与投入、机会及经营能力相称，不靠无依据一步登天

### 信任危机/身份暴露弧（8-15 章）
本书确有隐瞒与信任问题时，可选拆分：2-3 章疑问 → 3-6 章沟通或隐瞒 → 2-4 章获知 → 1-2 章关系结果。章数是预算示意，不是配额，允许主动坦白、全公开或继续保密。

- 暴露可来自选择、调查或事故，知识与线索来源可追溯
- 半暴露、全暴露与不暴露按本书契约采用，不设最佳模板
- 关系可修复、保持分歧或结束，影响由信任与回应决定，不强制留下长期浅疤
