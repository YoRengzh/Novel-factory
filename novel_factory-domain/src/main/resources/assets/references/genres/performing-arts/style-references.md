# 演艺/文娱/直播 风格参考

基础风格见 assets/styles 中本书已选用的风格文件，本文补充行业流程、镜头舞台、舆论数据、戏班文娱与合约人设的处理，按本书设定和作者指定契约选用，不另设优先级。

## 行业流程

- 试镜、定妆、进组、通告、宣传、结算各有环节；时间与档期是硬约束。
- 剧组有导演、制片、编剧、场务的权力差；改戏、加戏、删戏都牵动利益。
- 直播有平台、运营、审核与商家；推流机制、选品品控、坑位费与公会抽成直接决定行动。

## 镜头与舞台

- 拍戏写走位、机位景别切换、现场收音限制、台词节奏与对手反应，交代每次 NG 怎么微调。
- 表演的“好”要能被看见：一条过不是常态，反复重拍微调表情、语速与视线才是工作日常。
- 幕后比台前更真实：候场、补妆、盒饭、冷场。

## 戏班舞台与幕后文娱

- 传统戏班或曲艺行当写清行当规矩、唱念做打基本功磨损、班主与角儿的拆账比例，以及搭台跑码头的气候路费约束。
- 编剧、词曲、后期与综艺幕后突出版权归属、署名顺位、剪辑叙事权与宣发档期抢占。

## 舆论、人设与合约

- 热搜、通稿、剪辑与粉丝动向各自服务不同利益方，区分刷量数据与真实买单口碑；反转依赖时间线与实证，不靠单篇小作文。
- 人设是工作产品，私下与镜头前有落差；艺人同时面对家人、经纪人、公司与金主的多重期待。
- 合约有年限、分成、违约金、竞业与署名；带资进组、改剧本、换角有资本博弈逻辑。

## 常见陷阱

- 一部戏就爆红，全网零差评。
- 舆论战全靠发通稿，没有证据与程序。
- 圈内人全体恶毒或全体善良，没有具体利益。
