# 演艺/文娱/直播 弧型参考

适用于艺人成长、剧组生态、戏班曲艺、直播带货与文娱创作类长篇。每条弧的章数是预算示意，不是配额，节点可省略、合并或重排。

### 入行/试镜弧（6-12 章）

本书确从入行写起时，可选拆分：2-3 章处境与机会 → 3-6 章试镜或首播 → 2-3 章结果与后续。章数是预算示意，不是配额，节点可省略、合并或重排。

- 入行靠具体能力与运气，不靠“被星探一眼看中”
- 试镜写准备、对手、导演要求与临场调整
- 第一次机会可能带来合约，也可能带来麻烦

### 小爆/黑红弧（8-15 章）

本书确写走红时，可选拆分：2-3 章作品或事件 → 4-8 章舆论发酵 → 2-3 章应对与后果。章数是预算示意，不是配额，节点可省略、合并或重排。

- 红的方式影响后续路线：作品红、话题红、争议红
- 舆论有传播路径：剪辑、营销号、粉丝、对家
- 当事人能做的有限，选择比口号重要

### 剧组/舞台弧（10-18 章）

本书确写拍摄或演出时，可选拆分：2-3 章进组与角色 → 5-10 章拍摄/排练 → 2-3 章成片或首演。章数是预算示意，不是配额，节点可省略、合并或重排。

- 创作冲突具体：改词、抢戏、档期、预算
- 剧组人际关系影响成片质量
- 作品播出后的评价可能和拍摄时的判断不同

### 戏班搭台/打擂弧（8-15 章）

本书确写传统戏班、曲艺社或舞台驻演时，可选拆分：2-3 章接戏约与排戏 → 3-5 章抢台或救场风波 → 2-4 章唱响口碑或拆账重组。章数是预算示意，不是配额，节点可省略、合并或重排。

- 行当缺角、嗓子或筋骨受伤、班主与角儿分成不均都可以逼出救场危机
- 打擂靠实打实的板眼唱腔、身段抢戏或观众捧场，不靠同行降智使坏

### 直播冲榜/带货专场弧（6-12 章）

本书确写主播带货或赛道冲榜时，可选拆分：2-3 章选品与流量测算 → 3-5 章开播拉流或突发翻车 → 1-2 章复盘与品牌结算。章数是预算示意，不是配额，节点可省略、合并或重排。

- 坑位费、退货率、样本货不对板和投流 ROI 直接卡住后续资源
- 公会抽成与平台限流机制构成持续博弈

### 资本/合约与转型弧（8-16 章）

本书确写公司博弈或生涯转折时，可选拆分：2-3 章合约或瓶颈 → 3-6 章谈判或尝试 → 2-3 章结果或新身份。章数是预算示意，不是配额，节点可省略、合并或重排。

- 条款可核算（分成、年限、违约金、署名），各方有各自算盘
- 转型幕后、教学或退圈不等于失败，留下的人要继续面对行业竞争
