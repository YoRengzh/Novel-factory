# 探险/寻宝 弧型参考

适用于荒野探险、遗迹寻宝、极地/高原科考、航海远航与公路冒险类长篇。按本表自由组合，不必全用。每条弧的章数是预算示意，不是配额，节点可省略、合并或重排。

### 筹备组队弧（6-12 章）

本书确从筹备写起时，可选拆分：2-3 章目标与资料 → 3-6 章找人、备装备、办手续 → 2-3 章出发。章数是预算示意，不是配额，节点可省略、合并或重排。

- 组队有利益与性格冲突：谁出钱、谁负责、谁说了算
- 资料有缺口，路线只能定个大概；出发前写清风险与撤退线

### 进入无人区弧（10-18 章）

本书确写徒步进山或荒野行进时，可选拆分：2-3 章适应与初次遇阻 → 5-10 章推进与判断 → 2-3 章到达节点。章数是预算示意，不是配额，节点可省略、合并或重排。

- 每天行进面对涉水、绕路、修装备等现实阻碍；判断失误带来绕远或物资损耗，及时止损也可化险为夷

### 航海远航弧（10-18 章）

本书确写海船远航或孤岛探索时，可选拆分：2-3 章定船凑水手与补给 → 5-8 章风浪季风与舱内秩序磨合 → 2-4 章登岸、触礁危机或返航。章数是预算示意，不是配额，节点可省略、合并或重排。

- 淡水补给、坏血病或霉变口粮、船长与水手分赃比海怪更常逼出危机
- 航线受季风潮汐和补给岛屿卡死，无法随意掉头直行

### 公路多站行程弧（8-15 章）

本书确写长途自驾、车队穿越或公路旅行时，可选拆分：2-3 章启程契机与载具条件 → 4-7 章多站途经事件与车况故障 → 2-3 章抵达或分道扬镳。章数是预算示意，不是配额，节点可省略、合并或重排。

- 路过城镇的修车行、加油站与过客关系推进人物变化，一站一风土不硬塞主线反派

### 意外/发现与返程弧（6-15 章）

本书确写事故、遗迹发现或返程交付时，可选拆分：2-3 章异常征兆或目标验证 → 3-6 章自救或归途抢险 → 1-2 章处置与交付。章数是预算示意，不是配额，节点可省略、合并或重排。

- 返程在物资见底时尤为凶险；发现实物须经过验证，归属与公开牵动各方利益，结局可以是成功、部分撤回或留白放弃
