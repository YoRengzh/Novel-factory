# 无限流/副本/规则怪谈 风格参考

基础风格见 assets/styles 中本书已选用的风格文件，本文补充规则阅读、副本差异、群像后果与主世界衔接，按本书机制和作者指定契约选用，不另设优先级。无限流的质感来自“规则的严密 + 风险与后果的真实 + 主世界的牵挂”；减员是可选后果，不是必备事件。genre-flow-tactics 的【无限流】节可作节奏参考，公布比例、首本伤亡和难度阶梯不在此升级为硬契约。

## 规则的写法

- 主世界规则保留一致性，新增认知区分此前未知与真正变化；副本规则按玩家可获得的信息分步呈现，明暗比例与隐藏条数随解题需要安排。
- 规则让读者理解行为、条件与后果，例如“22:00 后不可发出声响”；规则怪谈也可使用有意歧义，含义需能从措辞、现象或证据中辨明。
- 已公布的规则在适用条件下有效，可以被触发、主动规避或作为推理依据；未触发也能限制行动，不要求全部现场演示。
- 规则间的矛盾可用真伪、适用范围或条件差异解释，线索落在可观察材料中；没有矛盾的规则体系同样可以构成副本。
- 破局可交叉查规则原文、场景细节与队友言行，检验假说；调查轮数按难度安排，决定性解法有已交代依据，既有能力按其边界参与。

## 副本的差异化

- 生存、推理、护送、扮演或限时任务可轮换，也可复用核心机制；改变目标、信息结构、协作压力或环境条件，形成不同的选择难题。
- 原创场景或既有题材都应有本书自身的任务逻辑，让地点、人物与规则相互支持，而非只换布景名称。
- 记忆点可来自独特空间、规则含义、NPC 诉求或关键抉择，不必用特殊死法建立辨识度。

## 减员与群像

- 单人、小队或大型队伍按副本需求配置，重点人物的能力、职责与私心有辨识度；新人失误的影响与行为风险相称，也可被及时纠正。
- 发生死亡或离队时交代原因及其对任务、关系和分工的影响；遗物、情报或未完成的事在有实际意义时承接，不固定复现次数。
- 猜疑可来自隐瞒、不同委托、资源冲突或误判；真实背叛与无辜解释各有证据和动机，不按卷限制次数。
- 主角依据其实际情报判断，错误可损失时间、资源、信任或任务机会，也可能导致伤亡；后果由局势决定，不强制用队友死亡支付学费。

## 主世界的牵挂

- 本书有结算或兑换时，展示影响下一步选择的得分、资源和取舍；完整清单或重点概述均可，结余、权限与道具保持连续。
- 家人、疾病、约定、自由或个人追求都可构成返回的理由；在与行动相关的节点体现牵挂，无需每个副本重复强调。
- 运营方、轮回真相等暗线仅在本书已建立时推进；道具异常、消息或离场方式可提供实证，推进时机按主线安排，不按副本间隔打卡。
