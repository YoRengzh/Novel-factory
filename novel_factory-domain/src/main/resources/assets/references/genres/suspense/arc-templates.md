# 悬疑/推理 弧型参考

以下弧型适用于悬疑、推理、刑侦、惊悚类长篇。根据具体设定自由组合，不必全部使用。

### 案件调查弧（10-15 章）
本书确有案件调查时，可选拆分：2-3 章案件/勘查 → 3-5 章排查 → 2-3 章突破 → 1-2 章解答与影响。章数是预算示意，不是配额，节点可省略、合并或重排。
- 公平推理所需线索可理解、可回溯，不以复现次数衡量公平性
- 排查可以证实、排除或修正判断，不强制每条线都打开新背景与新疑问
- 逻辑解答与情感影响的重心按作者定位安排，不设统一高下

### 真相逼近弧（8-12 章）
本书确有长线悬念时，可选拆分：2-3 章线索 → 3-5 章追查 → 2-3 章选择或结果。章数是预算示意，不是配额，不强制危险升级。
- 适用于贯穿多弧的谜团，也可在当前弧内完整解答
- 追查发生风险或损失时交代来源与影响，不要求每次接近真相都付代价
- 答案可以结束一个问题，也可以引出相关疑问，不强制谜团接力

### 追凶/潜入弧（12-18 章）
本书确有追凶或潜入时，可选拆分：2-3 章目标/计划 → 6-10 章执行 → 2-3 章结果。章数是预算示意，不是配额，不强制最终反转。
- 执行可有意外也可按计划完成，应变来自人物所知与资源，不为展示能力反复造危机
- 潜入的环境与风险按现场条件交代，不只依赖氛围词
- 对峙手段按角色能力与证据条件选择，可以武力、谈判、程序处理或不见面对决

### 审判/揭示弧（8-12 章）
本书确有审判或公开揭示时，可选拆分：2-3 章证据/准备 → 3-5 章交锋 → 1-2 章裁定。章数是预算示意，不是配额，不预设意外证据。
- 结案、定罪与公开事实遵循证据及相应程序
- 局势变化由筹码与证据引起，也允许一方持续占优，不强制轮流翻盘
- 裁定可以正义获胜、妥协或留下后果，服从已建立事实，不强造更大阴谋

### 连环案串联弧（15-20 章）
本书确有相关案件时，可选拆分：2-3 章单案 → 5-8 章关联 → 3-5 章追查 → 2-3 章解答。章数是预算示意，不是配额，关联不必指向幕后主使。
- 单案的经过与人物逻辑各自成立，不只承担送线索功能
- 关联发现按已有证据改变判断，也可以只是确认原有推测
- 确有幕后主使时，其动机与行动有依据，不在终局无理由空降

### 日常/过渡弧（4-6 章）
本书需要休整时，可写关系、心理恢复与生活常态。章数是预算示意，不是配额。
- 高压之后可以彻底放松，也可以连续行动，按局势与人物状态安排
- 日常可以独立成立，不要求暗线推进或预告下一场危机
- 大案确影响人物时保留相关变化，也允许恢复原有生活
