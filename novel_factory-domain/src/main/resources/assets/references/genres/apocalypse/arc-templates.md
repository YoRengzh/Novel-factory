# 末世/废土 弧型参考

适用于末世囤货、天灾生存、废土重建、基地建设流。核心情绪是"生存压力下的秩序与人"；最大的坑是囤货刷屏与基建流水账。与 genre-flow-tactics 的【末日求生】节配合使用。

### 灾前布局弧（8-20 章）

本书从灾前准备展开时，可选拆分：2-3 章征兆 → 5-12 章采购、体能与人际准备 → 2-4 章正常生活 → 1-2 章灾难降临。章数是预算示意，不是配额，节点可省略、合并或重排。

- 囤货写清采购、运输、存放与估算依据；清单长短按阅读需要调整，有实际限制时再展开协商，不强造邻居敌意
- 钱、空间与时间按本书条件核算；准备可以充分，也可以有缺口，不强制制造遗憾
- 确有没来得及时交代其后果，也允许灾前告别完整、物资齐备

### 灾变降临弧（5-10 章）

本书描写灾变初期时，可选拆分：2-3 章现场变化 → 2-4 章生存应对 → 2-3 章立足点确立。章数是预算示意，不是配额。

- 灾变类型与演变遵循本书设定，混合灾变有可信关联与时间次序
- 首次危机的胜负、消耗与伤亡来自现场条件，不强制付伤势、物资或他人生命的代价
- 秩序变化按灾变范围、基础设施与人物反应发生，不固定为信号、商店、人心、怪物的顺序

### 基地建设弧（10-25 章）

本书确有基地建设时，可选拆分：2-3 章落脚与防御 → 5-12 章人口、物资与制度 → 2-4 章检验 → 2-3 章调整。章数是预算示意，不是配额；检验也可来自常态运行而非大危机。

- 分配、安全与权责按规模建立；收人可以协作也可以冲突，不要求每个决定都得罪人
- 围墙、存粮、发电量等仅在影响判断时呈现，数据前后一致，不为升级刷指标
- 既有短板在相关事件中检验，不设每十章一次危机

### 人性冲突弧（穿插型）

本书确有幸存者利益冲突时，可写背叛、争夺或猜疑；互助、信任与共同生存也可独立承担主线。

- 对手行为从其目标、信息与处境推得，不预设所有抢粮者都挨过饿或叛逃者都被亏待
- 主角作出艰难选择时保留理由与影响；不要求冷血决定或驱逐弱者
- 帮人与被帮的结果依行动因果展开，不设每卷一次反噬与一次回报

### 资源远征弧（8-15 章）

本书确需远征时，可选拆分：2-3 章资源需求与情报 → 4-8 章行程与搜集 → 2-3 章结果与返程。章数是预算示意，不是配额。

- 收获与油料、弹药、时间等实际消耗可核算；伤亡不是远征必选项
- 遇见其他势力时按其生活方式与当前作用分配细节，不强制为每段旅程补新组织

### 真相/源头弧（卷级暗线）

本书确承诺灾变来源、官方态度或重建答案时，按证据与事件相关性推进，不设每卷暗线配额。

- 文件、电台或目击者是可选线索载体，信息来源可追溯
- 终局允许不给出全部真相；明确交付或留白哪些承诺，活下去本身也可成为答案
