# 历史/架空 弧型参考

适用于架空王朝、朝堂权谋、宫斗宅斗、科举仕途与历史穿越类长篇。每条弧的章数是预算示意，不是配额，节点可省略、合并或重排。

### 立足朝堂弧（8-15 章）

本书确从入仕或入京写起时，可选拆分：2-3 章身份与靠山 → 3-6 章第一件差事 → 2-3 章站稳或调整位置。章数是预算示意，不是配额，节点可省略、合并或重排。

- 立足靠一件办成的小事：核账、赈灾、断案、修渠，比空谈韬略可信
- 同僚各有派系与私利；站队可以是被迫的
- 得罪同僚常伴随实职变动、夺差或弹劾压力，也可凭实绩或靠山斡旋

### 党争/夺嫡弧（12-20 章）

本书确有储位或派系之争时，可选拆分：2-3 章格局与筹码 → 4-8 章结盟与试探 → 3-5 章交锋 → 2-3 章结果。章数是预算示意，不是配额，节点可省略、合并或重排。

- 各方的诉求可理解：出身、军功、清议、财权
- 关键节点由程序与人事决定，不靠一句“圣心难测”
- 输家要有去处：贬、囚、反、降

### 边患/战事弧（10-18 章）

本书确涉战事时，可选拆分：2-3 章边报与朝议 → 4-8 章备战或行军 → 2-4 章战与和。章数是预算示意，不是配额，节点可省略、合并或重排。

- 粮道、军饷、兵源先于战术
- 主战主和各有依据，不把一方写成蠢或坏
- 战果要回到朝堂结算：赏罚、割地、岁币

### 变法/改革弧（12-20 章）

本书确写改革时，可选拆分：2-3 章弊政与契机 → 4-8 章推行与阻力 → 2-4 章结果与反扑。章数是预算示意，不是配额，节点可省略、合并或重排。

- 改革要落到具体条款：税怎么收、谁被触动、执行成本多少
- 改革阻力往往先于收益显现，受益各方也可能因短期顾虑观望
- 结果可以部分成功，也可以人亡政息

### 翻案/身世弧（8-15 章）

本书确写旧案时，可选拆分：2-3 章疑点 → 3-6 章查证 → 2-3 章翻案与安置。章数是预算示意，不是配额，节点可省略、合并或重排。

- 旧案牵涉在位者，翻案就是政治行动
- 证据链要能过堂：人证、物证、文书、时间
- 翻成之后，活下来的人怎么安置同样重要

### 科举仕途弧（10-18 章）

本书确写科举取士时，可选拆分：2-3 章备考与资历 → 3-6 章乡试/会试考场 → 2-4 章放榜与拜谒选官。章数是预算示意，不是配额，节点可省略、合并或重排。

- 科举拼经义时文也拼路费、同乡会馆与主考风向
- 放榜后按甲第与关系网分派实缺或庶吉士，名次不自动等同实权

### 内宅/后宫博弈弧（8-15 章）

本书确写内宅掌家或后宫争宠时，可选拆分：2-3 章例银/名分争议 → 3-6 章查账或借势 → 2-3 章定规或换权。章数是预算示意，不是配额，节点可省略、合并或重排。

- 每次交锋围绕账目、礼数、子嗣或母家外援展开，保留长辈与宗族牵制
- 胜出往往落到掌印权、月例配额或位分实利变化，而非当场彻底覆灭对方
