# 武侠 弧型参考

适用于传统武侠、江湖恩怨、门派争斗与庙堂江湖交织的长篇。每条弧的章数是预算示意，不是配额，节点可省略、合并或重排。

### 入门拜师弧（6-12 章）

本书确从学艺写起时，可选拆分：2-3 章处境与机缘 → 3-5 章学艺与试手 → 2-3 章第一次独立行事。章数是预算示意，不是配额，节点可省略、合并或重排。

- 拜师要有理由：活命、报仇、求学或无处可去，不必人人天资卓绝
- 学艺写“练什么、错在哪、怎么改”，不靠一句“三年后武功大成”
- 第一次出手可以失败，失败暴露短板而不是否定人物

### 江湖行走弧（10-18 章）

本书确写游历时，可选拆分：2-3 章上路与盘缠 → 4-8 章沿途事件 → 2-3 章到埠与结果。章数是预算示意，不是配额，节点可省略、合并或重排。

- 沿途事件各有自己的因果，不必都指向主线阴谋
- 盘缠、马匹、伤势、人情是持续约束；解决一个麻烦常带来另一个
- 遇到的高手可以只是路过，不必都成为对手或师父

### 门派冲突弧（10-16 章）

本书确有门派博弈时，可选拆分：2-3 章矛盾与立场 → 3-6 章交涉或暗斗 → 3-5 章交锋 → 2-3 章结果。章数是预算示意，不是配额，节点可省略、合并或重排。

- 各派立场能独立解释，不按阵营自动分正邪
- 掌门、长老、弟子各有利益；门规可以被援引、曲解或废弃
- 胜负之外按因果承接余波：死伤、名声、产业或盟约变化，不强加额外损失

### 恩怨复仇弧（8-15 章）

本书明确写复仇时，可选拆分：2-3 章旧事与目标 → 3-5 章追查与准备 → 3-5 章对决 → 2-3 章余波。章数是预算示意，不是配额，节点可省略、合并或重排。

- 仇要具体：谁做的、为什么、证据在哪，允许认错人与报错仇
- 复仇手段受身份、武功与资源限制；借刀、诉官、私斗各有代价
- 结局可以是完成、放弃、失手或发现真相，不强制手刃

### 庙堂边关弧（10-18 章）

本书确涉官府或边事时，可选拆分：2-3 章局势与立场 → 4-8 章周旋或征战 → 2-4 章结果与去留。章数是预算示意，不是配额，节点可省略、合并或重排。

- 官场逻辑与江湖逻辑不同：文书、品级、军令、粮饷都能改变胜负
- 江湖人可以介入，但不能替代整个官僚系统
- 事后要交代立场变化：招安、隐退、被通缉或继续游走
