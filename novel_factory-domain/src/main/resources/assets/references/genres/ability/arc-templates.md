# 都市异能/觉醒 弧型参考

适用于都市异能、全民觉醒、超能力进化等"现实背景 + 个体超常"的长篇。与 genre-flow-tactics 的【都市异能】节配合：那边管爽点通道与雷区，这里管弧线骨架。每条弧的章数按卷长伸缩。

### 觉醒开局弧（5-10 章）

本书确有初次觉醒时，可选拆分：2-3 章觉醒事件（仪式/事故/契机） → 2-4 章首次尝试与理解能力 → 1-2 章相关社会回应。章数是预算示意，不是配额，节点可省略、合并或重排。

- 弱能力可以靠用法翻盘，强能力也可以可靠运用；边界与成本遵循本书设定，不为开局强加失控或代价
- 觉醒确会影响家人、机构或生活时，交代其原因与后果；秘密觉醒也可暂时维持常态
- 首次使用是否被目击取决于现场条件，不强制生成见证者

### 等级攀升弧（10-20 章）

本书采用等级成长时，可选拆分：2-3 章等级/区域信息 → 4-8 章训练、任务或排位 → 2-4 章关键验证 → 1-2 章社会位置变化。章数是预算示意，不是配额。

- 仅在既有体系采用量化与公示时沿用等级（F-SSS / 一至九阶）；隐秘或非数值能力同样可写清边界
- 社会权益确与等级绑定时交代执照、准入或法律地位，不新增制度来证明升级
- 胜负依能力、情报与现场条件展开，不要求低等级反杀与高等级碾压交替

### 能力组合/顿悟弧（6-12 章）

本书需要探索新用法时，可选拆分：2 章瓶颈 → 3-5 章合作或经历 → 1-2 章组合技成型 → 1 章验证。章数是预算示意，不是配额，也可以没有专门验证战。

- 新用法来自已有能力、学习或可信的新来源，不凭空加能力；必要时说明此前未使用的原因
- 已有克制关系和翻盘依据前后一致，不为展示组合技另造对手

### 换体系/换地图弧（10-20 章）

本书确需进入新体系时，可选拆分：2-3 章迁移原因 → 3-6 章新世界/规则入场 → 4-8 章适应 → 1-2 章新旧体系衔接。章数是预算示意，不是配额，不自动清零旧优势。

- 迁移时交代仍相关的旧目标与恩怨去向，可以已结清、继续牵连或明确留白
- 若存在等级换算，保留可理解的对应；新体系不得无依据否定旧积累
- 新人物与旧地图是否相连由已有关系决定，不强制暗线勾连

### 身份暴露/体制冲突弧（8-15 章）

本书确有隐瞒与暴露风险时，可选拆分：2-3 章暴露契机 → 3-6 章机构回应 → 2-4 章选择 → 1-2 章结果。章数是预算示意，不是配额，也允许顺利合作或彻底分离。

- 体制按本书程序、内部立场与资源行动，不一概设为反派或可靠保护者
- 暴露可来自主角选择、调查、事故或主动公开，线索与知识来源需成立
- 收编条件确与目标冲突时展开协商或拒绝，不强造一条绝不能接受的条件

### 源头之谜弧（贯穿卷级）

本书确有能力来历谜团时，按可获得证据与叙事承诺安排答案；不设每卷揭一层或答案必带新问号。

- 化验单、影像、口误等是可选载体，来源与角色所知可追溯
- 是否回答能力来历、为何选中主角及其时机服从本书承诺，允许早揭、晚揭或明确留白
