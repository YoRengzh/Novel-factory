# 都市异能/觉醒 风格参考

基础风格见 assets/styles 中本书已选用的风格文件，本文补充现实社会中的能力展示、身份制度与知情圈管理，按本书已有异能机制和作者指定契约选用，不另设优先级。现实背景 + 个体超常的质感来自能力如何改变日常选择；避免“能力展示轰炸”和“数值通胀”，同时保留既有能力的实际作用，不因此新增觉醒、等级或社会制度。

## 能力展示的节奏纪律

- 能力在改变冲突或选择时展示，战斗、救人、生活与赚钱均可成为用途；密度按剧情安排，不设每几章的次数配额。
- 旁观者的反应取决于世界常识、见识和风险：熟悉者可能习以为常，首次目睹者也可惊呼或求证，具体反应与信息强度匹配。
- 新用法可体现探索，旧用法也可体现熟练、稳定或条件变化；重复场面带来新的结果或关系影响，常规应用可以简写。
- 已建立的冷却、消耗和副作用在适用时生效，后续保留影响；没有这些限制的能力不另补惩罚，也不按卷安排“限制生效”次数。

## 等级与社会的绑定

- 本书有等级体系时沿用既定标准，当前能力与判定依据保持一致；可用数值、阶级或定性描述，没有等级制度时以作用范围与边界表达实力。
- 等级若关联执照、保险、择业、婚恋或刑责，展示当前情节所涉及的权利和义务；秘密异能或无分级社会按原有制度处理。
- 越级挑战依靠已建立的克制、信息差、地利、道具或其他机制，胜负与实际条件一致，不按卷限制次数。
- 切换体系时说明可比的能力与评判差异；存在稳定换算时给出换算，不可直接等值时保留旧能力事实并解释新标准。

## 战斗与日常的配比

- 战斗与日常按事件因果和阅读节拍衔接，可连续行动或连续生活；人际、休整与准备在需要时展开，不固定比例或插场。
- 战斗写清解法：能力作用于什么、为何有效、对手如何应对；空间、目标和既定边界共同构成攻防。
- 日常可写修东西、找猫、赚外快，也可写能力引发职业选择、法律责任或生活失衡；能力是辅助还是核心由实际作用决定。

## 秘密与人际

- 知情圈按看见、告知、调查或泄密的事实变化，家人、挚友、组织与对手不必依次解锁；谁知道什么及其来源保持连续。
- 旁人态度从自身处境出发，可能敬畏、羡慕、怀疑、利用或合作；同一群体内也有不同反应。
- 有等级制度时可从不公、特权或义务冲突塑造对手；利益、信仰、私人经历等也可成为动机，不为套用题材凭空建立等级社会。
