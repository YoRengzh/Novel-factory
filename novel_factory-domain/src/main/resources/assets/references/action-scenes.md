# 战斗与动作场面写作

本规范仅供动作戏技法参考，须严格服从当前章节的场景契约与既有战力设定。严禁使用破折号强行解释动作意图，严禁角色在战后做账房式的收获盘点。

## 动作怎样接起来

动笔前先立住空间与目标：交代清楚人物身在何处、要往哪去、当面拦路的是什么。每一次交手只写实打实的因果链条：谁先出手，对方如何招架或变招，这次碰撞又怎样改变了双方的处境与下一步选择。切忌把打斗拆成机械的固定拍数，也不必在每一招后堆砌拟声词、旁观者惊叹或总结性旁白。

关键的局势转折应当细写，重复的试探交手则一笔带过。负伤、脱手、踏空等失利必须持续制约后续动作，绝不能用一句空泛的“付出了惨重代价”轻轻揭过。删去毫无局势推进的招式罗列；句式长短与段落切分皆服务于动作呼吸，不用单字独词成段来强行制造高潮。。

## 窄桥上的交锋

木桥狭窄，仅容两人错身。赵衡背着伤者刚走到桥心，迎面而来的刀客已堵死了去路。他俯身将伤者安置在栏杆内侧，让那人抓稳望柱，随即反手抽出了背上的短棍。

刀客迎面劈落，赵衡横棍硬架，巨大的冲力让他连退两步。左脚后撤时踩翻一块翘起的朽木桥板，脚踝骤然传来一阵钻心的锐痛。他左肩猛地抵住栏杆借力稳身，双手顺势拧棍下压，引导刀锋斜滑着劈进桥板的缝隙里。趁刀客俯身拔刀的空当，赵衡腾出左手，揪住伤者后领往自己身后拖去。

木屑迸裂，长刀已被硬生生拔出。赵衡左脚不敢再吃劲，只能贴着栏杆侧身寸移，用后背挡住伤者。刀客每往前逼近一步，他便持棍横在胸前戒备，同时用棍尾沿着身后腐朽的栏杆向后探摸，震落簌簌木屑，直至棍梢触到一根半断的横木。他手腕发力将横木猛地挑向桥心，趁刀客抬腿跨障的一瞬，架起伤者退到了桥头。

岸边同伴抢上前接过伤者，赵衡右手仍死死攥着短棍。桥上的刀客在断木前收步驻足，赵衡低头试着拿左脚点地，钻心的刺痛让他眉心一紧，只得伸手扶住岸边的老树树干，没有再追上去。

## 能力与胜负

以弱胜强必须建立在已铺垫的情报、地形、默契配合或敌方能力短板之上；严禁临阵给主角凭空添置新技能，也不许让对手突然降智失常。对手应当能敏锐察觉主角的意图并做出合理反制，每一次破局手段只能解决它力所能及的局部困境。

战斗的结局可以是速胜、相持、主动退走或败北受挫，不必强求每一场都绝境翻盘。援军入场与环境突变必须前文有据，绝不为凑章节高潮而强行塞入场外变数。旁观者唯有亲自出手或切实影响战局时才写入画面，不设专门负责惊呼解说的看客席位。

## 收尾与多人场面

多人混战始终紧扣当前视角人物目力所及的战局展开；确需切换战线时，先交代清楚方位变化与在场人手。战后的包扎救治、交替撤离、拾回兵刃或排查余险皆可自然延续，并干净地收束在人物的下一项具体行动上，不在章末追加战利品清点与战力排位。
