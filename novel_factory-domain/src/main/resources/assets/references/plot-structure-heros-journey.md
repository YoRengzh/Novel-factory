# 英雄之旅（Hero's Journey）

神话学家约瑟夫·坎贝尔在《千面英雄》中归纳了 17 个阶段的"单一神话"；编剧克里斯托弗·沃格勒在《作家之旅》里把它压缩成 12 个阶段，成为写作中最常用的版本。下面的阶段名与位置以沃格勒版为准。

## 十二阶段

| 阶段 | 位置（约） | 作用 |
|------|-----------|------|
| 1. 平凡世界 | 0-10% | 主角的常态与缺口，读者建立代入 |
| 2. 冒险的召唤 | ~10% | 打破常态的事件或消息 |
| 3. 拒绝召唤 | 10-15% | 恐惧、责任或代价让主角犹豫 |
| 4. 遇见导师 | 10-20% | 获得指引、装备或一条关键信息 |
| 5. 跨越第一道门槛 | ~20% | 主动进入新世界，退路消失 |
| 6. 考验、伙伴、敌人 | 20-40% | 学习新规则，建立同盟与对立 |
| 7. 接近最深的洞穴 | 40-50% | 准备面对核心难题，压力收紧 |
| 8. 磨难 | 50-60% | 直面死亡或最大失败，旧我被打碎 |
| 9. 报酬 | 60-70% | 拿到宝物、真相或能力（常伴随代价） |
| 10. 归途 | 70-80% | 返回途中受阻，追兵或反噬到来 |
| 11. 复活 | 80-90% | 最终考验，用改变后的自己通过 |
| 12. 带着灵药归来 | 90-100% | 回到常态，带回能改变他人与世界的东西 |

## 使用要点

- 阶段是**功能位**，不是章号。可按比例折算到卷，也可以只取其中几段。
- "洞穴"是主角最怕面对的东西，不必是地点；"灵药"可以是认知、关系或代价换来的资格。
- 拒绝召唤、归途受阻这两段最容易被省略，省略后旅程会显得过于顺遂。

## 常见误用

- 把 12 阶段当检查表逐条打勾，导致每本书同一节奏。
- 主角一路被动，所有推力来自导师与反派。
