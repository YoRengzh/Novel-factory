# 情绪表达与对白

按人物已知的事实、此刻在意的事和双方的关系选择表达。情绪可以通过直述、内心判断、对白、行动、沉默或叙述节奏呈现。下面的方法用于完成已有场景的表达任务，也适用于回查改稿是否保住人物的态度。

## 先弄清情绪为什么在这里变化

- **找触发点**。确认人物刚经历了什么、知道了什么，或想起了什么。让读者看得出本次反应来自具体处境。
- **分清人物与叙述者所知**。人物可以误判、压下情绪或向对方讲明。视角人物对他人情绪的解释需要可观察的依据，并保留该有的推断语气。
- **看这段要交付什么**。角色承认失望、作出决定、重新理解一段关系，或只是在悲伤里维持日常，都可以构成有效内容。表达是否需要外化，取决于本段作用与叙述声音。

## 选择能完成任务的表达

| 表达 | 适用场景 | 如何写清 |
| --- | --- | --- |
| 情绪直述或内心想法 | 独处、坦白、回顾或情绪本身值得保留 | 把感受落到真正关心的人或事，让读者知道为什么此刻会这么想 |
| 对白 | 人物需要询问、承认、拒绝、安慰或协商 | 给发言一个明确对象和目的，让对方的回应接得上；语言可坦率、含蓄或带情绪，取决于人物 |
| 既有行动和选择 | 情绪改变人物正在做的事或之后的决定 | 在已安排的行动中写出选择及影响。所用物件、能力和信息来自本书 |
| 停顿、留白或叙述节奏 | 人物没准备好开口，或前文已足以让读者理解 | 留下仍可理解的反应或结果，按作者节奏决定是否写出未说的话 |

细节能使人物更具体，也可以被直接一句话替代。人物可以平静地说明愤怒，也可以一边悲伤一边把事情办完。读者已经明白感受和来由时，后续笔墨可以移到人物的行动和处境。

## 交涉、冲突和关系变化

本场已经安排交流时，先看双方各自所求、掌握的信息和能决定的事。让他们对具体问题作答、追问、给出条件或拒绝，也可以在能达成一致之处先商定一步。

- 对峙可以升级、缓和或以暂停结束。选择哪种结果，由场景已有目标、筹码和关系边界决定。
- 在场的旁观者如果会因结果改变实际决定，可以写出相关反应。交流仅发生在两人之间时，可以让两人的反应自己承担场景效果。
- 人物有所隐瞒时，明确隐瞒的对象、理由和实际影响。有条件说清的事情可以直接说清；后续误会需要由已有的信息差或行动维持。
- 关系变化应体现为新的理解、态度或决定。作者安排人物暂时无法改变时，写清卡住他的原因，同一结尾也允许保留余韵。

## 独立演示

这些短例展示技法。例中的事实和措辞只属于各自场景。

- **直接表达**。她关了灯，才承认自己还在生姐姐的气。那封信里她最想听的一句有了，剩下的仍然没说开。
- **让谈话改变决定**。“明天我可以代你开门，账不能替你签。”对面想了一会儿，说：“那就只开门。账等我回来，一起算。”
- **安静地承接既有行动**。他把名单读到一半，略过那个已经划掉的名字，接着核对余下几行。念完以后，他回到第一行，从头看了一遍。

## 改稿时如何检查

- 先引用让人读不明白或显得重复的原句，指出是来由缺失、人物口气不合、表达没有进展，还是感受与行动互相冲突。
- 清楚且符合人物声口的内心、直接情绪、谈话与停顿都可以保留。需要补写时，优先补已有处境如何影响人物选择。
- 修改局部时保留现有剧情、事实和视角。若改动需要新增目击者、物件、冲突或决定，回看本章计划是否已经安排该内容。
