# 质量检查清单

这份清单用于阅读与修订判断，不增加本章的剧情任务、人物配额或固定技法次数。交付格式、明确计划和已建立事实优先；篇幅遵从实际配置与内容承载，不用通用字数范围替代本次任务。

## 整体检查

### 基础要素

- [ ] 标题准确、可辨识，与已写章节不无意义重复。
- [ ] 篇幅与本章任务相称，关键过程和结果完整；安静过渡可以短，复杂交锋可以长，不因相邻章长短不同而补水。
- [ ] 读者能辨识必要的时间、地点、在场人物与物品位置。倒叙或留白服从叙事安排，不造成事实矛盾。
- [ ] 本章承载完整的阅读单元，可以推进、等待、消化后果或闭合，不要求每章都有高潮。

## 开头检查

- [ ] 开头承接已有处境或明确的新叙事位置，不复述前章刚写完的事件。
- [ ] 行动、日常、环境或内心按视角与作者风格选用，不为抓人强造冲突。
- [ ] 必要背景交代清楚；不因避免解释而让读者无法理解当前行动。

## 内容检查

### 情节与因果

- [ ] 按实际计划交付事件或静场，重要结果有足够的过程支撑。
- [ ] 人物改变决定的依据可理解：已有目标、已知信息、压力、资源与新的行动或回应相接。
- [ ] 交易的对象、条件、筹码和责任明确；被要求不等于答应，试出问题不等于已经解决。
- [ ] 允许有准备的顺利成功、停顿或无外部冲突，不额外制造代价、误会、救场或敌人。

### 注水检测（长篇小说必查）

- [ ] 复述若没有新的阅读功能可以删改；因果必要的连续行动和有意义的回响可以保留。
- [ ] 疼痛服从实际伤势、情绪与行动后果，不按全书次数限制，也不反复用同一种体感填篇幅。
- [ ] 内心、信念与身份判断可以表达犹疑、情绪或理解，不要求每段都产生新决定。
- [ ] 环境可以定位、塑造氛围或承载情绪，长度取决于场景，不用固定字符数切断。
- [ ] 机制和能力说明帮助读者理解实际操作，不临时新增能力，也不为了次数限制省掉必要解释。

---

## 人物检查

- [ ] 人物行为与已建立身份、信息、利益和处境相接。重要立场变化有依据，不为主角降智。
- [ ] 欲望、需要、防御、价值排序和底线是设计依据，不自动变成人物已经经历或知道的事实。
- [ ] 配角有自己的行动逻辑；独立牵挂按实际需要体现，不要求每人另造支线或每章交一份成长结果。
- [ ] 人物情绪可以用行动、对白、心理或讲述表现，表达方式符合视角，不把所有反应改成攥拳或停顿。
- [ ] 相同说话方式不单靠口癖区分；人物的关系、目的和已知信息影响当前发言。

## 对话检查

- [ ] 提问与回答针对同一对象和时段；试探或诈供让读者有足够线索辨认。
- [ ] 关键条件说明完整，不用含混代词或短句省去必要因果。
- [ ] 问答、长发言、寒暄、沉默都按实际交流需要使用，不规定句数、句长或交锋轮次。
- [ ] 对话可有潜台词，也可直说；不因强求含蓄让交易和人物意图不可理解。
- [ ] 出声对白和内心区分，说话人可识别，引号与段落符合本书约定。

## 悬念检查

- [ ] 结尾服从计划落点，允许未决、闭合或余韵，不要求每章新钩子。
- [ ] 当前场景必需的信息已经讲清，不用省略交易条件或因果来冒充悬念。
- [ ] 留下的问题有真实后果，不机械重复“暂且放过、之后追责”。
- [ ] 已安排的风险和收益得到相称的回应；登记、推荐和资格变化应让读者看懂区别。

## 展示与讲述检查

- [ ] 关键动作及结果可理解，不能只说“解决了”却没有合理过程。
- [ ] 直接判断、情绪直述、心理、对白和描写按视角与阅读功能选择，讲述本身不是错误。
- [ ] 具体细节揭示真实处境，不用固定身体反应替换每一种情绪。
- [ ] 旁白不得无依据宣布人物已经理解或改变立场；读者需要足够的信息支持这个结论。

## 节奏检查

- [ ] 篇幅配置与读者关心的事件重量相称，不展开手续却略过关键兑现。
- [ ] 句子和段落长度服从表达，避免机械同形，但不按固定次数轮换长短。
- [ ] 连续行动、静场与消化可以自然持续，不按章数强插缓冲或换地点。

## 语言检查

- [ ] 命名、术语和措辞符合本书世界、时代、角色身份与信息来源。
- [ ] 检查无意义的套话、明喻、万能副词和同形身体反应，按上下文判断，不以禁词代替阅读。
- [ ] 认知旁白准确且必要，既不替读者空泛总结，也不为避免“意识到”而删除关键判断。
- [ ] 复杂判断可以直接讲清，不统一改成物件、停顿和短促口语。
- [ ] 指代精确、对象清楚；词语、标点和引号自然可读。

## 连贯性检查

- [ ] 角色位置、持有物、伤势、修为、关系和知识前后相容，变化有故事内依据。
- [ ] 关键物品出现、移动、交付与取回连续，不在同一场景中消失后无缘由重现。
- [ ] 回收按明确排期执行：同段到期可兑现，跨段线不提前透支。
- [ ] 能力规则、事实对象与治法一致，病因或价值变化有可理解的判据。
- [ ] 摘要提取的引文存在且支持对应结论；“原文声称发生”不自动证明操作过程完整。
- [ ] 修订后的反馈与观察对应同版正文，不把旧审校结果继续当作当前事实。

## 类型特定检查

- 悬疑：秘密可以暂不揭晓，当前问答和证据关系仍须成立。
- 言情：情绪与关系变化符合人物处境，不为配额强造误会或亲密。
- 奇幻／科幻：特殊能力按明确设定运作，必要原理与操作结果足以理解。
- 动作：空间与动作后果清楚，详略服从危险与角色选择，不要求每章战斗。

## 交付前最终检查

- [ ] 通读全文，核对错别字、标点、格式和说话人。
- [ ] 不看章纲，能解释关键人物为何答应、改口或承担风险。
- [ ] 不靠读者补事实，能复述关键行动和物品去向。
- [ ] 先检查已知事实与明确承诺，再判断表达是否服务人物和故事。

## 质量评分

人工比较时可分别观察可理解性、因果与连续性、人物选择、对话、节奏、表达及结尾兑现。评分只用于诊断和对照，不替代事实核对或程序准入，更不能把模型自评分当作文学质量合格证。
