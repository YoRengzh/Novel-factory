# 开篇钩子与金手指设计

网文的命脉是留人，而留人的两个起点是**开篇的注意力**与**金手指设计**。本资料三部分：七种常见开篇结构、金手指十流派与四要素、爽点的压与抬。与 hook-techniques（章末悬念钩）互补：那份管每章怎么收尾留住人，本资料管第一章怎么开头与外挂怎么设计。

## 七种常见开篇结构

快节奏平台的常见做法，是在开篇尽快制造"信息差 + 危机/反差"。以下是结构类型，不是必须套用的模板句。

| 结构 | 做法 | 适用 |
|---|---|---|
| **悬置危机** | 主角已身处绝境，原因/出路未知 | 通用 |
| **身份反差** | 低身份与高能力的落差先摆出来 | 男频逆袭、女频宅斗 |
| **结局倒挂** | 从故事结束之后的位置回看 | 穿书、无限流 |
| **替身/挡刀** | 主角替别人承受了命运的一击 | 女频、悲剧反转 |
| **金手指激活** | 开篇不久就让系统/外挂上线 | 男频爽文 |
| **日常爆破** | 平静日常被一条消息/一个电话击碎 | 都市、悬疑 |
| **反派开局** | 以反派/恶役视角开场，命运将倾 | 快穿、反派文 |

女频常见手感：弱势方对庞然大物（身份、家族、规矩），或一个决绝姿态（把赐死之物挂断，一句话立人设立冲突）。男频常见手感：屈辱/危机 + 金手指或实力反差，尽快立"逆袭预期"；"扮猪吃老虎"靠隐藏实力与外人误判，而不是靠旁白吹。

## 金手指十流派（选型表）

| 流派 | 机制 | 爽点来源 | 风险 |
|---|---|---|---|
| **系统流** | 任务发布 + 数值奖励 | 确定性反馈、升级闭环 | 易写成任务流水账 |
| **签到流** | 每日/地点签到领奖 | 零成本收益、复利滚雪球 | 前期爽后期乏力 |
| **空间流** | 随身世界/灵田/商城 | 资源囤积、乱世安全感 | 节奏易拖沓 |
| **模拟器流** | 推演人生/预演结果 | 信息差、试错无代价 | 逻辑要自洽 |
| **词条流** | 给万物附加属性词条 | 组合 build 的策略爽 | 数值要平衡 |
| **复制/吞噬流** | 复制他人天赋/吞噬变强 | 无限叠加的成长感 | 易破坏世界平衡 |
| **重生/先知流** | 携带未来信息重来 | 降维打击、弥补遗憾 | 蝴蝶效应要处理 |
| **召唤流** | 召唤名将/英灵作战 | 名场面 + 卡牌收集 | 易沦为抽卡 |
| **赘婿/扮猪流** | 隐藏实力/身份 | 扮猪吃老虎、打脸 | 装太久读者烦 |
| **无限流** | 闯关副本/恐怖游戏 | 智斗 + 求生 + 团队 | 设定门槛高 |

## 金手指设计四要素

1. **获取门槛**：怎么得到的？越独特越好，别"路边捡到"；绑定主角性格或遭遇更佳。
2. **成长曲线**：从弱到强的台阶要清晰，每一阶解锁新玩法，避免一步到位。
3. **使用代价**：无代价的外挂等于无聊。设定冷却/反噬/资源消耗/道德取舍，制造张力。
4. **主线绑定**：金手指的来源/进化要和主线大谜团挂钩（谁给的？为什么是我？），后期才有戏。

上线时机按本书节奏决定：快节奏平台常在前几章给出首次使用，慢热作品可以更晚。上线后尽快让它解决一个具体困境，读者才知道它值钱。防烂尾：给金手指设"成长上限的悬念"，否则主角无敌后无戏可写。

## 核心爽点元素部署表（按触发机制选型）

主角逆袭（弱变强的势能释放，前期压低、随后逐级抬升）；身份反转复仇（身份提前埋，揭晓压到高潮）；打脸反派（常见四拍：嘲讽→沉默→碾压→回应，不要求每场都凑齐）；隐忍复仇（苟得越久爆发越强，注意别苟到读者弃书）；重生（重生点选在"最痛的那一刻"前）；隐藏大佬（低调铺垫越足，露锋越强）；策略布局（提前埋子，收网时一次性揭晓全盘）；身世揭秘（可分三段揭：误导→半真→全真）；逆境翻盘（把主角逼到"必死"再翻盘）；越级挑战（越级幅度决定爽感，但必须给合理性）；智商碾压（让对手"自以为赢"再反杀）。

## 三段式爽感闭环

```
压抑（铺垫不公/嘲讽/危机）→ 蓄势（主角隐忍/布局/觉醒）→ 释放（打脸/翻盘/碾压）
```

压抑越具体，释放越有力。蓄势长度按事件与平台节奏决定，没有通用章数。

## 使用红线

- 套路是与读者的默契契约，不是贬义；但**主爽点宜集中**，其余做调剂（与 emotion-curve 的七来源表配合使用）。
- 已有旁观者的态度或行动会被结果改变时，可以写出这层后果。人物如何反应服从其所知和利害，参见 emotion-display-dialogue。
- 开篇钩与章末钩分工：本资料管第一章的注意点，每章的收尾悬念走 hook-techniques。
