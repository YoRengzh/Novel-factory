# 伏笔埋设与回收技法

伏笔用于建立并兑现具体期待，配合记忆系统跟踪已承诺的线索与结果。普通物件、人物习惯和生活细节不是默认伏笔；本文提供埋设与回收方法，不增加逐章数量、揭晓方式或题材任务。

## 伏笔三要素

检查一条明确的伏笔时，关注：

1. **信息可回看**：揭晓依赖的关键事实已在适当位置给出，不在结尾临时发明证据。
2. **期待可辨认**：读者对什么产生了疑问或期待，作者能说清；不把所有出场细节登记成待回收任务。
3. **兑现有意义**：答案解释先前事实或完成已建立的承诺。可以改变局面，也可以完成理解、情感或关系，不一定引发新冲突。

## 三线交织埋设法

物件、对话和行为是可组合的线索来源，不是每个谜团必须凑齐的三件套。以下假设师尊隐瞒了与旧敌的联系，三种写法分别提供不同信息：

| 线索类型 | 示例及成立条件 |
|---------|----------------|
| 物件 | 弟子见过旧敌的印记后，认出师尊收藏的信上也有同样印记；只能先证明存在联系，不能直接证明投敌 |
| 对话 | 师尊说自己未去过渡口，后来却说出未公开的渡口见面细节；需要交代细节的公开范围，形成可核实的疑点 |
| 行为 | 有记录表明师尊改了巡防路线，且时间与某次会面相接；动机仍需调查，不能把“慢半拍”自动解读为背叛 |

选择适合当前故事的线索即可。不同线索若独立支持同一推论，可以互相印证；不要让物件、语塞和异常动作只是在重复同一个含糊标签。

## 伏笔的密度与台账

管理明确承诺，而不是限制场景里能出现多少细节。

| 项目 | 管理方式 |
|------|----------|
| 新埋伏笔 | 与当前故事相关时登记，不规定每章必须新增或最多几处 |
| 待回收伏笔 | 看承诺的时间、当前相关性和读者期待，不按总数强制清账 |
| 台账字段 | 以运行时 schema 为准，不另造简化字段覆盖系统契约 |
| 普通闲笔 | 没有建立未来承诺时无需登记，不为登记而追加回收剧情 |

多题材融合时记录线索在哪条线产生、谁掌握信息、怎样影响其他线。已有因果足够时可以直接交汇，不强制先铺一个“衔接章”。

## 分类伏笔：不同类型各有埋法

| 类型 | 可用方法 | 需要检查的问题 |
|------|----------|----------------|
| 人物伏笔 | 先给可被后文重新理解的经历、说法或选择 | 后文是否凭空改写人物前史 |
| 身份误导（含双马甲） | 分清读者与各角色的知情来源，隐瞒需要现实或设定内条件 | 配角是否无视明显证据，误导是否靠叙述伪造事实 |
| 道具伏笔 | 交代与解题有关的来历、持有者和已知用途 | 回收时是否突然新增能力；普通道具不要求全部回收 |
| 世界观谜团伏笔 | 根据人物调查进度揭示信息，允许逐层，也允许一次讲清 | 新解释是否兼容既有事实、是否有信息来源 |
| 感情线伏笔 | 让后文关系变化承接已发生的相处、理解或冲突 | 目光、双标和旧物是否被机械当作恋爱证据 |
| 回溯题材伏笔 | 跟踪改变导致的实际后果与先知知识边界 | 是否把每次改变都强制写成新坑或惩罚 |
| 反派承载悬念 | 通过其行动和可靠信息逐步了解动机 | 是否要求每个反派都留遗言、名单和更大阴谋 |

## 长线伏笔与跨卷管理

- **跨卷承接**：回收时确保读者能找到相关前史。需要提醒时可以用回忆、谈话、行动或简要叙述，不固定间隔与方式。
- **契诃夫之枪**：突出强调并建立用途期待的要素通常需要兑现。并非所有椅子、食物、天气和日常习惯都必须变成解题工具。
- **连环线索**：嵌套可以使用，层数服从故事；检查各层问题与答案是否可懂，而不是按层数判废。
- **未决承诺**：收官前核对作者承诺与既定结局。明确的主线问题不能无交代消失，作者有意留下的开放结尾仍可保留。

## 闲笔成蝶伏笔法

普通细节可以在后文获得新的意义，但不能因此要求每条闲笔都指向终局。

- **选择**：后文需要使用某个旧事实时，确认它在前文确实存在，且新用途没有改变原事实。
- **埋设**：让细节在人物实际会注意到的位置出现，不为了藏谜强添与场景无关的物件。
- **复现**：需要承接时再出现；不为了保温固定每卷重复动作、声音和气味。
- **登记**：决定以它建立未来承诺后再登记；自然生活描写不自动进入伏笔账。

## 假伏笔与误导边界

误导可以发生在角色或读者的解读中，叙述中的事实须服从既定视角与作者约定。人物可以说谎，谎言不是叙述者认可的事实。

- 可疑行为可能有其他原因，揭晓时要能解释它，而不是事后说“其实无关”。
- 判断被误导后，相关人物是否有信息条件作出那个判断；不要把所有人写得迟钝来保护谜底。
- 不规定真假线索比例、每卷误导次数或固定补偿。误导需要完整来由，不能靠密集反转掩盖证据不足。

## 埋设的自然度伪装

自然度来自事实在场景里成立，不是专门安排动作替物件隐藏意义。

- 交代人物为什么见到、拿到或谈起这条信息。
- 特写、平淡叙述和直说都可以使用，取决于当下的叙事焦点。
- 不因为担心读者猜中，就删除应当提供的关键证据。
- 不把每次异常都附上“他记下了”“这件事另有玄机”的提示。

## 回收周期与时机管理

| 伏笔级别 | 处理方式 |
|---------|----------|
| 短线 | 服从当前事件的时间与承诺；可以同章兑现 |
| 中线 | 根据弧或卷的实际事件安排，必要时说明未完成原因 |
| 长线 | 在大纲层保留来由和预计用途，回收前确认前史可理解 |

- 同一事件自然解决多条线索时可以一起回收，不为分散数量拆成多次同构揭晓。
- 可以让线索暂时不推进，不必每章给一个暗示；长期承诺需要在故事中保持可识别。
- 回收需要已有机会和因果，不为了到排期而凭空请来证人或发明物证。

## 回收的写法

1. **呼应旧事实**：读者能认出它与前文的关系，不要求逐字复述旧句。
2. **补足理解**：新增信息怎样解释旧事实，推理步骤要有依据。
3. **交付结果**：明确承诺完成了什么，不只宣布“真相大白”。
4. **表达方式**：现场行动、谈话、叙述和内心均可使用；解释清楚不等于失败。

大揭晓也不必一律公开、崩溃或立刻决定生死。谁在场、谁得知、谁受影响，按事件和人物关系安排，不为“炸点”添加围观者。

## 弃坑回补技术

未能兑现时先确认原承诺与当前局面。能自然兑现则兑现；无法继续时，可以给出有依据的取消、失败或未决结果，不用更大阴谋遮住旧问题。

- 优先使用已有事实和人物，不临场发明新机制来填漏洞。
- 不为补坑强制暂停或推进主线；交代本身可以成为当前章节内容。
- 回补不能悄悄更改已发布文本的事实。确需修订旧文时，按项目授权和版本规则处理，不伪装成原来就有铺垫。

## 回收后的自检

1. **事实**：答案能解释哪些旧事实，仍有哪些未解决；不把相似、同尺码或时间相接直接当作身份和因果证明。
2. **时间与知识**：物证何时出现、谁何时知道、人物能否据此行动。
3. **可理解性**：读者只凭已交付的信息能否跟上，缺少的必要步骤要写清。

自检先处理逻辑，再处理表达。少一个标点、短几句话或增加物件细节，都不能替代事实核验。

## 与伏笔账配合

- 新埋承诺写清对象、问题与来源，字段服从运行时 schema。
- 实际兑现后再核销，不因为计划写了回收就宣布正文完成。
- 待回收总数只是管理信息，不凭数量强迫本章制造清账事件。
- 来源登记留在计划与账本中，正文无需点明“回收了第几章的伏笔”。

## 常见错误

| 错误 | 后果 |
|------|------|
| 无证据断言 | 人物像提前拿到了谜底 |
| 新增万能机制解题 | 回收不再依赖前文 |
| 把所有闲笔当作承诺 | 整个生活场景都在表演线索 |
| 同一提示反复换词 | 读者察觉模板而非获得新信息 |
| 假线索无来由地消失 | 误导变成遗漏 |
| 为清账强加聚会或事故 | 人物行动服从台账而非故事 |
| 正文与拆解不一致 | 教材把未成立的逻辑认证为正确 |

## 自查清单

- [ ] 这条信息确实建立了未来承诺，还是普通生活细节？
- [ ] 关键事实已有来源，人物的推论没有越过证据？
- [ ] 时间、空间、持有物与知情范围连续？
- [ ] 答案回应了什么期待，还有哪些未决？
- [ ] 回收表达与本书视角、人物声音和作者结局一致？
- [ ] 没有为了配额增加线索、反转、伤害、观众或新阴谋？
