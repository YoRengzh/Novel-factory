# 跨章一致性四表

长篇小说最容易翻车的地方不是单章写得好不好，是跨章前后不一致。把"一致性"从一次性的检查清单，升级成四张**持续维护的台账**：写好每一章前先看表、写完后更新表。本文只讲台账机制（怎么持续记、怎么防漂移），不重复通用检查清单。

> 下表的数据只演示格式，全部为占位符；不要把这里的物件、年份、金额当成本书事实。

## 一、道具链表

每个关键物件一张表，记录它每一章的位置/状态变化：

```
## 道具链 · 物件甲
| 章 | 位置/状态 | 变化 |
|---|---|---|
| N | 持有人处（随身处） | 首次出现 |
| N+3 | 持有人处 | 交代来历与用途 |
| N+9 | 第三方处 | 转手、损坏或丢失 |
| N+10 | 持有人处 | 取回时的状态 |
```

规则：**写新章前先查表**，确认物件当前在哪、什么状态；**写完后更新表**。关键物件是"剧情说了算"的东西——信物、兵刃、契书、凭证，一律建表。

## 二、时间锚表

每章在台账中记录一个时间戳，用于章间计算跨度；台账时间不要求写进正文开头：

```
| 章 | 时间锚 | 距上一章 |
|---|---|---|
| N | 某日午后 | — |
| N+1 | 当日入夜 | +数小时 |
| N+2 | 次日清晨 | +一夜 |
| N+3 | 三日后 | +三天 |
```

规则：**跨天/跨月的章之间必须算清几周几个月**，防止"钩子说两个月后、正文算出来五周"这种读者一数就穿帮的错。时间跨度是强校验项（影响剧情因果与人物状态恢复）。

## 三、术语一致性表

同一个东西全书必须用同一个名字。改任何一处，全文对齐：

```
| 概念 | 统一叫法 | 禁用别名 |
|---|---|---|
| 关键文书 | 完整限定名（含归属与用途） | 简写、代称、含糊指示 |
| 关键印记 | 可辨认的独有特征 | "那枚章""旧印" |
| 配角随身物 | 具体物件名 | "小物件""那个东西" |
```

规则：术语名**宁长勿歧**——宁可啰嗦，不因缩写产生歧义。同一概念被换叫法 = 一致性破坏，读者会以为出现了新东西。

## 四、关键数字表

年龄、年份、件数、金额、比分——最容易前后不符的类别：

```
| 项 | 数值 | 出现章 |
|---|---|---|
| 主角年龄（关键节点） | 数值甲 | N/N+5/N+12 |
| 关键事件的年份 | 年代甲 | N/N+6 |
| 结算比分/总数 | 数值乙 | N+3/N+4 |
| 债务或刑期 | 数值丙 | N+9 |
```

规则：数字项**必须完全一致**，写新章引用时回表核对；涉及结算的总分/金额/年限，写前先算一遍再落字。

## 五、钩子区 vs 正文核对

钩子承诺的东西正文必须兑现——这是"章末悬念"质量的关键：

最常冲突的四类（实战高频）：
- **比分**：钩子写"五胜两平"，正文算出来四胜两平加第七局
- **时间线**：钩子写"两个月后"，正文算出来五周
- **道具细节**：钩子写"推门进某处"，正文写成另一处
- **罪名/清单项**：钩子列了三条，正文只兑现两条

核对方法（每章发布/定稿前）：
1. 把钩子段的关键名词、数字、时间、事件列出来
2. 逐项检索正文是否出现
3. 数字项必须完全一致（比分/时间跨度/金额/件数）
4. 名词项要统一叫法

## 自检清单（每章写完/定稿前）

- [ ] 本章出现的每个关键物件，道具链表已更新？
- [ ] 本章时间锚已记录，跨度与上章能对上？
- [ ] 本章用到的概念叫法，与术语表一致（无新别名）？
- [ ] 年龄/年份/比分/金额，与关键数字表一致？
- [ ] 钩子区的数字、时间、道具、清单项，正文全部兑现？
