# 战斗场面范例

本范例仅供动作戏技法参考，不替代当前章节的既有事实、人物能力与场景契约。动作推进须紧扣空间与地形条件，负伤状态必须持续制约后续选择；严禁使用破折号强行解释动作意图，严禁角色在战后做账房式的收获盘点。

## 湿木擂台

铜锣声落，沈砚沿着擂台边缘缓步走了两步。昨夜的积水浸透了台面木板，鞋底一踩，水渍便从板缝间溢出来，脚下发腻打滑。对面的剑客将长剑推开半寸，见他迟迟不进，便又按回鞘中。

“三招，我让你先出。”

沈砚欺身提掌逼近，右脚却始终留在台沿。那人侧身避让，顺势探手来拿他手腕。沈砚猛地矮身下沉，掌心贴实湿木，将熟稔于心的火痕劲气拍进板缝。滚烫的白汽骤然自缝隙蒸腾而起，漫过两人靴面；趁对方低头避视的刹那，沈砚五指如钩，径直抓向那人的剑鞘。

沉重的剑脊已先一步砸在他左肩上。沈砚半边身子瞬间酸麻失力，整个人扑倒在湿滑的台面上，指间只扯下半截系剑的布带。那人抽回长剑，向右侧撤步拉开距离，靴底在积水处打了个滑，随即稳稳停在靠近擂台中线的一溜干木板上。

沈砚单手撑地起身，试着抬了抬左臂，刚举到胸口便疼得剧烈痉挛。他改用右手按住膝盖，低头将喘息压稳。对面那人已不再给他贴身的机会，长剑前指，剑尖遥锁他胸口，只是脚下可供腾挪的地方，也只剩下中线那条窄窄的干板。

台沿的白汽渐渐消散。沈砚将那截断带一圈圈缠紧右掌，贴着干湿木板的交界线往前寸移。那人剑锋随行，刚迈出半步，靴尖触到水渍便下意识缩了回来。沈砚抓住这半息迟滞猛扑剑侧，缠满布带的右手一把攥住鞘口，径直拿受伤的左肩狠狠撞进对方怀里。两人踉跄着一同撞向台沿，沈砚借势松手翻滚卸力，硬生生将那人逼出了中线的干木板。

那人在湿滑的木板上勉强稳住下盘，五指重新扣紧剑柄。沈砚后背距擂台边缘只剩半步，左臂无力地垂在身侧。他抬起右手抹去眼角溅上的泥水，目光死死锁住对方踩在水渍里的靴底，静候下一剑刺来。
