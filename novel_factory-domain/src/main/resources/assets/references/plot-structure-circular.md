# 环形结构（Circular Structure）

结局回到开头设定的情境、意象或问题，首尾相接形成闭环；常用来表达宿命感、时间轮回或历史重演。

## 章级组织（比例制）

```text
开篇：      设定一个"起点意象/预言/提问"（读者未必察觉其重量）
主体：      线性推进（中段可按三幕/五幕正常走）
收尾：      回到开头的意象/场景/那句话，但意义已改变
```

## 关键

- 开头元素必须"足够轻却能承重"：既是普通细节，又是结局的解码钥匙。
- 回环要制造"原来如此"的重读感，而非机械复读同一句。
- 适用于宿命、轮回、遗产、执念等主题，也适合因果报应题材。

## 例证辨析

- 《百年孤独》：开篇是预叙（"许多年之后……"），结尾是羊皮卷被读完。首尾呼应的是**预叙与揭底**，不是"预言应验"。
- 《牧羊少年奇幻之旅》：结尾让主角回到开篇的废弃教堂、在原处树下挖到宝藏——首尾**同景**，并没有重复开场那句话。
- 《开端》：循环结构，每一轮回到同一时间点，但人物的认知在累积。

## 常见误用

- 首尾复读同一段文字，读者只觉得重复，不觉得回环。
- 为了闭合硬凑对称，牺牲了中段的因果。
