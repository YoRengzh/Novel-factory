# 悬疑小说结构

按"问题—调查—收束"推进，不绑定具体章号；短篇一轮跑完，长篇由若干案件弧叠加。

## 第一幕：案件成立

- **异常出现**：发现、报案或被卷入，先把"哪里不对"写具体。
- **谁在查**：交代调查者的身份、权限与私人牵连，决定他能看到什么。
- **初步勘查**：给出可核实的事实与第一批疑点，不急着下结论。
- **立案焦点**：明确本案要回答的核心问题（谁、为何、怎么做到的）。

## 第二幕：调查深入

- **逐个排查**：每个嫌疑人/方向给出支持与反对的证据，排除要有理由。
- **信息差**：读者与调查者的知情范围不同；让读者"多知道一点"或"少知道一点"都成立。
- **第二起事件或新证据**：改变对前文的理解，而不是单纯加一个坏人。
- **压力上身**：期限、上级、舆论或人身风险改变调查者的选择。
- **错误方向**：至少一次合理误判，误判来自已有偏见或证据缺口，不靠角色降智。

## 第三幕：真相与代价

- **关键证据落地**：复盘时读者能指着前文说"这里就有"。
- **对质**：动机、机会、手法三者对上；对手可以狡辩、反制或求和。
- **收束**：案件结果之外，交代它改变了谁的处境。

## 公平推理自检

- 答案依赖的线索，揭晓前是否已经出现，且读者有机会注意到？
- 每个被排除的人，排除理由是否只依赖其已知信息？
- 反转后，旧解释是否仍能解释它当初为何成立？

## 常见误用

- 用"第 8 章必须反转"安排节奏：反转由证据链决定，不由章号决定。
- 靠凶手自白补全所有漏洞，前文却没有可回溯的材料。
