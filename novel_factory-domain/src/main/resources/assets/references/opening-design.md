# 开篇设计（黄金三章）

本资料以快节奏类型小说的“黄金三章”为参考，用于诊断已有开篇如何建立人物兴趣、交代必要信息并与后文衔接；章数、任务表与冲突技法是样本，不是生成配额，也适用于检查生活流、配角开场、叙述式与慢热开篇各自的阅读效果。

## 为什么是前三章

前三章是观察部分连载作品首读体验的参考窗口，不是所有读者、编辑或题材统一的去留期限。

回读开篇时，可以问读者先获得了什么兴趣：在意人物的处境、想知道一个答案、享受叙述声音，或愿意继续观察一段生活。兴趣不必等于主角马上解决麻烦；慢热开篇也能通过清楚的视角、有辨识度的观察和具体的生活联系让读者留下。

## 黄金三章任务表

任务表只是某类快节奏开篇的参考样本，用来对照已写内容，不要求三章按表交付。

| 样本位置 | 可能承担的作用 | 回读时观察 |
|----------|----------------|------------|
| 第一章 | 建立人物、处境、声音或一个疑问 | 读者有什么理由继续读，是否能理解当前场景 |
| 第二章 | 展开选择、关系或信息变化 | 内容是否发展了已有兴趣，而非重复介绍 |
| 第三章 | 回应局部问题，或使关注更清楚 | 已有变化是否可信，后续兴趣从何而来 |

快节奏对抗故事可以在一段内完成“遇事—应对—结果”；生活流也可以先让人熟悉早餐铺、常客与掌柜的相处。配角开场可以完成独立事件后再转主角，章数由实际内容决定。局部反转与初露锋芒是可选手段，不要求第三章释放爽点、亮底牌或揭示更大世界。

## 开篇即冲突

冲突直入只是行动型开篇的参考，第一段也可以写生活、天气、人物观察、背景叙述或尚未显形的矛盾。

- **切入有重心**：对抗题材可从催债现场切入；生活题材可从掌柜核对今日订单切入；叙述式开篇可用一段对小城的观察建立声音。判断它是否给读者具体可读的内容，而不是只看有没有冲突。
- **定位足够清楚**：让读者理解当前视角与场景联系。地点可以随行动交代，不要求首章用一句话答全所有问题；若人物跨地点行动，应说明出发处、目的地与必要路径。
- **疑问有内容**：异常、未完成的事与人物态度都能形成兴趣，不能只靠故意省略人物本应知道的信息。
- 需要行动型开头的扩展时，可参照 chapter-guide.md 的“十种强力开头技巧”；不将技巧名作为必用清单。

### 首个冲突的五个检查角度

这五项是直接对抗型开篇的参考检查维度，不构成通用门槛，也不要求开篇必有冲突。

| 维度 | 具体诊断与可用方法 |
|------|------------------|
| 进入时机 | 对抗开始前的交代是否帮助理解选择？若只是复述背景，可从相关行动切入；必要的铺垫仍可保留 |
| 利害 | 谁在意什么、结果会改变什么？可以是钱、资格、关系或安稳，不需升级成伤亡 |
| 后续联系 | 结果怎样影响后面的行动？冲突也可以完整结束，以关系余波、生活恢复或相关的新选择衔接 |
| 立场 | 各方依据与利益是否能理解？允许灰色冲突、误判和暂不站队，不强迫分出欺人者与占理者 |
| 入局方式 | 主角、配角或叙述视角为何与此事有关？允许旁观、主动介入或配角独立处理 |

若情节确有智斗，写清人物所知、筹码、办法与对方反应；协作、直接谈判或暂时退让同样可成立。不为凑算计次数添加计谋，也不能靠对手无依据降智取胜。

## 主角登场速写

登场速写是帮助读者认识人物的参考，不要求主角首章出现、当场受欺或在一次冲突中暴露全部特征。

- **选择与日常都能立人**：救不救人可以说明价值取向，如何记账、照料家人、对待同事也能说明人物。旁白与心理叙述可以与行动结合。
- **愿望可渐显**：先看人物已有关注，再辨认愿望与阻碍；无明确目标的阶段可以由观察、迷茫、习惯或关系建立兴趣。
- **记忆点有意义**：口头禅、职业手艺或外貌特征在适当处帮助辨认，不需每次出场重复。
- **边界可信**：有能力的人可以稳定生活、轻松办事；只有故事声称人物无所不知、能力又随需要变化时，才需检查依据，不强制添加贫弱困境。

### 人物介绍的五个观察角度

身份、欲望、缺陷、记忆点与抉择可以帮助理解行动型人物。叙述、对白与逐步披露同样有效，不要求在第一章全部呈现。

| 维度 | 可用方法 |
|------|----------|
| 身份 | 给读者理解当下行为所需的职业、关系或处境，不必一次罗列完整家世 |
| 欲望 | 通过所关注的事、对白或心理呈现“为何在意”，不必量化或当场宣布 |
| 缺陷 | 若已有短板影响选择，说明作用与后果；不为介绍人物临时让缺陷发作 |
| 记忆点 | 用与生活相连的特征帮助辨认，避免孤立标签和反复机械表演 |
| 抉择 | 有真实分歧时展现选择及理由；没有两难也可以写工作、观察与相处 |

**陈九示例：同一目标与地点路径保持连续。** 长工陈九在东家宅院的账房外领月钱，兜里揣着母亲银簪的当票。账房扣了他的工钱，他对照工日与签收记录，说明少算了两日，取回应得的月钱。出了宅院，他沿南街走到桥头当铺，把月钱与当票交给柜伙，核对银簪后赎回。身份、想要的东西、阻碍、应对与结果彼此相关；没有为展示抉择突然改去买地契，也不必让他跪雪、挨打或当众受辱。

这段也可保留明确的心理叙述：“他怕当铺认不出当票，更怕自己认不出母亲留下的簪子。”情绪不需要全部替换成手指、茶杯或沉默。

## 已有金手指的开篇展示

本节用于已明确设有金手指的卖点型开篇。出现时机按本书计划安排，没有金手指的故事跳过，不为开篇新增外挂或系统任务。

| 维度 | 可用诊断与方法 |
|------|----------------|
| 出现时机 | 若开篇已把能力当作主要兴趣，观察读者是否能理解它为何重要；出现位置由剧情决定 |
| 使用体验 | 在相关场景展示能力实际影响，例如辨认修补痕迹，而不只堆面板说明；允许先发现、后研究 |
| 效果清楚 | 说明改变了什么、角色怎样获知，不把抽象数值当成完整体验 |
| 规则边界 | 依既定设定交代作用范围与限制，不临时添加代价，也不遇到困难就改规则 |
| 与当下联系 | 能力若影响当前问题，写清连接；也允许它暂时无用、引起疑虑或在另一条线发挥作用 |
| 披露层次 | 先给理解当前行动所需的信息，复杂规则可后续展开；已有说明性叙述若清楚有趣也可保留 |

## 首次回应：建立可靠的阅读期待

首次回应可以帮助建立信任，但不规定三章内给小甜头。可靠回应不等于必须获胜、受辱翻盘或有人围观。

- **局部问题有结果**：取到月钱、找到失物线索、解释一个误会，都能让读者感到内容有所回应；失败或仍待查明也可以，只要变化有实质。
- **手段有前因**：技能、证据、协作、赠予与合理偶然都可产生结果，不要求金手指或主角独力完成。
- **结果能感知**：通过人物行动、关系变化、心理叙述或生活恢复写出意义。例如陈九独自在当铺核对银簪，胜利不需旁观者惊呼。
- **成本不硬造**：已有付出应前后连续，轻松办成小事也可成立，不为“有分量”临时增加挨打、破财或伤亡。
- **核心体验不偷换**：许诺公平解谜，就用已有线索支持答案；以生活观察吸引读者，就继续提供可读的生活层次，不必改成打脸闭环。

## 开篇目标感：短期目标驱动前三章

短期目标驱动只是目标型故事的开篇参考，不要求前三章给出带数字期限的一句欲望，也不把随生活探索视为失格。

- **结果可理解**：想赎回母亲银簪、向朋友道歉、学会一种手艺，比空泛目标更易理解；原因可以通过行动、叙述或对白展开。
- **阻碍与选择相关**：有欠薪、缺材料、无法开口等事实时说明影响，没有阻碍则不补造敌人。
- **长期方向可晚些明确**：人物在观察与经历中逐渐认清所求，也可以只关注眼前生活。
- **目标可以独立**：章、段、卷目标未必上下套娃，配角的探亲与主角的工作可以各有意义。
- **量化只在确有时用**：当票写明赎期、钱数影响办理时交代具体数字；“想恢复与父亲的来往”不需要期限或进度条。
- **能力连接有条件**：只有已有金手指且实际相关时，才分析其作用，不要求短期目标专为外挂第一用法设置。

回读时将“人物关心什么—为什么关心—现在怎样行动”作为观察工具，不将“具体物 + 期限 + 阻力”设为事实之外的补造要求。

## 忌堆设定

避免设定过载是开篇信息组织的参考，不是禁止整段世界观叙述或限定首章名字数量。

- **给当下所需的信息**：账房为何能扣工钱、当铺如何核验当票，比无关的全城制度更直接；若制度本身是叙述兴趣，可以完整写清。
- **降低辨认负担**：人物成批出现时，用关系、行动与场景位置帮助辨认；人数由故事需要决定，不按五个名字截断。
- **名词有落点**：先让读者知道制度或器物怎样影响生活，再展开相关层级。已知术语不必重复解释。
- **判断段落作用**：若说明段清楚、有声音、能建立兴趣，可以保留；若读者尚无理由关心，可后移、压缩或结合具体经历。

## 世界观的软性植入

软性植入是设定披露的一种参考方式，人物受欺与悬念留白不是必备条件。

- **从使用规则展开**：排班、交易、节庆或修理过程都能展示世界运作，不只靠主角被规则欺负。
- **依理解需要选择篇幅**：一句话可以解释当票效力，一段叙述可以说明复杂制度；不要求每个设定只有一句。
- **留白有边界**：未知疤痕可以留下疑问，人物清楚的常识则依视角正常呈现，避免为了神秘刻意不说。
- **事实保持连续**：规则、地点、路径与信息来源前后一致；情绪需要不能成为任意改动设定的理由。

## 开篇与后续的衔接

衔接检查是回读已有剧情连续性的参考，不要求开篇冲突跨三章、悬念撑到固定高潮或后文每章更紧。

- **辨认承接内容**：未完的事、结果余波、人物关系、叙述声音与固定生活场景，都能连接后文。
- **明确阶段完成**：陈九赎回银簪后可以回家、整理旧物或继续工作；局部事件完整结束不等于“换故事”。
- **回应已建立的关注**：重要问题后续消失时，检查是否已有结束、暂置理由或有意开放，不按 8-20 章排回应期限。
- **强度可以回落**：行动后有休整、日常或独立支线可以成立；判断它们是否仍提供作品承诺的体验，不把开篇强度当全书下限。
- 如需诊断段落拖延，可参照 pacing-control.md 的相关方向，不套用固定加速曲线。

## 黄金三章后的节奏控制（防止用力过猛）

本节只是快节奏连载开篇之后的参考诊断，不用章数判定是否过猛，也不要求所有故事推迟高潮或保留最终敌人。

真正需要观察的是：开篇已展示的能力与规则能否支持后续，人物转变是否有依据，重要问题完成后是否还有值得读的内容。早早发生大事可以成为故事前提，后文也可以转向后果、日常重建或关系探索。

### 用力过猛的典型症状

这些症状只是特定成长、能力或反转型故事的检查参考，不适用于没有相应设定的开篇。

- **胜负无依据**：能力差距、筹码与结果无法对应。跨层击败强者本身不是错误，关键是既有规则能否解释。
- **答案抹掉全部兴趣**：揭示之后只重复答案，没有相关后果；可以改写为对真相的行动与生活影响，不一定重藏最终敌人。
- **核心能力被无故忘记**：已有问题明显能由该能力处理，却无解释地不用。暂时无使用场景、角色不愿使用或规则限制都可以成立。
- **转变没有过程**：重大的价值变化缺少经历、判断或心理依据；不按章数补挣扎，而补真正改变判断的内容。
- **对手与力量设定断裂**：新对抗超出已有因果，却只靠临时规则接续。直接遇到最终敌人可以成立，不必填中间头目阶梯。

### 第 4-10 章节奏基准线

“第 4-10 章”只是部分快节奏作品的取样窗口，下面是观察样本，不是章数配额、敌人档位或金手指使用排期。

| 样本范围 | 可能看到的内容 | 回读问题 |
|----------|----------------|----------|
| 第 4-6 章 | 前事余波、日常恢复、关系展开或新行动 | 开篇结果怎样影响此刻，信息与行动是否连续 |
| 第 7-10 章 | 局部完成、进一步探索或持续观察 | 已有兴趣是否仍有内容，重复是否带来新意义 |

- **高潮位置看结构**：重要选择与结果可以早到、晚到或分散出现，不要求第 8-15 章首次大高潮。
- **世界观披露看需要**：局部规则、广域背景与终极真相依视角和叙述目标安排，不设置第十章以后才能揭示的门槛；可参照 worldbuilding.md 的披露方法。
- **成长遵循既定规则**：训练、经验、天赋或其他已有条件解释变化与边界，不要求每次成长额外冒险，也不凭空改变能力。
- **金手指/系统仅在存在时分析**：确有该设定时，检查重要使用、限制与不用的理由是否自洽；没有就跳过，不每三章补使用、提及或魔法任务。

## 开篇流派选择：四种开局各有适配题材

四种开局只是部分类型作品的参考分类，不覆盖全部开篇，也不要求读者三章内认定流派。

| 样本类型 | 可能适配 | 可用方法 |
|----------|----------|----------|
| 冲突直入型 | 行动、对抗类故事 | 写清当前利害与选择，让应对符合人物所知 |
| 金手指先行型 | 确有系统或特殊能力的故事 | 展示与当下有关的作用和既定边界，不添加外挂 |
| 身份反差型 | 身份差异本就重要的故事 | 通过行为、关系与信息差让两种身份互相解释，不只靠旁白贬低 |
| 回溯型 | 确有重生、回忆或历史层次的故事 | 交代时间关系，说明过去的信息怎样影响当下，不必首次就变现获胜 |

生活、配角、叙述与慢热开篇不需归入这四类。例如先写配角经营当铺，再由陈九来赎簪引入主角；也可先叙述小城的借贷习惯，以一张当票连接具体人物。

- **焦点可主次也可并行**：检查各元素是否能被辨认、如何相连，不禁止混合流派或多视角。
- **转向有依据**：故事可以从对抗转向日常、从生活观察转向谜案；让变化来自已有经历，而不是无解释地撤掉原有兴趣。
- **收束回应已有内容**：可以回扣第一幕，也可以回答另一段更重要的关注，不要求全部愿望成功或流派承诺逐项清账。
- **区域选择（pattern 016 开篇场景）**：场景选择是诊断可见行动与人物关系的参考。账房、当铺、厨房、街道都可适用，写清谁为何在此及移动路径；不强迫选择输不起的公开场合或把人物压到最低点。

## 常见开篇死法与自查

以下是阅读可能失效的诊断参考，不把天气、吃饭、配角、回顾或慢热本身视为“死法”。

| 可观察问题 | 具体修正方向 |
|------------|--------------|
| 日常或天气只有重复概述 | 补充与人物、地点、声音有关的具体观察，或压缩无作用的重复；不必加灾难 |
| 名词难辨、解释缺落点 | 说明当前行动所需的关系与规则，复杂信息分层组织或清楚叙述 |
| 配角开场关注落空 | 保留配角事件自身结果，或说明它怎样连接后文；不硬赶主角首章出现 |
| 回顾与当下关系不清 | 标明时间、视角及回顾为何重要，不把回忆或叙述式开场当禁项 |
| 开场结果和目标不对应 | 核对行动为何能取得所求，补齐地点、路径与相关结果，避免赎簪突然变买地契 |
| 为快节奏临时增加设定 | 删除无依据的外挂、伤亡、围观或敌人升级，沿既有条件组织应对 |
| 情绪表达只剩小动作与沉默 | 结合人物适用的心理、对白、叙述与细节，不规定一律短句 |

以下清单只用于回读已有开篇，按题材与实际设定选用，不生成强制任务。
