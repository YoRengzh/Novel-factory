# 语域纪律与热梗边界

语域（register）一致是长篇文风的隐形地基：全文的用词频道必须统一——朴实就一直朴实，古风就不冒现代词。AI 最隐蔽的破绽不是比喻和套话（判据库已覆盖），而是**跨度大/不搭的引用**：古风文里冒出 MBTI，朴实白描里塞普鲁斯特。本资料四部分：语域红线与判断法、按频道的语域基线、网络热梗使用边界、感叹号与标点降噪。适用正文与修订场景，尤其穿越/古风/修仙题材。

## 语域红线（两问判断法）

每一个引用、比喻、概念，问两句：
1. "**这个叙述者/这个角色**，会知道、会这么说吗？"——市井女主不会随口引黑格尔；杂役弟子不会用"心理创伤""应激反应"这类现代心理学词汇。
2. "这个引用，和**全文的语气**是一个频道吗？"——朴实白描里别塞华丽典故。

反例即改：古风文里"公主气场全开，仿佛人间清醒的 MBTI 之王"（现代梗污染古风语域）→ "公主眼皮都没抬：'退下。'"；通俗都市文里"他的背影消失在街角，恰似《追忆似水年华》中那不可追回的时光"（跨度过大，出戏）→ "他头也不回地走了。我站在原地，看着那个背影越来越小。"

技术代差原则：古风/修仙世界的叙述与台词不得出现**晚于该世界技术水平的概念**——炮弹、辐射、纤维、阀门、声呐、雷达、内啡肽、条件反射一类工业/医学/军事现代词汇，除非叙述者本身是穿越者且此处正是他的认知卡壳点（穿越文的主角偶尔闪现代类比是角色特征，但每处感官描写至多 1 个，且马上被现实打断——见 transmigration-transition）。

## 语域四条守则

1. **先定语域**（朴实/华丽/古风/现代/冷感/俏皮），全文统一，不中途跳。
2. 通俗爽文：少引经据典，少掉书袋；要引也引读者秒懂的。
3. 古风不用现代网络梗；现代不硬塞古诗酸文；第一人称市井叙述者不用超出其认知的概念。
4. 宁可"老陈朴实"，不要"花哨不搭"——**风格一致大于单句出彩**。

## 网络热梗使用边界（六条铁律）

1. **看题材**：现代都市/校园/职场/现实向/轻松搞笑可用；**古风/玄幻/历史/正剧基本不用**——现代梗塞进古风是语域污染。
2. **贴人物身份**：年轻、有网感的角色才说热梗；老人、古人、严肃/高位角色不说。
3. **适量**：一篇撒 1-3 个就够。堆梗等于廉价 + 过气快 + 像硬蹭。
4. **避开快过气的**：越是"一句话场景梗"越短命，越是"一个概念词"越长青（内卷、躺平、破防属长青；当月谐音梗、综艺事件梗火得快烂得快）。拿不准就不用。
5. **放进对话/心理，别硬塞旁白**：梗在角色嘴里、吐槽里才自然；作者旁白强行玩梗最出戏。
6. **服务情绪/人物**：梗要体现性格或推进情绪，不是为玩而玩。

## 感叹号降噪

- **彻底禁用双感叹号（！！）**，任何场景。
- 单章感叹号总量控制在 5 个以内：感叹号是情绪重音，满屏感叹等于没有重音；真正的压迫感靠台词内容与动作，不靠标点喊。
- 连续两个以上感叹号结尾的对话连发即红线：把其中至少一半改成句号，靠台词本身立强度。

## 标点补充规范

- 简体网文引号一律弯引号（""''），不用直角引号「」『』，不用英文直引号。
- 省略号用 ……（六点一个标点），不用 ... 或 。。。
- 并列用顿号、，不用句号碎切（"他买了苹果。香蕉。橘子。"是病）。
- 正文不用装饰符号（✦ ✨ ◆ ● ★一类全删）；场景分隔用空行。系统流的系统弹窗提示【】是唯一例外。
